第 1 章 文件读写

预计 30 分钟·约 5,674 字·C 语言实战

你写的程序，数据大多活在内存里。程序一退出，内存就被系统收回去，刚才算得再漂亮也没了。文件的作用很朴素：给数据找一块能活过进程的地方。

这一章只做两件事：把数据写进文件，再原样读回来。听起来简单，但 fopen 那一行我第一次写的时候没检查返回值，程序安静地什么都没做，我还以为是硬盘坏了。后来才知道，文件根本没打开成功，后面的 fprintf 全写进了空气。

1.1 文件是一条数据流#

C 不把文件当成「一个东西」，而是当成一条流：你从流里按顺序读，或者往流里按顺序写。打开文件时，fopen 给你一个 FILE *，它更像一张取件凭证，之后所有读写都凭这张凭证。

其实你早就在用流了。stdin、stdout、stderr 是程序启动时自动打开的三条流：

  • stdin：键盘输入，scanf 从这儿读
  • stdout：正常输出，printf 往这儿写
  • stderr：错误输出，perror 往这儿写

所以 printf("hi") 和 fprintf(stdout, "hi") 是一回事。fopen 只是让你自己再开一条流，并且给它起个文件名。

FILE * 里的 * 说明它是个指针。如果你对指针还发怵，先回去看 C 语言 第 6 章 指针，至少要知道「指针可能是 NULL，用之前要检查」。

1.2 fopen：先拿凭证，再进门#

最小的写文件程序长这样：

C
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("hello.txt", "w");
    if (fp == NULL) {
        perror("hello.txt");
        return 1;
    }

    fprintf(fp, "Hello, file\n");

    if (fclose(fp) != 0) {
        perror("fclose");
        return 1;
    }
    return 0;
}

逐句看：

  • fopen("hello.txt", "w")：以写模式打开。文件不存在就新建，存在就清空。
  • 返回 NULL 表示失败：目录不存在、没有权限、磁盘满了，都会失败。
  • perror("hello.txt") 把失败原因打到 stderr，输出类似 hello.txt: No such file or directory。
  • fclose(fp) 关闭流，返回 0 表示成功。

FILE 这个类型定义在 stdio.h 里，你不需要知道它内部长什么样，把它当成文件句柄就行。

模式只有几个，但每个的脾气不一样：

模式文件不存在时已有内容能读能写
"r"返回 NULL保留是否
"w"新建立刻清空否是
"a"新建保留，写在末尾否是
"r+"返回 NULL保留是是
"w+"新建立刻清空是是
"a+"新建保留，写在末尾是是

最容易被忽略的是 "w"：它在打开的那一刻就把文件清空了，不管后面写不写。你想用 "w" 打开文件「先看看里面有什么」，结果一打开，内容已经没了。想保留原内容再往末尾加，用 "a"。

C
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "w");   // 打开这一刻，data.txt 已经被清空
    if (fp == NULL) {
        perror("data.txt");
        return 1;
    }
    fclose(fp);
    return 0;
}

你可以自己验证：先往 data.txt 写几行，再运行这个程序，文件会变成 0 字节。把 "w" 改成 "a"，内容就保住了。这个实验做一次，比背十遍模式表都管用。

"r" 则相反：文件不存在就直接返回 NULL，不会帮你新建。所以读文件前检查返回值不是「好习惯」，是必须做的事。

▲常见错误

fopen 返回 NULL 后继续 fprintf(fp, ...)，程序不会报错，只会安静地什么都不做，或者当场崩溃。每次 fopen 后面紧跟一个 if (fp == NULL)，这几行不要省。

1.3 fprintf 和 fscanf：带格式的读写#

fprintf 和 printf 的用法一样，只是多一个「往哪写」的参数；fscanf 和 scanf 同理，多一个「从哪读」。

C
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("nums.txt", "w");
    if (fp == NULL) {
        perror("nums.txt");
        return 1;
    }

    for (int i = 1; i <= 3; i++) {
        fprintf(fp, "%d %d\n", i, i * i);
    }
    fclose(fp);

    fp = fopen("nums.txt", "r");
    if (fp == NULL) {
        perror("nums.txt");
        return 1;
    }

    int a, b;
    while (fscanf(fp, "%d %d", &a, &b) == 2) {
        printf("%d 的平方是 %d\n", a, b);
    }
    fclose(fp);
    return 0;
}
运行结果
1 的平方是 1
2 的平方是 4
3 的平方是 9

两个细节：

  1. fscanf 的返回值是成功读到的项数，不是读了多少字节。上面格式串有两个 %d，所以读到两个数才返回 2；文件结束或格式对不上，返回值就小于 2。
  2. 循环条件写 == 2，不要写 != EOF。因为读到一半失败时返回值可能是 1，!= EOF 会把它当成成功。
▲不要用 while (!feof(fp))

feof 只有在读过一次并且失败之后才变真。写成 while (!feof(fp))，循环会多跑一轮，最后一行数据被处理两次。判断还有没有数据，看 fscanf 或 fgets 的返回值。

fscanf 读字符串时用 %s，遇到空格就停。所以它读不了「张 三」这种带空格的名字。要按整行读，得用下一节的 fgets。

1.4 fgets 和 fputs：按行处理#

按行读写更像人说话，日志、配置、名单都适合。

C
#include <stdio.h>
#include <string.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "w");
    if (fp == NULL) {
        perror("notes.txt");
        return 1;
    }
    fputs("第一行\n", fp);
    fputs("第二行\n", fp);
    fclose(fp);

    fp = fopen("notes.txt", "r");
    if (fp == NULL) {
        perror("notes.txt");
        return 1;
    }

    char line[128];
    int no = 1;
    while (fgets(line, sizeof(line), fp) != NULL) {
        size_t len = strlen(line);
        if (len > 0 && line[len - 1] == '\n') {
            line[len - 1] = '\0';
        }
        printf("%d: %s\n", no++, line);
    }
    fclose(fp);
    return 0;
}
运行结果
1: 第一行
2: 第二行

fgets(line, sizeof(line), fp) 的三个参数分别是：往哪存、最多存多少、从哪读。规则有两条：

  • 最多读 n - 1 个字符，最后一个位置留给 '\0'
  • 如果这一行没超过缓冲区，换行符 '\n' 也会被读进来

所以上面的代码要手动把末尾的 \n 去掉，不然 printf("%s\n", line) 会多出一个空行。如果一行比 127 个字符还长，fgets 会分两次读完，解析日志时要注意这一点。

fputs 不会自动补换行。想要每行分开，就在字符串里自己写 \n。另外，gets 这个函数已经被 C 标准删了，别用。

1.5 完整例子：成绩写进去，再读出来#

把前面几块拼起来：先读入若干学生的姓名和成绩，写进 scores.txt；再从文件读回来，打印并统计。

C
#include <stdio.h>

#define FILE_NAME "scores.txt"

int save_scores(void) {
    FILE *fp = fopen(FILE_NAME, "w");
    if (fp == NULL) {
        perror(FILE_NAME);
        return 0;
    }

    int n;
    printf("输入人数：");
    if (scanf("%d", &n) != 1 || n <= 0) {
        printf("人数不合法\n");
        fclose(fp);
        return 0;
    }

    for (int i = 0; i < n; i++) {
        char name[32];
        int score;
        if (scanf("%31s %d", name, &score) != 2) {
            printf("第 %d 条数据有问题\n", i + 1);
            fclose(fp);
            return 0;
        }
        fprintf(fp, "%s %d\n", name, score);
    }

    if (fclose(fp) != 0) {
        perror("fclose");
        return 0;
    }
    return 1;
}

int report(void) {
    FILE *fp = fopen(FILE_NAME, "r");
    if (fp == NULL) {
        perror(FILE_NAME);
        return 0;
    }

    char name[32];
    int score;
    int count = 0, sum = 0;
    int max = 0, min = 0;

    while (fscanf(fp, "%31s %d", name, &score) == 2) {
        printf("%s %d\n", name, score);
        sum += score;
        if (count == 0) {
            max = min = score;
        } else {
            if (score > max) max = score;
            if (score < min) min = score;
        }
        count++;
    }
    fclose(fp);

    if (count == 0) {
        printf("文件里没有有效数据\n");
        return 0;
    }
    printf("人数 %d，平均 %.1f，最高 %d，最低 %d\n",
           count, (double)sum / count, max, min);
    return 1;
}

int main(void) {
    if (!save_scores()) return 1;
    printf("\n--- 从文件读回来 ---\n");
    if (!report()) return 1;
    return 0;
}
运行结果
输入人数：4
张三 85
李四 92
王五 79
赵六 90

--- 从文件读回来 ---
张三 85
李四 92
王五 79
赵六 90
人数 4，平均 86.5，最高 92，最低 79

几个值得看的点：

  • "%31s" 里的 31 是宽度上限，防止输入的名字撑爆 name[32]
  • 写完后检查 fclose 的返回值：缓冲区里的数据在关闭时才真正落盘，关失败说明可能没写全
  • 读的时候用 while (fscanf(...) == 2)，文件读完自然退出，不用先数有多少行
  • max 和 min 在第一条记录时初始化，而不是硬编码成 -1 和 101，这样换成分制、千分制都不会算错

文件里的内容和屏幕上差不多，每行是「姓名 空格 成绩」。用记事本打开 scores.txt 看一眼，是确认「到底写进去没有」最快的方法。

1.6 几个我踩过的坑#

第一，相对路径是相对于运行时的工作目录，不是源文件所在目录。 在 Dev-C++ 里点运行，工作目录通常是项目目录；直接双击 exe，工作目录可能是 exe 所在目录。找不到文件时，先把你以为的路径打印出来，再确认实际路径。

第二，忘了 fclose。 fprintf 写的内容先放在内存缓冲区里，攒够一批或者关闭文件时才写到磁盘。程序正常结束会帮你关闭，但中途崩溃就可能丢。写完立刻关，不要拖到 return 之前。

第三，把 "w" 当成「打开看看」。 它真的会清空。想读用 "r"，想追加用 "a"，想读写同一个文件用 "r+"，而且读到文件尾后要 fseek 回到开头才能写。

第四，文本模式和二进制模式混用。 Windows 下文本模式会把 \n 翻译成 \r\n，读的时候再翻译回来。如果你处理的是图片、压缩包这类二进制数据，打开时加 b："rb"、"wb"，否则文件会被悄悄改坏。

★中文乱码不一定是文件坏了

用记事本打开正常、控制台却是乱码，多半是控制台编码和源文件编码不一致。先确认文件本身能用记事本正常打开，再去查编译器和终端的编码设置。

◆小结
  • fopen 返回 FILE *，失败返回 NULL，打开后第一件事就是检查
  • "w" 打开即清空，"a" 追加，"r" 文件不存在就失败
  • fprintf 和 fscanf 带格式；fscanf 返回成功读到的项数，循环用 == 2 这种判断
  • fgets 最多读 n - 1 个字符并保留换行，fputs 不自动补换行
  • 写完一定 fclose，否则缓冲区里的数据可能没落盘
✎练习
  1. 写一个程序，用 fgets 统计 notes.txt 一共有多少行、多少个字符（包括空格，不包括换行），空行也要算进去。
  2. 把 1.5 节的 scores.txt 读进一个数组，按成绩从高到低排序后写到 sorted.txt。提示：先读满数组，再排序，最后用 fprintf 逐行写。
  3. 用 "a" 模式做一个简易日志：每次运行都往 log.txt 末尾追加一行「第 N 次运行」，N 从上一次的内容里读出来再加一。
  4. 故意把 fopen 的文件名改成 no/such/dir.txt，运行并观察 perror 的输出和退出码；然后把返回值检查去掉，看看程序的行为有什么变化。
