第 2 章 运算

预计 15 分钟·约 3,518 字·C 语言入门

程序光会存数据还不够，还得会算。这一章讲三件事：算术（加减乘除）、比较（谁大谁小）、逻辑（并且、或者、不是）。

2.1 加减乘除#

和小学数学几乎一样，只是乘号要写成 *、除号要写成 /：

运算符号例子结果
加+3 + 25
减-3 - 21
乘*3 * 26
除/6 / 23
取余%7 % 21
C
int a = 7, b = 2;

printf("%d\n", a + b);     // 9
printf("%d\n", a - b);     // 5
printf("%d\n", a * b);     // 14
printf("%d\n", a / b);     // 3  ← 注意不是 3.5
printf("%d\n", a % b);     // 1  ← 7 除以 2 余 1
运行结果
9
5
14
3
1
◆记住这句

两个整数相除，结果还是整数，小数部分直接扔掉（不是四舍五入）。

2.2 整数除法：新手第一大坑#

C
int a = 7, b = 2;

printf("%d\n", a / b);            // 3      整数除法，丢掉小数
printf("%.2f\n", a / b);          // 3.00   仍然是 3，只是显示成小数
printf("%.2f\n", 7.0 / 2);        // 3.50   有一个是小数，就按小数算
printf("%.2f\n", (double)a / b);  // 3.50   强制转换，最稳妥

为什么会这样？因为 C 看到两边都是 int，就按「整数运算」的规则来，结果也只能是整数。想让结果是小数，至少要让其中一个操作数变成小数。

这个坑在算平均分时特别致命：

C
int sum = 250, n = 3;

printf("%d\n", sum / n);            // 83      错！真值是 83.33
printf("%.2f\n", (double)sum / n);  // 83.33   对
★记住这个写法

算平均值一律写 (double)sum / n。(double) 叫强制类型转换，意思是「把 sum 临时当成小数来用」。

2.3 取余 % 的妙用#

% 求的是除法后的余数。它在编程里非常有用，主要有两个场景：

判断奇偶#

C
int n = 7;
if (n % 2 == 0) printf("偶数\n");
else            printf("奇数\n");     // 输出：奇数

拆分数字（秒数转时分秒）#

C
#include <stdio.h>

int main(void) {
    int total = 3661;                 // 一共 3661 秒

    int h = total / 3600;             // 3661 / 3600 = 1 小时
    int m = total % 3600 / 60;        // 剩下 61 秒，61 / 60 = 1 分钟
    int s = total % 60;               // 最后剩 1 秒

    printf("%d 小时 %d 分 %d 秒\n", h, m, s);
    return 0;
}
运行结果
1 小时 1 分 1 秒

这个例子把 / 和 % 配合得非常好：/ 取「整的部分」，% 取「剩下的部分」，一层层剥下去，就能把一个大数拆成需要的格式。

2.4 赋值与复合赋值#

= 在 C 里不是「等于」，而是「把右边的值放进左边」。所以 x = x + 1 完全合理：把 x 原来的值加 1，再存回 x。

C
int x = 10;

x = x + 5;      // 15
x += 5;         // 等价于 x = x + 5，现在 20
x -= 3;         // 等价于 x = x - 3，现在 17
x *= 2;         // 等价于 x = x * 2，现在 34
x /= 2;         // 等价于 x = x / 2，现在 17
x %= 5;         // 等价于 x = x % 5，现在 2

2.5 自增自减#

i++ 就是 i += 1，i-- 就是 i -= 1。它们常出现在循环里（第 3 章就要用）。

C
int i = 5;
printf("%d\n", i++);    // 先输出 5，然后 i 变成 6
printf("%d\n", i);      // 6
printf("%d\n", ++i);    // 先加 1 变成 7，再输出 7
运行结果
5
6
7

i++（后置）和 ++i（前置）单独使用时没有区别，都是加 1。区别只在「同时还要用这个值」的时候——新手先记住：写循环统一用 i++ 就行。

2.6 比较：谁大谁小#

比较的结果只有两种：真（成立）或假（不成立）。C 用 1 表示真，0 表示假。

运算符含义例子结果
>大于5 > 31（真）
<小于5 < 30（假）
>=大于等于5 >= 51
<=小于等于5 <= 30
==等于5 == 51
!=不等于5 != 31
▲= 和 == 是两回事

if (x = 5) 是把 5 赋给 x，然后判断 5 是不是真（永远为真），这个 if 永远成立。判断相等必须写 if (x == 5)。这个错误编译器一般只给警告，查起来非常痛苦。

2.7 逻辑：并且、或者、不是#

运算符读作什么时候为真
&&并且（and）两边都为真才为真
||或者（or）有一个为真就为真
!不是（not）把真变假，把假变真
C
int age = 20;

if (age >= 18 && age <= 30) {
    printf("你是青年\n");        // 两个条件都满足才输出
}

if (age < 18 || age > 60) {
    printf("不在青年范围内\n");  // 满足一个就输出
}

if (!(age >= 18)) {
    printf("未成年\n");
}
★短路求值

a && b 里如果 a 已经是假，C 根本不会去看 b；a || b 里如果 a 已经为真，也不会看 b。这叫短路，可以用它来避免越界，比如 if (i < n && a[i] > 0)——i 越界时右边就不会执行。

2.8 优先级：不确定就加括号#

运算有先后顺序，比如先乘除后加减。完整规则很长，但新手只需要记两件事：

  1. 数学里的规则照旧：先 * / %，后 + -。
  1. 拿不准就加括号。括号不花钱，还能让代码更好读。
C
int a = 2 + 3 * 4;          // 14，不是 20
int b = (2 + 3) * 4;        // 20
int c = 10 - 2 - 3;         // 5，从左往右算
int d = 10 - (2 - 3);       // 11
▲一个容易错的判断

if (a > 0 && b > 0) 是对的。但如果你想写「a 和 b 都大于 0」，不能写成 if (a, b > 0)——逗号表达式的值只看最后一个，前面的 a 被忽略了。

2.9 类型转换#

不同类型混在一起算时，C 会自动往「更精确」的方向转：

C
int    i = 3;
double d = 2.5;

printf("%.2f\n", i + d);      // 5.50，i 自动变成 3.0
printf("%d\n",   (int)d);     // 2，强制转成整数，小数被截断
printf("%d\n",   (int)(i + d)); // 5

隐式转换是 C 自动做的，强制转换是你用 (类型) 明确要求的。算平均值、算比例时，强制转换是你的救命稻草。

2.10 小结与一个综合例子#

  • / 两边都是整数时，结果也是整数，小数被丢掉。
  • % 求余数，常用来判断奇偶、拆分数字。
  • = 是赋值，== 才是判断相等。
  • && 并且、|| 或者、! 取反。
  • 拿不准优先级就加括号。
C
#include <stdio.h>

int main(void) {
    double weight, height, bmi;

    printf("请输入体重(kg)和身高(m): ");
    scanf("%lf %lf", &weight, &height);

    bmi = weight / (height * height);

    printf("你的 BMI 是 %.1f\n", bmi);
    return 0;
}
运行结果
请输入体重(kg)和身高(m): 65 1.75
你的 BMI 是 21.2

练习#

2-1 四则运算

读入两个整数，依次输出它们的和、差、积、商、余数。

提示：商和余数分别用 / 和 %。

2-2 判断奇偶

读入一个整数，输出它是奇数还是偶数。

提示：用 n % 2 == 0 判断。

2-3 时间换算

读入一个秒数，输出「几小时几分几秒」。

提示：照抄 2.3 节的例子，把 3661 换成输入值。

2-4 三位数反转

读入一个三位数（比如 123），输出反转后的数（321）。

提示：用 / 和 % 分别取出百位、十位、个位。

2-5 成绩等级

读入一个百分制成绩，输出对应等级：90 以上 A，80~89 B，70~79 C，60~69 D，60 以下 E。

提示：用 if / else if 链，注意边界。
