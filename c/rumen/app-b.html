附录 B 20 个新手最常犯的错误

预计 10 分钟·约 839 字·C 语言入门

下面每一条都是真实高频的错误。写代码前扫一眼，能省很多时间。

#错误写法正确写法原因
1for (i=0; i<=n; i++)i < n数组下标最大是 n-1，越界
2if (x = 5)if (x == 5)= 是赋值，== 才是判断
3scanf("%d", n);scanf("%d", &n);漏了 &
4int a[n];（n 是变量）#define N 100长度必须是常量
5int a[5]; 直接用int a[5] = {0};局部数组是垃圾值
6printf("%d", 3.14);printf("%f", 3.14);格式符和类型不匹配
7printf("%f", 3.14); 读 int用 %d同上，尤其是 scanf
8scanf("%f", &d);（double）scanf("%lf", &d);double 必须用 %lf
9sum / n 求平均(double)sum / n整数除法丢掉小数
10if (str1 == str2)strcmp(str1, str2) == 0== 比的是地址
11s.name = "张三";strcpy(s.name, "张三");数组不能整体赋值
12for 或 if 后面加分号if (x) { ... }if(x); 后面那句永远执行
13switch 的 case 忘 break每个 case 后加 break会继续往下执行
14int *p; *p = 5;int *p = &a;野指针
15free(p); 之后还用 pfree(p); p = NULL;释放后使用
16函数返回局部数组用 static 或 malloc函数结束内存就没了
17char c = "A";char c = 'A';字符用单引号
18中文标点；;全角符号编译报错
19while (i < 10) 里忘了 i++记得更新循环变量死循环
20数组长度写太小按实际需求留余量输入超了会溢出
