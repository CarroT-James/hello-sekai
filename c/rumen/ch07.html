第 7 章 结构体

预计 10 分钟·约 2,590 字·C 语言入门

7.1 为什么需要结构体#

假设要记录一个学生：学号（整数）、姓名（字符串）、成绩（小数）。用三个变量表示还行，但如果有 50 个学生呢？

C
int    ids[50];
char   names[50][20];
double scores[50];

// 按成绩排序时，三个数组必须同步搬移
// 一旦漏搬一个，数据就全错位了

结构体把这三个字段捆成一个整体：一个学生就是一个变量，排序时整体一起动。

◆记住这句

结构体 = 自己定义的一种新类型，把几个不同类型的数据打包在一起。

7.2 定义与使用#

C
#include <stdio.h>

struct Student {          // 定义一种新类型，叫 struct Student
    int    id;            // 学号
    char   name[20];      // 姓名
    double score;         // 成绩
};                        // 这个分号不能丢！

int main(void) {
    struct Student s = {1001, "张三", 92.5};   // 声明并初始化

    printf("学号: %d\n", s.id);        // 用 . 访问成员
    printf("姓名: %s\n", s.name);
    printf("成绩: %.1f\n", s.score);

    return 0;
}
运行结果
学号: 1001
姓名: 张三
成绩: 92.5
▲三个容易错的地方

① 定义末尾的 ; 不能丢；② 字符串成员赋值要用 strcpy(s.name, "张三")，不能写 s.name = "张三"；③ 在 C 里类型名要写全 struct Student，除非用 typedef（7.6 节）。

7.3 点号 . 和箭头 ->#

访问成员有两种写法，取决于你手里是结构体本身还是它的指针：

C
struct Student s = {1001, "张三", 92.5};
struct Student *p = &s;

printf("%s\n", s.name);       // 结构体变量用 .
printf("%s\n", p->name);      // 结构体指针用 ->
printf("%s\n", (*p).name);    // 等价于上面那行
手里是什么用什么例子
结构体变量.s.id
结构体指针->p->id
结构体数组的元素.list[i].id

7.4 结构体数组#

这是最常用的组合：一个数组，每个元素是一条完整记录。

C
#include <stdio.h>

struct Student {
    int    id;
    char   name[20];
    double score;
};

int main(void) {
    struct Student list[3] = {
        {1001, "张三", 92.5},
        {1002, "李四", 78.0},
        {1003, "王五", 85.5}
    };

    for (int i = 0; i < 3; i++) {
        printf("%d  %s  %.1f\n", list[i].id, list[i].name, list[i].score);
    }
    return 0;
}
运行结果
1001  张三  92.5
1002  李四  78.0
1003  王五  85.5

7.5 结构体作函数参数#

两种传法，区别和普通变量一样：

C
// 传值：复制整个结构体（成员多时开销大）
void print_student(struct Student s) {
    printf("%d %s %.1f\n", s.id, s.name, s.score);
}

// 传指针：只传地址，快，而且能修改原数据
void add_score(struct Student *p, double delta) {
    p->score += delta;
}

实际写代码时，结构体一般传指针，不想被改就加 const：

C
void print_student(const struct Student *p) {
    printf("%d %s %.1f\n", p->id, p->name, p->score);
}

// 调用
print_student(&list[i]);

7.6 typedef：起个短名字#

每次都写 struct Student 太啰嗦。用 typedef 起个别名：

C
typedef struct Student {
    int    id;
    char   name[20];
    double score;
} Student;                  // 以后 Student 就等于 struct Student

Student s;                  // 不用再写 struct
Student list[30];

这是实际项目里的标准写法，建议从一开始就这么写。

7.7 选学：链表是什么#

结构体里可以放一个指向自己这种类型的指针，这样就能把一个个结构体串起来，形成「链表」：

C
struct Node {
    int          data;      // 存数据
    struct Node *next;      // 指向下一个结点
};

//   [1] -> [2] -> [3] -> NULL

为什么必须用指针？如果写 struct Node next;，这个结构体就包含它自己，大小无限递归，编译器算不出来。指针大小固定，所以没问题。

链表的完整操作（插入、删除、遍历）第 8 章会讲。这里先知道它的长相就够了。

7.8 本章小结#

  • 结构体把不同类型的数据打包成一个整体。
  • 定义完别忘了末尾的分号。
  • 访问成员：变量用 .，指针用 ->。
  • 结构体数组 = 一张表，每个元素是一条记录。
  • 传参优先传指针，只读就加 const。
  • 用 typedef 可以省掉 struct 关键字。

提示：字符串用双引号初始化即可。

提示：定义和遍历都跟普通数组一样，只是元素是结构体。

提示：冒泡排序，交换时整体交换结构体。

读入学号，输出对应的学生信息，找不到就提示。
