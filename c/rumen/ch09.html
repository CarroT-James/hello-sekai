第 9 章 综合实战

预计 10 分钟·约 2,641 字·C 语言入门

这一章不教新知识，只用前面学过的东西做两个完整的程序。能独立写出这两个，你就真的入门了。

9.1 项目一：猜数字游戏#

程序随机想一个 1~100 的数，你反复猜，它告诉你大了还是小了，直到猜对。

C
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));                  // 用当前时间做随机种子
    int target = rand() % 100 + 1;      // 1~100 的随机数
    int guess, count = 0;

    printf("我想了一个 1 到 100 的数，你猜猜看\n");

    do {
        printf("请输入你的猜测: ");
        scanf("%d", &guess);
        count++;

        if (guess > target) {
            printf("大了\n");
        } else if (guess < target) {
            printf("小了\n");
        }
    } while (guess != target);

    printf("猜对了！你一共猜了 %d 次\n", count);
    return 0;
}
运行结果
我想了一个 1 到 100 的数，你猜猜看
请输入你的猜测: 50
大了
请输入你的猜测: 25
小了
请输入你的猜测: 37
猜对了！你一共猜了 3 次

涉及的知识点：随机数、do-while、if-else、计数器。

▲每次运行都是同一个数？

如果没写 srand(time(NULL))，每次运行 rand() 都会给出同一串数。srand 用时间当种子，每次运行就不同了。记得 #include <time.h>。

9.2 项目二：学生成绩管理#

读入若干个学生的学号、姓名、成绩，然后求平均分、按成绩排序、按学号查找。这个程序几乎用到了前面所有的知识。

C
#include <stdio.h>
#include <string.h>

#define MAXN 100

typedef struct {
    int    id;
    char   name[20];
    double score;
} Student;

/* 求平均分 */
double average(Student a[], int n) {
    double sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i].score;
    }
    return sum / n;
}

/* 冒泡排序：按成绩从高到低 */
void sort_by_score(Student a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j].score < a[j + 1].score) {
                Student t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
}

/* 按学号查找，返回下标，找不到返回 -1 */
int find_by_id(Student a[], int n, int id) {
    for (int i = 0; i < n; i++) {
        if (a[i].id == id) return i;
    }
    return -1;
}

int main(void) {
    Student list[MAXN];
    int n;

    printf("请输入学生人数: ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        printf("第 %d 个（学号 姓名 成绩）: ", i + 1);
        scanf("%d %s %lf", &list[i].id, list[i].name, &list[i].score);
    }

    printf("\n平均分: %.2f\n", average(list, n));

    sort_by_score(list, n);
    printf("\n按成绩从高到低:\n");
    for (int i = 0; i < n; i++) {
        printf("%d  %s  %.1f\n", list[i].id, list[i].name, list[i].score);
    }

    int id;
    printf("\n输入要查找的学号: ");
    scanf("%d", &id);

    int idx = find_by_id(list, n, id);
    if (idx >= 0) {
        printf("找到: %d %s %.1f\n", list[idx].id, list[idx].name, list[idx].score);
    } else {
        printf("没有找到学号为 %d 的学生\n", id);
    }

    return 0;
}

9.3 程序不对怎么办#

写完程序，十有八九第一次跑不对。别急，按下面四步排查：

  1. 先看报错。编译错误看第一条，行号常常指向上一条语句。
  1. printf 大法。在可疑的地方打印变量值，看看它到底是多少。这是最有效的调试手段。
  1. 缩小范围。把代码注释掉一半，看问题还在不在，逐步锁定出错的那几行。
  1. 说给人听。把代码一行行念出来，很多错误在念的过程中就自己发现了（叫橡皮鸭调试法）。

// 怀疑哪里，就在哪里打印

9.4 学完这本之后#

你已经掌握了 C 语言的主干。接下来可以按兴趣选方向：

  • 想深入 C：文件读写（把数据存到 txt）、位运算、多文件工程、Makefile。
  • 想学数据结构：链表进阶、二叉树、哈希表、图。C 是学这些最好的语言。
  • 想快速做东西：转 Python，你会发现很多概念是相通的，写起来轻松很多。
  • 想做嵌入式/单片机：C 是唯一的选择，指针和位操作会天天用到。
