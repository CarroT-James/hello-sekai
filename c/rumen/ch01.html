第 1 章 基本元素

预计 15 分钟·约 3,237 字·C 语言入门

这一章讲四样东西：怎么存数据（变量）、存什么类型（int/double/char）、怎么显示出来（printf）、怎么让用户输入（scanf）。学完这一章，你就能写「输入两个数，输出和」这种程序了。

1.1 变量：给数据起个名字#

想象一排带标签的盒子。你在盒子里放一个数字，贴上标签 age，以后想用这个数字，喊 age 就行了。

C
int age = 18;

这一行做了三件事：

  • int —— 说明这个盒子里装的是整数；
  • age —— 给盒子起名，以后用它来取东西；
  • = 18 —— 把 18 放进去（注意：这是「赋值」，不是数学里的「等于」）。
C
#include <stdio.h>

int main(void) {
    int age = 18;
    printf("我今年 %d 岁\n", age);

    age = 19;                       // 把盒子里的东西换成 19
    printf("明年我 %d 岁\n", age);

    return 0;
}
运行结果
我今年 18 岁
明年我 19 岁

注意 printf 里那个 %d：它是个「占位符」，表示「这里要放一个整数」，真正放什么由后面的 age 决定。printf 会按顺序把参数填进去。

1.2 三个最常用的类型#

盒子有大有小，装不同的东西要用不同的盒子。刚开始你只需要记三个：

类型装什么例子占几个字节
int整数（没有小数点）18、-5、10004
double小数3.14、-0.5、99.98
char单个字符'A'、'7'、'+'1
C
int    count = 10;        // 整数
double price = 9.9;       // 小数
char   grade = 'A';       // 单个字符，用单引号

printf("%d\n", count);
printf("%.1f\n", price);
printf("%c\n", grade);
运行结果
10
9.9
A
▲两个高频错误

① 字符用单引号 'A'，字符串用双引号 "A"，别搞混；② 给 int 赋小数会被截断：int x = 3.9; 之后 x 是 3，不是 4。

★sizeof 是什么

想知道一个类型占几个字节，写 printf("%d", (int)sizeof(int)); 就会输出 4。现在不用深究，只要知道 int 是 4 字节、double 是 8 字节就够了。

1.3 起名字的规矩#

变量名随便起，但要守三条规矩：

  1. 只能用字母、数字、下划线，不能有空格和中文。
  1. 不能以数字开头。2name 是错的，name2 可以。
  1. 不能和关键字重名。int、return、if、for 这些词是留给语言本身的。

另外强烈建议：名字要有意义。a、b、c 过两天你自己都看不懂，age、score、total 一眼就明白。

写法对不对原因
my_age对下划线连接，清晰
myAge对驼峰命名，也很常用
2age错数字开头
my age错有空格
int错是关键字

1.4 输出：printf#

printf 是你用得最多的函数。它的本事就是「把东西显示到屏幕上」。

核心是记住格式符——不同的类型要用不同的占位符：

格式符用于例子输出
%dint 整数printf("%d", 42);42
%fdouble 小数printf("%f", 3.14);3.140000
%.2f保留两位小数printf("%.2f", 3.14159);3.14
%c单个字符printf("%c", 'A');A
%s字符串printf("%s", "你好");你好
%%输出一个百分号printf("50%%");50%

几个常用技巧：

C
printf("%d\n", 42);                  // 简单输出
printf("a = %d, b = %d\n", 3, 5);    // 一次输出多个
printf("%.3f\n", 3.1415926);         // 保留 3 位小数
printf("%5d|\n", 42);                // 占 5 格，右对齐 → "   42|"
printf("%-5d|\n", 42);               // 占 5 格，左对齐 → "42   |"

%f 默认输出 6 位小数，所以想好看一点一定要用 %.2f 这种写法指定位数。

1.5 输入：scanf#

scanf 让用户从键盘输入数据。它和 printf 长得很像，但多了一个 & 符号：

C
#include <stdio.h>

int main(void) {
    int age;

    printf("请输入你的年龄: ");
    scanf("%d", &age);              // 注意这个 &

    printf("你明年 %d 岁\n", age + 1);
    return 0;
}
运行结果
请输入你的年龄: 18
你明年 19 岁
▲& 千万不能漏

写 scanf("%d", age); 会直接崩溃。& 的意思是「把这个变量的地址给 scanf，让它知道往哪儿存」。为什么需要地址，第 6 章讲指针时会彻底明白——现在先记住：scanf 里每个变量前面都要加 &。

输入小数和字符时，格式符要对应：

C
int    n;
double x;
char   c;

scanf("%d", &n);        // 整数
scanf("%lf", &x);       // 小数：注意是 %lf，不是 %f
scanf(" %c", &c);       // 字符：前面加个空格，跳过上次留下的换行
★为什么 double 用 %lf

printf 输出 double 用 %f 就行，但 scanf 读入 double 必须用 %lf。这是 C 语言的历史遗留问题，记下来就好，不用问为什么。

1.6 常量：不会变的值#

有些值在程序里从头到尾都不该变，比如圆周率。这时候用常量，防止自己手滑改掉：

C
#define PI 3.14159          // 方式一：宏定义，写在 #include 下面

int main(void) {
    const double E = 2.718; // 方式二：const 常量
    // E = 3.0;             // 这行会报错，const 不允许修改
    return 0;
}

两种都行，新手建议先用 #define，因为写法简单。注意 #define 后面没有分号。

1.7 注释：给人看的话#

注释不会被执行，只是写给未来的自己（和队友）看的：

C
// 这是单行注释，从 // 到行尾都不算代码

/*
   这是多行注释
   可以写好几行
*/

int score = 90;   // 也可以在代码后面加注释

养成习惯：每写一段稍微复杂的东西，就加一句注释说明它在干什么。两周后你回来看自己的代码，会感谢现在的自己。

1.8 本章小结#

  • 变量是贴了标签的盒子，int a = 5; 就是「盒子 a 里放 5」。
  • 三个基本类型：int 整数、double 小数、char 单个字符。
  • 输出用 printf，记住 %d %f %c %s 四个占位符。
  • 输入用 scanf，变量前必须加 &。
  • 每条语句以分号结尾，所有标点用英文。

练习#

1-1 自我介绍

写一个程序，用 printf 输出三行：你的名字、年龄、专业。

提示：就是三个 printf，每条后面加分号。

1-2 两个数的和

读入两个整数，输出它们的和。

提示：scanf("%d %d", &a, &b); 可以一次读两个。

1-3 圆的面积

读入半径 r，输出圆的面积，保留两位小数。

提示：面积 = 3.14159 × r × r，用 %.2f 输出。

1-4 交换两个数

读入两个整数 a、b，交换它们的值后输出。

提示：需要一个临时变量 t：t=a; a=b; b=t;

1-5 温度转换

读入一个摄氏温度，输出对应的华氏温度（F = C × 9 / 5 + 32）。

提示：注意 9/5 在整数除法里是 1，要写成 9.0/5。
