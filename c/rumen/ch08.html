第 8 章 数据结构与算法入门

预计 20 分钟·约 3,494 字·C 语言入门

「算法」这个词听起来很高深，其实就是解决问题的步骤。比如在一堆数里找一个数，你可以一个一个看，也可以先排序再折半找——这两种不同的步骤，就是两种算法。

「数据结构」则是数据怎么摆放。同样一堆数，排成一排叫数组，用链子串起来叫链表，摆放方式不同，能用的算法和效率也不同。

8.1 怎么比较算法的好坏#

最直观的标准是：数据变多时，运行时间增长得快不快。我们用「大 O 记法」粗略表示，你只要看懂下面这张表就够了：

记法读作什么感觉典型例子
O(1)常数时间一步到位，数据多少都一样快数组按下标取值 a[i]
O(n)线性时间数据翻倍，时间翻倍从头到尾扫一遍
O(n²)平方时间数据翻倍，时间变四倍冒泡排序
O(log n)对数时间数据翻倍，只多一步二分查找

举个例子：在 100 万个数里找一个数，顺序查找最坏要看 100 万次，二分查找最多看 20 次。这就是算法的差距。

8.2 顺序查找：一个一个看#

C
int find(int a[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (a[i] == target) {
            return i;           // 找到，返回下标
        }
    }
    return -1;                  // 没找到，返回 -1
}

最简单，也不要求数组有序。数据量小的时候完全够用。

8.3 二分查找：每次砍掉一半#

像猜数字游戏：你说 50，我说「大了」，你就知道答案在 1~49 之间，一次砍掉一半。

但前提是数组必须已经排好序，否则「大了」这个判断就没有意义。

C
int binary_search(int a[], int n, int target) {
    int lo = 0;
    int hi = n - 1;

    while (lo <= hi) {
        int mid = (lo + hi) / 2;

        if (a[mid] == target) {
            return mid;
        } else if (a[mid] < target) {
            lo = mid + 1;           // 去右半边找
        } else {
            hi = mid - 1;           // 去左半边找
        }
    }
    return -1;
}

四个细节决定了它能不能跑对：

细节正确写法写错的后果
循环条件lo <= hi写 lo < hi 会漏掉最后一个元素
找中点(lo + hi) / 2超大数组可能溢出，严谨写法是 lo + (hi-lo)/2
左边界lo = mid + 1写成 lo = mid 会死循环
右边界hi = mid - 1写成 hi = mid 会死循环

8.4 冒泡排序#

相邻两个比较，前面的大就交换。每一轮结束，最大的会「冒」到最后面。

C
void bubble_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
}

手动走一遍 {5, 3, 1}：

C
初始:  5  3  1
第1轮: 5>3 交换 → 3  5  1
       5>1 交换 → 3  1  5     ← 最大的 5 到位了
第2轮: 3>1 交换 → 1  3  5     ← 完成
★为什么内层是 n-1-i

每跑完一轮，末尾就多一个已经排好的元素，不用再比。所以内层循环的次数逐轮减少。

8.5 选择排序#

每一轮从未排序的部分里挑出最小的，放到前面。特点是交换次数少。

C
void selection_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;                    // 假设 i 是最小的
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[min]) {
                min = j;                // 找到更小的就记下来
            }
        }
        if (min != i) {                 // 交换
            int t = a[i];
            a[i] = a[min];
            a[min] = t;
        }
    }
}

8.6 插入排序#

像打扑克摸牌：摸到新牌，插到手里已经排好的牌中间。

C
void insertion_sort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];                 // 摸到的牌
        int j = i - 1;
        while (j >= 0 && a[j] > key) {  // 比它大的都往后挪
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;                 // 插进空位
    }
}

数据本来就接近有序时，插入排序非常快，实际项目里经常用。

8.7 三种排序怎么选#

算法平均时间容易写错的地方什么时候用
冒泡排序O(n²)内层边界 n-1-i练手、数据量小
选择排序O(n²)忘记判断 min != i交换代价高时
插入排序O(n²)while 里 j >= 0 要写在前面数据接近有序

实际开发中，直接用标准库的 qsort 就好，不用自己写：

C
#include <stdlib.h>

int cmp(const void *p, const void *q) {
    int a = *(const int *)p;
    int b = *(const int *)q;
    return (a > b) - (a < b);       // 返回正数表示 a 排在后面
}

int main(void) {
    int a[5] = {5, 2, 9, 1, 7};
    qsort(a, 5, sizeof(a[0]), cmp); // 数组, 个数, 单元素大小, 比较函数
    return 0;
}

8.8 链表：用指针串起来的队伍#

数组的格子是连续摆放的，长度固定。链表的每个结点可以散落在内存各处，用指针连起来，想加就加，想删就删。

C
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int          data;
    struct Node *next;
};

int main(void) {
    struct Node *head = NULL;

    // 头插法：依次插入 3、2、1，得到 1 -> 2 -> 3
    for (int i = 3; i >= 1; i--) {
        struct Node *p = malloc(sizeof(struct Node));
        p->data = i;
        p->next = head;
        head = p;
    }

    // 遍历
    for (struct Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->data);
    }
    printf("\n");

    // 释放：先记住下一个，再释放当前
    struct Node *p = head;
    while (p != NULL) {
        struct Node *next = p->next;
        free(p);
        p = next;
    }
    return 0;
}
运行结果
1 2 3
▲释放链表必须先保存 next

如果写 free(p); p = p->next;，你在 free 之后又去读 p->next——那块内存已经不属于你了。一定要先把 next 存到临时变量里。

8.9 栈和队列：两种特殊的「容器」#

这两个名字和数据结构，其实就是两种存取规则：

名字规则生活里的例子
栈 stack后进先出（最后放的先拿）一摞盘子、浏览器的后退
队列 queue先进先出（先排队的先走）食堂打饭、打印机任务

用数组实现一个栈非常简单，只需要一个「栈顶指针」：

C
int stack[100];
int top = 0;                    // top 指向下一个空位

// 入栈
stack[top++] = 42;

// 出栈
if (top > 0) {
    int x = stack[--top];
    printf("%d\n", x);
}

队列则需要两个指针：一个记住队头，一个记住队尾。思路是一样的，只是取数据的方向不同。

8.10 本章小结#

  • 算法 = 解决问题的步骤，用大 O 粗略衡量快慢。
  • 顺序查找 O(n)，二分查找 O(log n)，但二分要求数组有序。
  • 冒泡、选择、插入都是 O(n²)，练手用；实战用 qsort。
  • 链表适合频繁插入删除，数组适合频繁随机访问。
  • 栈后进先出，队列先进先出。
