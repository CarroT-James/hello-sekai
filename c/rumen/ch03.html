第 3 章 流程控制

预计 15 分钟·约 3,626 字·C 语言入门

到目前为止，程序都是一行一行从头执行到尾。但真实的需求往往需要做选择（如果……就……）和重复做（做 100 遍）。这一章讲的就是这两件事。

3.1 顺序执行#

默认情况下，程序从上往下一条条执行，这叫顺序结构。这是最基本，也是你已经在用的。

3.2 if：满足条件才做#

C
int score = 85;

if (score >= 60) {
    printf("及格了\n");
}

读法：如果 score 大于等于 60，就执行花括号里的语句；否则跳过。

流程图长这样：

C
        ┌─────────────┐
        │ score >= 60 ?│
        └──────┬──────┘
         真 ┌──┴──┐ 假
            ▼     ▼
        ┌───────┐ ┌─────┐
        │ 打印   │ │ 跳过 │
        └───────┘ └─────┘

3.3 if-else：二选一#

C
int score;
scanf("%d", &score);

if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}

注意 else 后面没有条件，它就是「否则」。而且 else 总是和最近的、还没配对的 if 配对。

3.4 else if：多选一#

C
int score;
scanf("%d", &score);

if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");
} else if (score >= 70) {
    printf("C\n");
} else if (score >= 60) {
    printf("D\n");
} else {
    printf("E\n");
}

这一串是从上往下依次判断，一旦有一个成立，后面的全部跳过。所以顺序很重要：如果你把 score >= 60 写在最前面，那么 95 分也会被判定成 E——因为它先满足了 60 这个条件。

▲顺序写反的经典错误

判断区间一定要从大到小（或从小到大）排列。上面这段如果写成 >= 60 在最前面，所有及格的人都会得到 D。

3.5 嵌套 if#

if 里面还可以再套 if，用来处理「在某个前提下再细分」的情况：

C
int age = 20;
int has_ticket = 1;

if (age >= 18) {
    if (has_ticket) {
        printf("可以入场\n");
    } else {
        printf("请先买票\n");
    }
} else {
    printf("未成年不能入场\n");
}

嵌套太深会很难读，一般超过三层就该考虑换写法（比如用 && 合并条件，或者拆成函数）。

3.6 条件运算符 ? :#

简单的二选一可以写成一行，格式是 条件 ? 真时的值 : 假时的值：

C
int a = 10, b = 20;

int max = (a > b) ? a : b;
printf("%d\n", max);                 // 20

printf("%s\n", (a % 2 == 0) ? "偶数" : "奇数");   // 偶数

它不是必须的，用 if-else 一样能写。但赋值时用它会简洁很多，看到别人写也别奇怪。

3.7 switch：多分支的另一种写法#

当你要判断的是「等于某几个固定值」时，switch 比一串 else if 更清晰：

C
int day;
scanf("%d", &day);

switch (day) {
    case 1:
        printf("周一\n");
        break;
    case 2:
        printf("周二\n");
        break;
    case 3:
        printf("周三\n");
        break;
    default:
        printf("其他\n");
        break;
}
▲break 不能忘

每个 case 后面都要加 break;，否则程序会「继续往下执行」——这叫 case 穿透。比如 case 1 少了 break，输入 1 会连续输出「周一」「周二」。这是新手最常犯的错之一。

default 是「以上都不匹配时」执行的，可以放在最后，也可以不写。

3.8 while：条件成立就一直做#

C
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;                    // 千万别忘！否则死循环
}
printf("\n");
运行结果
1 2 3 4 5

while 的执行逻辑：先判断条件，成立就执行一次，再判断，直到条件不成立为止。

▲死循环

如果循环体里没有任何让条件变假的操作，循环就永远不会停，程序卡死。上面那段如果删掉 i++，就会无限打印 1。按 Ctrl+C 可以强行中断。

3.9 for：最常用的循环#

for 把「初始化、条件、更新」三件事写在一行里，是遍历最常用的写法：

C
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
运行结果
1 2 3 4 5

三个部分的含义：

位置写什么说明
第一个int i = 1初始化，只执行一次
第二个i <= 5条件，每轮开始前判断
第三个i++每轮结束后执行

执行顺序是：初始化 → 判断 → 循环体 → 更新 → 判断 → 循环体 → ……

C
// 求 1 到 100 的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
printf("%d\n", sum);       // 5050
◆记住这句

for 括号里的三段用分号隔开，不是逗号。写成逗号会编译报错。

3.10 do-while：先做一次再判断#

while 是先判断后执行，do-while 是先执行一次，再判断要不要继续。适合「至少要问一次」的场景：

C
int n;
do {
    printf("请输入一个正数: ");
    scanf("%d", &n);
} while (n <= 0);
printf("你输入的是 %d\n", n);
运行结果
请输入一个正数: -3
请输入一个正数: 0
请输入一个正数: 5
你输入的是 5

注意 do-while 的结尾有个分号：} while (...);，别漏。

3.11 break 和 continue#

关键字作用打比方
break立刻跳出整个循环不跑了，直接出门
continue跳过本轮剩下的，进入下一轮这圈不算，下一圈继续
C
// break：找到 5 就停
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    printf("%d ", i);
}
printf("\n");              // 输出：1 2 3 4

// continue：跳过偶数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;
    printf("%d ", i);
}
printf("\n");              // 输出：1 3 5 7 9

3.12 嵌套循环：打印图形#

循环里面套循环，最经典的用途就是打印二维图形：

C
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 5; i++) {      // 控制行数
        for (int j = 1; j <= i; j++) {  // 每行打印 i 个星号
            printf("*");
        }
        printf("\n");                   // 一行打完换行
    }
    return 0;
}
运行结果
*
**
***
****
*****

理解嵌套循环的关键：外层循环走一步，内层循环要跑完一整圈。就像时钟：时针走一格（外层），分针要转一圈（内层）。

再试一个九九乘法表，你会发现只是换个输出内容：

C
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%-3d", j, i, i * j);
    }
    printf("\n");
}

3.13 本章小结#

  • 单分支用 if，二选一用 if-else，多选一用 else if 链（注意顺序）。
  • 判断固定值用 switch，每个 case 都要 break。
  • 知道次数用 for，不知道次数用 while，至少要执行一次用 do-while。
  • break 跳出整个循环，continue 跳过本轮。
  • 嵌套循环：外层走一步，内层跑一圈。

练习#

3-1 判断闰年

读入一个年份，判断是不是闰年（能被 4 整除且不能被 100 整除，或能被 400 整除）。

提示：条件写成 (y%4==0 && y%100!=0) || y%400==0。

3-2 三个数排序

读入三个整数，按从小到大的顺序输出。

提示：两两比较交换，或者用 if 穷举六种情况。

3-3 求和

求 1 到 n 的和，n 由用户输入。

提示：for 循环从 1 到 n，累加到 sum。

3-4 猜数字

程序固定一个数（比如 42），让用户反复输入直到猜对，每次提示「大了」或「小了」。

提示：while 循环 + if-else + break。

3-5 打印金字塔

读入行数 n，打印一个由星号组成的金字塔。

提示：第 i 行先打印 n-i 个空格，再打印 2i-1 个星号。
