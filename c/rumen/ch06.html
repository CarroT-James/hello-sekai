第 6 章 指针

预计 15 分钟·约 3,395 字·C 语言入门

指针是 C 语言里最出名、也最吓人的东西。但它的核心其实只有一个想法：变量住在内存里，每个变量都有地址；指针就是用来存地址的变量。

跟着下面的比喻走，你会发现它没那么难。

6.1 变量都有「门牌号」#

把内存想象成一条街，街上有无数个房间。每个房间有个门牌号（地址），房间里住着一个值。

C
int a = 42;

这句话的意思是：申请一个房间，门牌号是 0x100（假设），里面住着 42，给这个房间起名叫 a。

C
        ┌──────────────┐
        │   房间 0x100  │
        │   ┌───────┐  │
        │   │  42   │  │   ← a 的值
        │   └───────┘  │
        └──────────────┘
              ↑
         a 住在这里，门牌号是 0x100

平时我们说 a，说的是房间里的东西（42）。用 &a 就能拿到门牌号：

C
int a = 42;
printf("a 的值是 %d\n", a);            // 42
printf("a 的地址是 %p\n", (void *)&a); // 0x7ffd... 之类的

& 读作「取地址」。&a 就是「a 的门牌号」。

6.2 指针：写着门牌号的纸条#

指针就是一个专门存门牌号的变量：

C
int a = 42;
int *p = &a;        // p 里存的是 a 的地址

printf("%d\n", *p); // 42    ← * 的意思是「去这个地址看看」
*p = 100;           // 通过地址修改房间里的东西
printf("%d\n", a);  // 100   ← a 跟着变了
运行结果
42
100
C
      变量 a                    指针 p
   ┌───────────┐          ┌────────────┐
   │    100    │  ←─────  │   0x100    │
   └───────────┘          └────────────┘
     地址 0x100              地址 0x200

   p 里存着 a 的门牌号。*p 就是"按门牌号 0x100 找过去"。
★两个符号，两个意思

& 是「取地址」（我要门牌号），* 是「解引用」（按门牌号找过去）。p = &a; 是把 a 的门牌号写进 p；*p 是顺着 p 里的门牌号找到那个房间。

定义指针时的 * 和用指针时的 * 长得一样，但意思不同：

C
int *p;        // 这里的 * 是类型的一部分：p 是「指向 int 的指针」
int x = *p;    // 这里的 * 是运算符：取出 p 指向的值

6.3 用指针给函数「传地址」#

还记得第 4 章那个问题吗？函数拿到的是参数的复印件，改不到原变量。指针可以解决它——不传复印件，直接传门牌号。

C
#include <stdio.h>

void swap(int *a, int *b) {     // 收到的不是值，是地址
    int t = *a;                 // 按地址取出第一个房间的值
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 1, y = 2;

    swap(&x, &y);               // 把 x 和 y 的地址传进去
    printf("%d %d\n", x, y);    // 2 1

    return 0;
}
运行结果
2 1

对照一下错误版本，就明白区别了：

C
void swap_wrong(int a, int b) {  // 收到的是复印件
    int t = a;
    a = b;
    b = t;                       // 换的是复印件，原件没动
}
◆记住这句

想让函数修改你的变量，就把变量的地址（&）传给它，函数用指针（*）去改。

6.4 指针和数组的关系#

这是指针最重要的应用。数组名，其实就是首元素的地址。

C
int a[5] = {10, 20, 30, 40, 50};
int *p = a;                 // 等价于 int *p = &a[0];

printf("%d\n", *p);         // 10
printf("%d\n", *(p + 1));   // 20
printf("%d\n", *(p + 2));   // 30

p + 1 不是「地址加 1 个字节」，而是「跳到下一个 int」，也就是往后 4 个字节。指针加 1，跳过一个元素。

C
p ──► [10] [20] [30] [40] [50]
       ↑
      p+0  p+1  p+2  p+3  p+4

所以数组的下标访问，本质就是指针运算：

C
a[i]   完全等价于   *(a + i)

a[0] = *(a + 0)
a[1] = *(a + 1)
a[2] = *(a + 2)
★为什么下标从 0 开始

因为第一个元素就是「距离首地址偏移 0 个元素」。这样 a[0] 对应 *(a+0)，最自然。

用指针遍历数组：

C
int a[5] = {10, 20, 30, 40, 50};

for (int *p = a; p < a + 5; p++) {
    printf("%d ", *p);
}
运行结果
10 20 30 40 50

平时写代码，能用下标就用下标（a[i] 更好读）。指针遍历知道就行，看别人代码时不至于懵。

6.5 指针和字符串#

有两种方式写字符串，它们在内存里完全不同：

C
char s[] = "hello";     // 字符数组：在栈上复制了一份，可以改
char *p  = "hello";     // 字符指针：指向只读区的常量，不能改
C
char s[] = "hello";
s[0] = 'H';             // 可以，变成 Hello

char *p = "hello";
// p[0] = 'H';          // 不行！字符串常量是只读的，改了会崩溃
▲记住这条

char *p = "..." 定义的字符串不能修改。要修改就用字符数组 char s[] = "..."。

6.6 两个必须避免的坑#

野指针：指针没指向任何地方#

C
int *p;         // 野指针！里面是垃圾值，指向一个随机地址
*p = 10;        // 危险：往随机地址写数据，可能直接崩溃

规范做法：定义时就初始化，不知道指哪就先赋 NULL（空指针，表示「不指向任何地方」）：

C
int *p = NULL;

if (p != NULL) {    // 用之前先检查
    *p = 10;
}

解引用 NULL#

C
int *p = NULL;
printf("%d\n", *p);    // 段错误，程序直接挂

对 NULL 解引用一定会崩。这其实是好事——崩了你能立刻发现问题，比悄悄改坏别的地方强。

6.7 动态内存：想要多少要多少#

数组的长度必须写死，但有时候程序运行时才知道要多大。这时候用 malloc 向系统临时借内存：

C
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    printf("要几个数? ");
    scanf("%d", &n);

    int *a = malloc(n * sizeof(int));   // 借 n 个 int 的空间
    if (a == NULL) {                    // 借不到就退出
        printf("内存不足\n");
        return 1;
    }

    for (int i = 0; i < n; i++) a[i] = i * i;
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");

    free(a);                            // 用完必须还！
    return 0;
}
运行结果
要几个数? 5
0 1 4 9 16
▲malloc 和 free 必须配对

借了不还叫内存泄漏，程序跑久了会越来越占内存。每写一个 malloc，就要想好 free 写在哪。而且 free 之后不要再使用那个指针。

6.8 本章小结#

  • &a 取地址，*p 按地址取值。
  • 指针就是存地址的变量。
  • 想让函数改你的变量，传地址 &x，函数用 *p 改。
  • 数组名就是首元素地址，a[i] 等价于 *(a + i)。
  • 指针没初始化就是野指针，要么指向真实变量，要么赋 NULL。
  • malloc 借内存，free 还内存，必须配对。
