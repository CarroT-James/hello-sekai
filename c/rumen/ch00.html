第 0 章 开始之前

预计 10 分钟·约 2,197 字·C 语言入门

这一章不写什么复杂代码，只解决三件事：程序是什么、工具怎么装、第一个程序怎么跑起来。看起来很简单，但90% 的新手放弃都发生在这一步——所以别急着往下翻。

0.1 程序到底是什么#

一句话：程序就是写给电脑的指令清单，电脑照着一条一条做。

比如你写「打印 Hello」，电脑就在屏幕上显示 Hello；你写「读入一个数字，乘 2 再打印」，电脑就照做。它不会猜你的意思，也不会自己发挥——你写什么，它做什么。

那为什么不能直接写中文给电脑看？因为电脑只认识 0 和 1。所以我们写的 C 代码需要先被翻译成机器指令，这个翻译的过程叫编译：

C
你写的代码 (.c 文件)          编译器 (gcc)          电脑能运行的程序 (.exe)
    hello.c        ──────────►  翻译      ──────────►      hello.exe
   （人能看懂）                              （机器能执行）
★打个比方

你写了一封中文信，电脑只懂英文。编译器就是翻译官，把中文翻成英文。翻译官说「你这句语法不对」，就是编译错误；翻译完了电脑读不懂，就是运行错误。

0.2 装好工具：Dev-C++#

我们用 Dev-C++，因为它把「写代码」和「编译运行」放在一个窗口里，对新手最省事。

  1. 安装 Dev-C++ 5.11（一路点下一步即可）。
  1. 打开后点菜单 文件 → 新建 → 源代码。
  1. 马上按 Ctrl+S 保存，文件名写成 hello.c。注意后缀必须是 .c，不是 .cpp——.cpp 是 C++，编译器会用另一套规则，很多 C 的写法反而会报错。
  1. 设置 C99 标准：菜单 工具 → 编译选项，勾选「编译时加入以下命令」，填入 -std=c99，点确定。
  1. 按 F11 编译并运行。
▲为什么要设 -std=c99

Dev-C++ 默认用 1989 年的老标准。老标准不允许在 for 括号里定义变量，也不支持一些新语法，你会莫名其妙地报错。加上 -std=c99 就一切正常。这个设置只需做一次，对以后所有文件都有效。

0.3 第一个程序#

新建文件，把下面这几行一个字一个字敲进去（不要复制），保存为 hello.c：

C
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

按 F11，你会看到一个黑色窗口一闪而过，或者显示：

运行结果
Hello, World!

恭喜，你已经写出第一个程序了。现在逐行解释它：

代码作用能不能省
#include <stdio.h>告诉编译器「我要用 printf」，相当于借工具箱不能
int main(void)程序的入口，电脑从这里开始执行不能
{ }一对花括号圈出 main 的地盘不能
printf("...");在屏幕上打印一段文字能，但就什么都不干了
\n换行符，让光标跳到下一行能，但输出会挤在一起
return 0;告诉系统「程序正常结束」能，但没有返回值是不好的习惯

三个必须记住的规则#

  1. 每条语句后面要有分号 ;。中文的「；」不行，英文的 ; 才行。
  1. 花括号必须成对。{ 和 } 少一个，程序就散架了。
  1. 代码里所有标点都用英文。逗号、分号、引号、括号，全都要在英文输入法下打。
▲最常见的翻车现场

用中文输入法打出了全角的 （ ； “ ”，编译器会报 stray '\357' in program 这种看不懂的错。遇到莫名其妙的错，先把这一行的标点重新用英文打一遍。

0.4 程序的基本结构#

以后你写的每个程序，基本都是这个骨架：

C
#include <stdio.h>          // 1. 头文件：借工具

int main(void) {            // 2. 主函数：程序入口
    // 3. 这里写你要做的事

    return 0;               // 4. 正常结束
}

你现在不需要理解每一部分的深层含义，只要知道：代码写在花括号里面，语句以分号结尾，程序从 main 的第一行开始执行。

0.5 报错不可怕，可怕的是不看报错#

新手最常见的反应是：一报错就慌，然后把代码删了重写。其实编译器已经把答案告诉你了，只是英文而已。

读报错分三步：

  1. 看第一行 error。后面的错误往往是它引起的，改好第一个，后面可能全消失。
  1. 看行号。Dev-C++ 底部会写 文件名:行号，双击能跳到那一行。
  1. 看关键词。抓 expected、undeclared、missing 这几个词，对照下表。
报错里出现意思怎么办
expected ';' before ...这里缺个分号看上一行末尾有没有分号
undeclared这个变量我没见过是不是没定义，或拼错了
expected declaration花括号不配对数一数 { 和 } 的个数
stray '\357'混进了中文标点把这一行重新用英文打
implicit declaration of function用了没借来的函数检查 #include
undefined reference to 'main'没有 main 函数检查是不是拼成了 mian
◆记住这句

报错行号指向的，常常不是出错的行。看到 expected ';'，先看上一行。
