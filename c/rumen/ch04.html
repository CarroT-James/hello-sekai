第 4 章 函数

预计 15 分钟·约 3,309 字·C 语言入门

写程序写到一定程度，你会发现有些代码在反复出现——比如「求最大值」这段，算成绩要用，算工资也要用。每次都复制一遍，代码会越来越长，改起来还容易漏。

函数就是解决这个问题的：把一段代码打包，起个名字，以后需要就喊名字。

4.1 先看一个例子#

C
#include <stdio.h>

int add(int a, int b) {       // 定义函数：名字叫 add，要两个整数，返回一个整数
    return a + b;
}

int main(void) {
    int x = add(3, 5);        // 调用函数
    printf("%d\n", x);        // 8
    return 0;
}
运行结果
8

你可能没意识到：你早就在用函数了。printf、scanf 都是别人写好的函数，你只是调用它们。现在你要学的是自己写。

4.2 函数的四个零件#

一个函数由四部分组成：

C
int add(int a, int b) {
    return a + b;
}
 │   │     │      │
 │   │     │      └── 函数体：具体做什么
 │   │     └───────── 参数：需要什么材料
 │   └─────────────── 函数名：叫什么
 └─────────────────── 返回类型：做完给你什么
零件作用例子
返回类型函数算完给你什么类型的结果int、double、void
函数名以后用这个名字调用它add、max、print_line
参数列表需要你提供什么数据(int a, int b)
函数体花括号里的具体步骤{ return a + b; }
★void 是什么意思

如果函数只是做点事、不需要返回结果（比如打印一行字），返回类型就写 void，意思是「什么都不返回」。这时候函数里不需要 return，或者写 return; 也可以。

4.3 参数和返回值#

C
// 有参数、有返回值：最常见
int max2(int a, int b) {
    return (a > b) ? a : b;
}

// 有参数、无返回值
void print_line(int n) {
    for (int i = 0; i < n; i++) {
        printf("-");
    }
    printf("\n");
}

// 无参数、有返回值
int read_int(void) {
    int x;
    scanf("%d", &x);
    return x;
}

return 有两个作用：把值交回去，并且立刻结束函数。所以 return 后面的代码不会执行：

C
int check(int x) {
    if (x < 0) {
        return -1;          // 负数：直接返回，后面的代码不执行
    }
    return x * 2;           // 非负数：返回两倍
}

4.4 值传递：函数拿到的是复印件#

这是新手最容易误解的一点。函数收到的参数，是原变量的一份复印件。函数里怎么改，都改不到原件。

C
void change(int x) {
    x = 100;               // 改的是复印件
    printf("函数里: %d\n", x);
}

int main(void) {
    int a = 5;
    change(a);
    printf("函数外: %d\n", a);
    return 0;
}
运行结果
函数里: 100
函数外: 5
◆记住这句

函数里的参数是复印件，改复印件不会影响原件。想改原件，得传地址——第 6 章讲指针时解决。

顺便说，这也意味着参数名可以和外面的变量名一样，互不干扰：

C
int square(int x) {       // 这个 x
    return x * x;
}

int main(void) {
    int x = 3;            // 和上面那个 x 没关系
    printf("%d\n", square(x));   // 9
    return 0;
}

4.5 变量的作用域#

变量只在它所在的那对花括号里有效，出了花括号就消失了：

C
int main(void) {
    int a = 1;

    {
        int b = 2;
        printf("%d %d\n", a, b);   // 1 2，a 和 b 都能用
    }

    printf("%d\n", a);             // 1，a 还在
    // printf("%d\n", b);          // 错！b 已经没了
    return 0;
}

所以你在一个函数里定义的变量，另一个函数是看不见的。这其实是好事——各管各的，互不干扰。

4.6 函数声明：先在前面打个招呼#

如果函数定义在 main 的后面，编译器读到 main 里的调用时还不认识它，会报错。解决办法是在前面先声明一下（叫「函数原型」）：

C
#include <stdio.h>

int add(int a, int b);        // 声明：告诉编译器有这么个函数

int main(void) {
    printf("%d\n", add(2, 3));   // 现在编译器认识了
    return 0;
}

int add(int a, int b) {       // 定义：具体实现
    return a + b;
}

声明就是把函数头抄一遍，后面加分号，不带函数体。新手最简单的做法是把函数都写在 main 上面，就不用声明了。

4.7 递归：函数自己调用自己#

递归听起来吓人，其实就是一个函数在里面又调用了自己。最经典的例子是阶乘：

C
int fact(int n) {
    if (n <= 1) return 1;        // 出口：不能一直递归下去
    return n * fact(n - 1);      // 自己调用自己
}

int main(void) {
    printf("%d\n", fact(5));     // 120 = 5*4*3*2*1
    return 0;
}
运行结果
120

理解递归要抓两点：① 一定要有出口（否则无限调用，程序崩溃）；② 每次调用都要向出口靠近（这里是 n 每次减 1）。

算阶乘其实用循环更简单，递归的真正用武之地是「树」「汉诺塔」这类天生就分层的问题，第 8 章会再见到它。

4.8 常用库函数#

C 语言自带了很多现成的函数，用好它们能省很多事。用之前要 #include 对应的头文件：

函数作用头文件例子
sqrt(x)开平方math.hsqrt(16) = 4
pow(x, y)x 的 y 次方math.hpow(2, 10) = 1024
fabs(x)绝对值（小数）math.hfabs(-3.5) = 3.5
abs(x)绝对值（整数）stdlib.habs(-5) = 5
rand()随机数stdlib.hrand() % 100
srand(t)设置随机种子stdlib.hsrand(time(NULL))
exit(0)立刻结束程序stdlib.hexit(0)

比如算平方根：

C
#include <stdio.h>
#include <math.h>

int main(void) {
    double x = 16.0;
    printf("%.2f\n", sqrt(x));      // 4.00
    return 0;
}
★如果 sqrt 报错

有的环境需要额外链接数学库。命令行编译时加 -lm；Dev-C++ 一般不用管，如果报 undefined reference to sqrt，去编译选项里加 -lm 即可。

4.9 本章小结#

  • 函数 = 打包好的代码块，起个名字，随叫随用。
  • 四要素：返回类型、函数名、参数、函数体。
  • 函数拿到的是参数的复印件，改不到外面的原变量。
  • 变量只在它的花括号里活着。
  • 递归必须有出口，而且每次都要靠近出口。
