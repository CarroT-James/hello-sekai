附录 A 编译环境与 -std=c99 设置

预计 10 分钟·约 1,120 字·C 语言进阶

本书所有代码都按 C99 标准书写，用到了「在 for 括号里定义变量」这个特性。如果你的编译器默认按 C89 编译，会报出这样的错误：

C
error: 'for' loop initial declarations are only allowed in C99 or C11 mode
note: use option -std=c99, -std=gnu99, -std=c11 or -std=gnu11 to compile your code

这不是代码写错了，是编译模式太老。两种解决办法：

方法一：修改编译器选项（推荐）#

Dev-C++ 5.11#

  1. 菜单「工具(T)」→「编译选项(C)」。
  1. 勾选「编译时加入以下命令」复选框。
  1. 在输入框中填入 -std=c99，点确定。
  1. 重新编译（Ctrl + F11 全部重新编译，避免缓存）。

英文界面路径为 Tools → Compiler Options → 勾选 Add the following commands when calling the compiler，填入 -std=c99。

Code::Blocks#

Settings → Compiler → Compiler settings 标签页，勾选「Have gcc follow the 1999 ISO C language standard [-std=c99]」。

VS Code + MinGW#

在 .vscode/tasks.json 的 args 数组里加一行 "-std=c99"：

C
"args": ["-std=c99", "-g", "${file}", "-o", "${fileDirname}\\${fileBasenameNoExtension}.exe"]

命令行#

C
gcc -std=c99 -Wall 源文件.c -o 程序名.exe
gcc -std=c11 -Wall 源文件.c -o 程序名.exe      // 更新的标准，也支持

// 如果用了 math.h 里的 sqrt、pow 等函数，Linux 下还要加 -lm
gcc -std=c99 源文件.c -o 程序名 -lm

方法二：改写代码（兼容所有编译器）#

把 for 里的变量声明提到外面，代码就符合 C89 了，任何编译器都能编：

C
// C99 写法
for (int i = 0; i < n; i++) { ... }

// C89 兼容写法
int i;
for (i = 0; i < n; i++) { ... }

如果作业要求提交到老旧的评测系统（比如某些学校的 OJ 或 Visual C++ 6.0），用方法二最稳妥。日常练习用方法一，代码更简洁。

▲特别注意

Visual Studio 2015 之前的版本（含 VC6、VS2008、VS2010）完全不支持 C99 的 for 内声明，加编译选项也没用，必须用方法二改写。
