第 8 章 指针与函数

预计 10 分钟·约 2,099 字·C 语言进阶

8.1 值传递与地址传递#

C 语言只有值传递。所有参数在调用时都会被复制一份，函数里改的是副本。所谓「地址传递」，本质是「把地址这个值复制过去」——函数拿到地址后，可以通过它去改原变量。

先看一个经典的错误示范：

C
void swap_wrong(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main(void) {
    int x = 1, y = 2;
    swap_wrong(x, y);       // 什么都没换！
    printf("%d %d\n", x, y); // 1 2
    return 0;
}

为什么没用？因为 a、b 是 x、y 的副本，函数里交换的是副本，函数一结束副本就销毁了，x、y 毫发无伤。

正确做法是传地址：

C
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);           // 传地址
    printf("%d %d\n", x, y); // 2 1
    return 0;
}

内存里发生的事：a 和 b 是 x、y 地址的副本，*a 就是 x 本身，所以交换 *a、*b 就是交换 x、y。

另一种错误：交换指针本身#

C
void swap_wrong2(int *a, int *b) {
    int *t = a;
    a = b;
    b = t;          // 只交换了副本指针的指向，原变量没动
}

这个错误更隐蔽：函数里看起来「交换了」，但那只是两个局部指针变量互换了值，调用者的 x、y 一点没变。要改的是 *a、*b，不是 a、b。

8.2 用指针「返回」多个值#

C 函数只能 return 一个值。需要返回多个结果时，用指针参数作为「输出参数」：

C
void min_max(const int a[], int n, int *pmin, int *pmax) {
    *pmin = *pmax = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < *pmin) *pmin = a[i];
        if (a[i] > *pmax) *pmax = a[i];
    }
}

int main(void) {
    int a[5] = {3, 9, 1, 7, 5};
    int mn, mx;
    min_max(a, 5, &mn, &mx);       // 把变量的地址传进去
    printf("min=%d max=%d\n", mn, mx);
    return 0;
}

这种参数一般命名成 out、result 或以 p 开头（pmin、pmax），一眼能看出是输出参数。

8.3 函数指针#

函数在内存里也有地址，所以可以定义指向函数的指针。语法有点绕，注意括号不能省：

C
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int (*fp)(int, int);        // fp 是「指向 返回int、参数为(int,int) 的函数」的指针
fp = add;                   // 函数名就是地址，不用 &
printf("%d\n", fp(3, 5));   // 8，调用方式一
printf("%d\n", (*fp)(3, 5));// 8，调用方式二，完全等价

理解方法：把 (*fp) 看成一个整体，它代表一个函数，后面的 (int, int) 是参数列表，最前面的 int 是返回值。如果写成 int *fp(int, int)，那就是「返回 int* 的函数」，意思完全不同。

函数指针作为参数：回调#

这是函数指针最重要的用途——把「做什么」也当成参数传进去，实现灵活的组合：

C
void apply(int a[], int n, int (*op)(int)) {
    for (int i = 0; i < n; i++) {
        a[i] = op(a[i]);
    }
}

int square(int x) { return x * x; }
int negate(int x) { return -x; }

int main(void) {
    int a[3] = {1, 2, 3};
    apply(a, 3, square);        // 每个元素平方
    apply(a, 3, negate);        // 再取负
    return 0;
}

标准库的 qsort 就是靠这个机制实现「能排任意类型」的——你把比较规则写成函数传给它，它负责排序框架。

C
typedef int (*CmpFunc)(const void *, const void *);
// 之后就可以写 CmpFunc cmp = cmp_int; 比原写法清爽得多

8.4 函数返回指针#

返回指针的语法是 类型 *函数名(参数)，但有一条铁律：不要返回局部变量的地址。

C
int *bad(void) {
    int x = 10;
    return &x;         // 错！函数结束，x 的内存已回收
}

正确做法有三种，和第 4.4 节的「返回数组」完全一样：返回 static 变量、返回 malloc 的内存、或者干脆让调用者传进来。实际工程里最推荐第三种。

C
// 方式一：static
int *counter(void) {
    static int c = 0;
    c++;
    return &c;
}

// 方式二：malloc（调用者负责 free）
int *new_int(int v) {
    int *p = malloc(sizeof(int));
    if (p) *p = v;
    return p;
}
