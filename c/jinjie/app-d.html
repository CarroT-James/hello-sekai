附录 D 学习路线与自测清单

预计 10 分钟·约 1,350 字·C 语言进阶

D.1 推荐学习顺序#

阶段内容目标预计时间
第 1 周第 1~2 章能手写遍历、求和、最值、逆序、二维矩阵4~6 小时
第 2 周第 4~5 章理解传参退化，手写四种排序 + 二分6~8 小时
第 3 周第 6~7 章吃透 a[i] 与 *(a+i)，能画内存图6~8 小时
第 4 周第 8~9 章会写 swap、函数指针、字符串处理5~7 小时
第 5 周第 10 章malloc/free 配对，能写动态数组4~6 小时
第 6 周第 12~13 章结构体数组排序、按学号查找4~6 小时
第 7 周第 14~16 章链表入门，完成综合案例6~8 小时

第 3 章（VLA）和第 15 章（枚举、联合体）可以先跳过，用到了再回来看。其余章节建议按顺序推进，尤其是第 7 章不能跳。

D.2 自测清单#

下面每一条都能独立完成，说明这三块内容已经过关。做不到的，回到对应章节复习。

数组#

  • □ 不看书写出「求数组最大值及其下标」的函数，并说明为什么初值取 a[0]。
  • □ 说清 a[5] 越界后可能发生什么，为什么编译器不报错。
  • □ 用双指针原地逆序一个数组，解释循环条件为什么是 i < j。
  • □ 手写冒泡、选择、插入三种排序，并说出各自的时间复杂度和稳定性。
  • □ 手写二分查找，解释为什么 mid 要写成 lo + (hi - lo) / 2。
  • □ 说出二维数组的内存布局，推导 a[i][j] 的地址公式。
  • □ 解释为什么二维数组作参数时列数不能省。
  • □ 说出函数里 sizeof(a) 为什么会变成 8。

指针#

  • □ 画出 int a = 10; int *p = &a; 的内存关系图。
  • □ 解释 a[i]、*(a+i)、*(i+a)、i[a] 为什么等价。
  • □ 说清 a 和 &a 的区别（数值、类型、+1 的结果）。
  • □ 分清 int *p[4] 和 int (*p)[4]。
  • □ 写出正确的 swap 函数，并解释错误版本为什么失败。
  • □ 解释为什么不能返回局部数组的地址，给出三种替代方案。
  • □ 说清 char s[] = "abc" 和 char *p = "abc" 的区别。
  • □ 用 malloc 申请二维数组，并正确释放。
  • □ 说出 const int *p 和 int * const p 的区别。

结构体#

  • □ 定义一个含学号、姓名、成绩的结构体，并初始化一个数组。
  • □ 说清 . 和 -> 的使用场景，以及 (*p).name 与 p->name 的关系。
  • □ 解释 struct { char c; int i; char d; } 为什么是 12 字节。
  • □ 用 qsort 按成绩给结构体数组排序。
  • □ 说清结构体传值和传指针的区别，知道什么时候该用 const。
  • □ 解释自引用结构体为什么必须用指针成员。
  • □ 独立完成第 16 章的综合案例，并扩展两个功能。

D.3 接下来学什么#

这三块学完，下一步通常是：

  1. 文件操作：fopen/fread/fprintf，把结构体数组存到文件里再读回来。
  1. 链表与动态数据结构：单链表、双向链表、栈、队列，全部建立在结构体和指针之上。
  1. 位运算与预处理：宏、条件编译、位操作，是嵌入式和底层开发的必备。
  1. 数据结构与算法：排序、查找的进阶（归并、堆、哈希表），这时你会发现自己已经能看懂大部分实现了。

最后一句建议：C 语言的学习曲线在指针这里最陡，但一旦过了这个坎，后面会越来越顺。多画内存图，多手动模拟，比死记语法有用得多。
