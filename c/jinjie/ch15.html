第 15 章 枚举、联合体与位域

预计 10 分钟·约 1,056 字·C 语言进阶

15.1 枚举 enum#

当一组取值是固定的几个选项时，用枚举比用 0、1、2 这样的数字可读性高得多：

C
enum Weekday { MON, TUE, WED, THU, FRI, SAT, SUN };
// 默认从 0 开始：MON=0, TUE=1, ... SUN=6

enum Color { RED = 1, GREEN = 2, BLUE = 4 };   // 可手动指定
enum Level { LOW = 1, MID, HIGH };              // MID=2, HIGH=3，自动递增

enum Weekday today = WED;
if (today == WED) { /* ... */ }

枚举的本质就是 int 常量集合，占 4 字节。它的价值在于：代码自解释、编译器能做类型检查、调试时能看到名字而不是数字。

C
switch (today) {
    case MON: printf("周一\n"); break;
    case FRI: printf("周五\n"); break;
    default:  printf("其他\n"); break;
}

15.2 联合体 union#

联合体的所有成员共用同一块内存，同一时刻只有一个成员有效。它的大小等于最大成员的大小：

C
union Data {
    int    i;       // 4 字节
    double d;       // 8 字节
    char   str[16]; // 16 字节
};

union Data u;
printf("%d\n", (int)sizeof(u));    // 16，等于最大的成员

u.i = 42;                      // 写入 i
u.d = 3.14;                    // 再写 d，会覆盖 i 的内容
对比structunion
内存分配每个成员各自分配所有成员共用一块
大小所有成员之和（含填充）最大成员的大小
同时有效所有成员都有效同一时刻只有一个
典型用途描述一条记录节省空间、类型转换

联合体有一个经典用法：判断机器是大端还是小端：

C
union {
    int  i;
    char c[4];
} u;

u.i = 1;
if (u.c[0] == 1) printf("小端\n");   // 低位字节存在低地址
else              printf("大端\n");

15.3 位域#

位域允许精确指定成员占几个二进制位，用于节省空间或对应硬件寄存器：

C
struct Flags {
    unsigned int is_ready : 1;     // 占 1 位
    unsigned int has_error: 1;     // 占 1 位
    unsigned int mode     : 3;     // 占 3 位，可表示 0~7
};

初学阶段了解即可，实际用到的地方不多，而且位域的具体布局依赖编译器，可移植性差。
