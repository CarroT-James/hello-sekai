第 11 章 二级指针与 const

预计 10 分钟·约 1,026 字·C 语言进阶

11.1 二级指针#

指针本身也是变量，也有地址。指向指针的指针就叫二级指针：

C
int a = 10;
int *p = &a;        // 一级指针：指向 int
int **pp = &p;      // 二级指针：指向 int*

printf("%d\n", **pp);    // 10，解引用两次才到 int

内存关系：

C
pp ──→ p ──→ a
0x300  0x200  0x100
        ↑      ↑
     存 0x100  存 10

二级指针最常见的用途：在函数里修改指针本身。

C
void alloc(int **pp, int n) {
    *pp = malloc(n * sizeof(int));   // 修改调用者的指针
}

int main(void) {
    int *a = NULL;
    alloc(&a, 10);                   // 传指针的地址
    // 现在 a 指向新分配的内存
    free(a);
    return 0;
}

为什么不直接传 int *a？因为那只是复制了一个指针，函数里改成指向新内存，main 里的 a 还是 NULL。要修改谁，就传谁的地址——这是指针参数的一贯规律。

另一个用途是指针数组作参数：char *argv[] 在形参里等价于 char **argv。

11.2 const 与指针的四种组合#

const 放在 * 的左边还是右边，含义完全不同。这是考试必考、工作必用的知识点：

写法含义能否改 *p能否改 p
const int *p指向常量的指针不能能
int const *p同上，写法等价不能能
int * const p常量指针（指针本身不能变）能不能
const int * const p两者都不能改不能不能

记忆口诀：看 const 在 * 的哪一边。

  • const 在 * 左边（const int *p）：锁住的是「指向的数据」，数据不能改，指针可以改指向。
  • const 在 * 右边（int * const p）：锁住的是「指针本身」，指针不能改指向，数据可以改。
  • 两边都有：都锁住。
C
int a = 1, b = 2;

const int *p1 = &a;     // 数据只读
// *p1 = 10;            // 错误
p1 = &b;                // 正确

int * const p2 = &a;    // 指针只读
*p2 = 10;               // 正确
// p2 = &b;             // 错误

const int * const p3 = &a;
// *p3 = 10;  p3 = &b;  // 都错误

实际用途：函数参数里用 const int * 表示「我只读，不改你的数据」，这是 C 标准库的通行做法，比如 strlen(const char *s)。
