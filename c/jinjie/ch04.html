第 4 章 数组与函数

预计 10 分钟·约 2,030 字·C 语言进阶

4.1 数组名作参数时发生了什么#

先看一个能正常运行、但结果很奇怪的例子：

C
#include <stdio.h>

void show(int a[]) {
    printf("%d\n", (int)sizeof(a));        // 输出 8，不是 20！
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    printf("%d\n", (int)sizeof(a));        // 输出 20
    show(a);
    return 0;
}

同一个数组，在 main 里 sizeof 是 20，传到函数里就变成 8 了。原因是：数组作为函数参数时，会「退化」成指向首元素的指针。函数收到的不是整个数组的副本，而是一个地址。

所以下面三种形参写法完全等价，编译器都当成 int *a 处理：

C
void f(int a[]);        // 等价
void f(int a[10]);      // 等价，10 会被忽略
void f(int *a);         // 本质

由此得到两个直接推论：

  1. 函数内部无法用 sizeof 求数组长度，必须额外传一个 n。
  1. 函数内部修改 a[i]，会改到调用者的原数组，因为大家操作的是同一块内存。
C
void double_all(int a[], int n) {
    for (int i = 0; i < n; i++) {
        a[i] *= 2;                 // 会改到 main 里的数组
    }
}

4.2 长度为什么必须单独传#

这是 C 语言的设计缺陷之一：数组退化成指针后，长度信息就丢了。所以所有接收数组的函数，标准写法都是「数组 + 长度」两个参数：

C
int  sum(const int a[], int n);
void print(const int a[], int n);
void sort(int a[], int n);
int  find(const int a[], int n, int target);

这个约定要养成肌肉记忆。看到只传数组不传长度的函数，基本可以断定有 bug（除非是字符串，它靠结尾的 '\0' 自带长度信息）。

4.3 用 const 保护数组#

如果函数只是读取数组、不应该修改它，就在形参前加 const。这是好习惯，能防住一类低级错误：

C
void print(const int a[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    // a[0] = 100;      // 编译错误：只读，改不了
}

const 还有一个好处：它向调用者明确承诺「我不会改你的数据」，代码可读性直接提升。

4.4 函数返回数组的三种方式#

先记住一条铁律：绝对不能返回函数内部定义的局部数组。

C
int *bad(void) {
    int a[5] = {1, 2, 3, 4, 5};
    return a;              // 严重错误！函数结束，a 所在的内存已被回收
}

函数返回后，它的栈帧被销毁，那块内存随时可能被别的函数覆盖。你拿到的指针指向一片废墟，读出来的值完全不可预期。编译器一般会给 warning，但不会报错，很容易漏掉。

正确做法有三种：

方式一：用 static 数组#

C
int *make_seq(void) {
    static int a[5];       // static 存放在静态区，函数结束不销毁
    for (int i = 0; i < 5; i++) a[i] = i * i;
    return a;
}

能用，但有副作用：所有调用者共享同一块内存，第二次调用会覆盖第一次的结果。只在简单场景下用。

方式二：用 malloc 动态分配#

C
#include <stdlib.h>

int *make_array(int n) {
    int *a = malloc(n * sizeof(int));
    if (a == NULL) return NULL;        // 分配失败要检查
    for (int i = 0; i < n; i++) a[i] = 0;
    return a;                          // 内存还在，调用者负责 free
}

这是最通用的做法，缺点是调用者必须记得 free，否则内存泄漏。第 10 章详细讲。

方式三：由调用者传入结果数组（推荐）#

C
void make_seq(int out[], int n) {      // 结果写进调用者的数组
    for (int i = 0; i < n; i++) {
        out[i] = i * i;
    }
}

int main(void) {
    int result[5];
    make_seq(result, 5);               // 谁申请谁释放，责任清晰
    return 0;
}

这种方式没有内存管理负担，也没有生命周期问题，是 C 程序里最常见的写法。标准库很多函数也这么做，比如 sprintf、strcpy。

4.5 本章易错点#

序号错误后果
1函数里用 sizeof(a)/sizeof(a[0]) 求长度得到 2 或 1（指针大小/元素大小），长度全错
2只传数组不传长度函数不知道边界，必然越界
3返回局部数组的指针悬空指针，读到垃圾值或崩溃
4形参写 int a[][], int a[][] 省略列数编译错误
5以为传数组是「传值」，函数里改了不影响外面实际会改掉原数组
