第 5 章 查找与排序

预计 20 分钟·约 3,893 字·C 语言进阶

查找和排序是数组最经典的两类应用，也是数据结构课的敲门砖。本章的代码要求能默写，并且能说清每种算法的时间复杂度。

5.1 顺序查找#

从第一个元素开始逐个比较，找到就返回下标，找不到返回 -1。最简单，也最通用——它不要求数组有序。

C
int sequential_search(const int a[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;                 // 约定：-1 表示没找到
}

平均要比较 n/2 次，时间复杂度 O(n)。数据量小或者只查一次时完全够用。

■约定

「返回下标、找不到返回 -1」是 C 里的通用约定。因为下标从 0 开始，-1 不可能是合法下标，用 int 返回下标 + -1 表示失败是最自然的做法。

5.2 二分查找#

二分查找效率极高，O(log n)——100 万个数据最多查 20 次。但它有一个硬性前提：数组必须已经有序。很多人忘了排序就直接二分，结果时对时错。

思路：每次取中间元素和目标比较，相等就找到；目标更大就去右半边找，更小就去左半边找；区间缩到空还没找到，说明不存在。

C
int binary_search(const int a[], int n, int target) {
    int lo = 0;
    int hi = n - 1;                 // 闭区间 [lo, hi]

    while (lo <= hi) {              // 区间非空就继续
        int mid = lo + (hi - lo) / 2;   // 防溢出写法
        if (a[mid] == target) {
            return mid;
        } else if (a[mid] < target) {
            lo = mid + 1;           // 目标在右半边
        } else {
            hi = mid - 1;           // 目标在左半边
        }
    }
    return -1;
}

这段代码有四个细节，每一个都是考点：

细节写法写错的后果
循环条件lo <= hi写 lo < hi 会漏掉区间只剩一个元素的情况
mid 计算lo + (hi - lo) / 2写 (lo + hi) / 2 在超大数组时整数溢出
左边界更新lo = mid + 1写 lo = mid 可能死循环
右边界更新hi = mid - 1同上

为什么 mid 要用 lo + (hi - lo) / 2？因为当 lo 和 hi 都接近 int 上限时，lo + hi 会溢出变成负数，除以 2 得到负下标，程序直接崩。虽然初学阶段数组不会那么大，但这个写法要养成习惯。

二分查找的递归写法#

C
int bsearch_rec(const int a[], int lo, int hi, int target) {
    if (lo > hi) return -1;                 // 区间为空
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target)  return bsearch_rec(a, mid + 1, hi, target);
    return bsearch_rec(a, lo, mid - 1, target);
}

递归写法更贴近「分治」的直觉，但每次递归都有函数调用开销。实际工程里用循环版。

5.3 冒泡排序#

相邻两个元素比较，逆序就交换。每一轮结束，最大的元素会「冒」到末尾。

C
void bubble_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {              // 最多 n-1 轮
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {      // 已排好的尾部不用再比
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;                       // 本轮无交换，已经有序
    }
}

两个关键点：

  • 内层循环上界是 n - 1 - i，因为每轮之后末尾 i+1 个元素已经就位。写死 n-1 也能排对，但白跑很多次。
  • swapped 标志是优化：如果某一轮一次交换都没有，说明整个数组已经有序，可以提前结束。对近乎有序的数据，这个优化能把最好情况从 O(n²) 降到 O(n)。

5.4 选择排序#

每一轮从未排序部分找出最小的，放到已排序部分的末尾。特点是交换次数少，最多 n-1 次。

C
void selection_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[min_idx]) {
                min_idx = j;
            }
        }
        if (min_idx != i) {              // 自己就是最小就不用换
            int t = a[i];
            a[i] = a[min_idx];
            a[min_idx] = t;
        }
    }
}

什么时候用选择排序？当「交换」的代价很高时。比如元素是很大的结构体，冒泡要交换 O(n²) 次，选择排序只要 O(n) 次。

5.5 插入排序#

像打扑克摸牌：把新牌插到手里已经排好的牌中间。

C
void insertion_sort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];                 // 取出当前牌
        int j = i - 1;
        while (j >= 0 && a[j] > key) {  // 比 key 大的都往后挪
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;                 // 空出来的位置放 key
    }
}

插入排序在「数据基本有序」时非常快，接近 O(n)，而且它是稳定的。很多标准库的快排在数据量小（比如少于 16 个元素）时会退化成插入排序，就是这个原因。

注意 while 的条件顺序：j >= 0 必须写在前面。因为 C 的 && 是短路求值，如果先判断 a[j] > key，当 j 变成 -1 时会先访问 a[-1]，直接越界。

5.6 快速排序与 qsort#

手写快速排序#

快排的核心是「分区」：选一个基准值，把比它小的放左边、大的放右边，然后对左右两半递归。

C
static int partition(int a[], int lo, int hi) {
    int pivot = a[hi];              // 选最后一个元素作基准
    int i = lo;                     // i 指向"小于区"的下一个位置

    for (int j = lo; j < hi; j++) {
        if (a[j] < pivot) {
            int t = a[i]; a[i] = a[j]; a[j] = t;
            i++;
        }
    }
    int t = a[i]; a[i] = a[hi]; a[hi] = t;   // 基准归位
    return i;
}

void quick_sort(int a[], int lo, int hi) {
    if (lo >= hi) return;           // 0 或 1 个元素，不用排
    int p = partition(a, lo, hi);
    quick_sort(a, lo, p - 1);
    quick_sort(a, p + 1, hi);
}

// 调用：quick_sort(a, 0, n - 1);

平均 O(n log n)，最坏 O(n²)（数组已经有序且总选最后一个作基准时）。实际工程中会用「三数取中」或随机选基准来避免最坏情况。

用标准库的 qsort#

C 标准库自带排序函数 qsort，实际开发中优先用它——它经过高度优化，而且能排任意类型：

C
#include <stdlib.h>

int cmp_int(const void *p, const void *q) {
    int a = *(const int *)p;
    int b = *(const int *)q;
    return (a > b) - (a < b);      // 返回正数/0/负数，避免相减溢出
}

int main(void) {
    int a[8] = {5, 2, 9, 1, 7, 3, 8, 4};
    int n = sizeof(a) / sizeof(a[0]);

    qsort(a, n, sizeof(a[0]), cmp_int);   // 数组, 个数, 单元素大小, 比较函数
    return 0;
}

qsort 的四个参数顺序是：数组首地址、元素个数、单个元素字节数、比较函数指针。比较函数必须返回 int：负数表示 p 应排在 q 前面，正数表示后面，0 表示相等。

为什么不用 return a - b？当 a 和 b 相差很大（比如 INT_MAX 和 -1）时，相减会溢出，结果符号翻转，排序就错了。三目运算的写法永远安全。

5.7 算法对比与选择#

算法平均时间最坏时间空间稳定性特点
顺序查找O(n)O(n)O(1)—不要求有序，通用
二分查找O(log n)O(log n)O(1)—必须有序
冒泡排序O(n²)O(n²)O(1)稳定简单，可提前退出
选择排序O(n²)O(n²)O(1)不稳定交换次数最少
插入排序O(n²)O(n²)O(1)稳定近乎有序时接近 O(n)
快速排序O(n log n)O(n²)O(log n)不稳定实际最快，递归

「稳定」的意思是：值相等的两个元素，排序后相对顺序不变。如果按成绩排序、同分要按学号先后，就必须用稳定排序。

■怎么选

数据量小（n < 100）：插入排序足够，代码短不易错。需要稳定：归并排序或插入排序。一般情况：直接 qsort。竞赛里数据有序性未知且要求快：手写快排或直接用 qsort。

5.8 本章易错点#

  • 对无序数组直接二分——结果时对时错，务必先排序。
  • 二分里写 lo = mid 而不是 mid + 1，区间不缩小，死循环。
  • 冒泡内层写 j < n - 1 而不减去 i——不影响正确性，但多跑很多轮。
  • qsort 的比较函数返回 a - b——大数相减溢出。
  • 比较函数写成 int cmp(int a, int b)——参数类型必须是 const void *。
  • 排完序返回下标——排序会打乱元素位置，要保留原下标需额外记录。
