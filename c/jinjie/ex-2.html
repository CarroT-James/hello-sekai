习题二 指针专项练习

预计 10 分钟·约 1,157 字·C 语言进阶

基础题#

【2-1】指针交换 基础

写函数 swap(int *a, int *b) 交换两个整数，并在 main 中验证。再写一个错误版本 swap(int a, int b)，观察结果并解释原因。

提示：对比两种写法的输出，想清楚「副本」这个词。

【2-2】指针遍历 基础

用指针（不用下标）遍历一个数组，输出所有元素及其地址，观察地址间隔。

提示：用 %p 输出 (void*)p，看相邻元素差几个字节。

【2-3】数组逆序（指针版） 基础

用两个指针（一个指向头、一个指向尾）实现数组原地逆序。

提示：循环条件写成 while (left < right)。

【2-4】手写 strlen 基础

不用 string.h，自己实现 my_strlen(const char *s)。

提示：用一个指针走到 '\0'，返回 p - s。

【2-5】指针求最值 基础

写函数 void min_max(const int *a, int n, int *pmin, int *pmax)，一次遍历同时求出最小值和最大值。

提示：两个输出参数都要解引用赋值。

【2-6】解释声明 基础

说明下面四个声明的区别，并各写一行使用代码：int *p[5]; int (*p)[5]; int *f(void); int (*f)(void);

提示：看 [] 和 () 与谁先结合。

进阶题#

【2-7】字符串反转（指针版） 进阶

用两个指针实现字符串原地反转，要求不用辅助数组。

提示：和数组逆序一样，只是元素类型变成 char。

【2-8】动态数组排序 进阶

用 malloc 申请 n 个 int，读入数据，用 qsort 排序后输出，最后 free。

提示：qsort 的第四个参数是比较函数指针。

【2-9】动态二维数组 进阶

用 malloc 申请一个 n×m 的二维数组，实现矩阵转置并输出，最后正确释放所有内存。

提示：注意释放顺序：先释放每行，再释放行指针数组。

【2-10】函数指针回调 进阶

写一个函数 apply(int *a, int n, int (*op)(int))，对数组每个元素应用 op；再用它分别实现「全部平方」和「全部取绝对值」。

提示：op 就是一个「变换规则」。

【2-11】二级指针分配 进阶

写函数 int alloc_array(int **pp, int n)，在函数内部分配数组并返回是否成功，在 main 中调用并验证。

提示：传 &a，函数里用 *pp = malloc(...)。

【2-12】找 bug 进阶

下面代码有几处错误？逐一指出并改正：char *s = malloc(10); s = "hello"; free(s);

提示：想想 malloc 返回的地址去哪了，以及字符串常量能不能 free。
