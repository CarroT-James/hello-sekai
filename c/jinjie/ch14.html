第 14 章 typedef、嵌套与自引用

预计 10 分钟·约 1,680 字·C 语言进阶

14.1 typedef 起别名#

每次都写 struct Student 太啰嗦。typedef 可以给它起个短名字：

C
typedef struct Student {
    int    id;
    char   name[20];
    double score;
} Student;                  // 现在 Student 等价于 struct Student

Student s;                  // 不用再写 struct
Student list[30];

这种写法在实际项目里几乎是标准做法。注意 typedef 的位置：名字放在最后，而且 typedef 定义的是一个类型别名，不是变量。

常见的几种写法对比：

C
// 写法一：分两步（清晰）
struct Student { int id; };
typedef struct Student Student;

// 写法二：合并（最常用）
typedef struct Student { int id; } Student;

// 写法三：匿名 + typedef（类型名只能叫 Student）
typedef struct { int id; } Student;

顺带一提，typedef 也常用于简化复杂的指针类型：

C
typedef int (*CmpFunc)(const void *, const void *);
CmpFunc cmp = cmp_score_desc;      // 比原写法清爽得多
▲易错点

不要用 typedef 隐藏指针：typedef struct Node *NodePtr; 看着方便，但会让代码里「这到底是不是指针」变得不明显，大型项目里是公认的坏习惯。指针就老老实实写 *。

14.2 嵌套结构体#

结构体的成员可以是另一个结构体：

C
struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    int         id;
    char        name[20];
    struct Date birth;        // 嵌套：出生日期
};

// 初始化：嵌套用嵌套的花括号
struct Student s = {1001, "张三", {2006, 5, 20}};

// 访问：一层层用点号
printf("%d\n", s.birth.year);

嵌套时要注意 sizeof：外层的大小包含内层的全部字节（含内层的填充）。

14.3 自引用结构体与链表#

结构体里可以包含指向自身类型的指针，这是链表、树等数据结构的基石：

C
struct Node {
    int          data;
    struct Node *next;        // 指向同类型的下一个结点
};

为什么是指针而不是直接放一个结构体？如果写 struct Node next;，那么这个结构体的大小就包含它自己，无限递归下去，编译器根本算不出它有多大。指针的大小是固定的（8 字节），所以没问题。

用自引用结构体串起一条链表：

C
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int          data;
    struct Node *next;
};

int main(void) {
    // 手工串三个结点：1 -> 2 -> 3 -> NULL
    struct Node *head = NULL;

    for (int i = 3; i >= 1; i--) {
        struct Node *p = malloc(sizeof(struct Node));
        if (p == NULL) return 1;
        p->data = i;
        p->next = head;         // 头插法
        head = p;
    }

    // 遍历
    for (struct Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->data);
    }
    printf("\n");

    // 释放：必须先保存 next 再 free
    struct Node *p = head;
    while (p != NULL) {
        struct Node *next = p->next;
        free(p);
        p = next;
    }
    return 0;
}
■知识点连通

这段代码同时用到了：结构体、自引用指针、malloc/free、指针遍历、NULL 终止条件。如果每一行你都能解释清楚，说明前三部分的知识已经串起来了——这就是学数据结构前的及格线。
