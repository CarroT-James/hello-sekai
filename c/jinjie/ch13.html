第 13 章 结构体与数组、指针

预计 10 分钟·约 2,412 字·C 语言进阶

13.1 结构体数组#

这是最常用的组合：一个数组，每个元素是一条完整记录。

C
#include <stdio.h>

struct Student {
    int    id;
    char   name[20];
    double score;
};

int main(void) {
    struct Student list[3] = {
        {1001, "张三", 92.5},
        {1002, "李四", 78.0},
        {1003, "王五", 85.5}
    };
    int n = sizeof(list) / sizeof(list[0]);

    for (int i = 0; i < n; i++) {
        printf("%d  %s  %.1f\n", list[i].id, list[i].name, list[i].score);
    }
    return 0;
}

注意 sizeof(list) / sizeof(list[0]) 这个写法在这里同样适用——因为 list 是真正的数组，还没有退化成指针。

结构体数组在内存里也是连续排列的，每个元素占 sizeof(struct Student) 字节：

C
list[0]            list[1]            list[2]
+--------+--------+--------+--------+--------+--------+
|  id    | name   | score  |  ...   |  ...   |  ...   |
+--------+--------+--------+--------+--------+--------+
|<-- sizeof(struct Student) -->|

13.2 结构体指针#

C
struct Student s = {1001, "张三", 92.5};
struct Student *p = &s;

printf("%d\n", p->id);        // 1001
p->score = 95.0;              // 通过指针修改
printf("%.1f\n", s.score);    // 95.0，原变量跟着变

结构体指针最常见的用法是遍历结构体数组：

C
struct Student *p = list;
for (int i = 0; i < n; i++) {
    printf("%s\n", p->name);
    p++;                      // 跳到下一个元素，自动跳过整个结构体
}

p++ 跳过的字节数等于 sizeof(struct Student)，这正是 6.3 节说的「指针类型决定步长」。

13.3 结构体作函数参数#

有两种传法，区别很大：

C
// 传值：拷贝整个结构体
void print_student(struct Student s) {     // 复制一份，有几 MB 就复制几 MB
    printf("%d %s %.1f\n", s.id, s.name, s.score);
}

// 传指针：只复制一个地址（8 字节），且能修改原数据
void add_score(struct Student *p, double delta) {
    p->score += delta;
}
传参方式开销能否修改原数据推荐场景
struct Student s整个结构体大小不能结构体很小，且只读
const struct Student *p8 字节不能（const 保护）只读访问，最常用
struct Student *p8 字节能需要修改时
■结论

只要结构体不是特别小，一律传指针；不想被改就加 const。这是 C 代码的默认风格，也是标准库（比如 qsort 的比较函数）采用的方式。

结构体还可以整体赋值，这是它和数组的一大区别：

C
struct Student a = {1001, "张三", 92.5};
struct Student b;

b = a;                  // 合法！逐字节复制，b 和 a 内容相同
// b == a;              // 不合法！C 不支持结构体的 == 比较

// 比较两个结构体是否相同，必须逐成员比较
if (a.id == b.id && strcmp(a.name, b.name) == 0 && a.score == b.score) {
    printf("相同\n");
}

13.4 结构体数组的排序#

排序结构体数组有两种写法。手写的话，交换时要注意：结构体可以整体赋值，直接换就行：

C
// 按成绩降序，冒泡版
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (list[j].score < list[j + 1].score) {
            struct Student t = list[j];        // 整体交换，不会错位
            list[j] = list[j + 1];
            list[j + 1] = t;
        }
    }
}

更推荐用 qsort，关键是写对比较函数：

C
int cmp_score_desc(const void *p, const void *q) {
    const struct Student *a = (const struct Student *)p;
    const struct Student *b = (const struct Student *)q;

    if (a->score < b->score) return 1;      // 降序：小的往后排
    if (a->score > b->score) return -1;
    return 0;
}

qsort(list, n, sizeof(list[0]), cmp_score_desc);

比较函数里必须把 void * 转成实际的类型指针，然后用 -> 访问成员。如果按姓名排序，把比较部分换成 strcmp(a->name, b->name) 即可。

多关键字排序也很简单：先比第一关键字，相等再比第二关键字：

C
int cmp_score_then_id(const void *p, const void *q) {
    const struct Student *a = p, *b = q;
    if (a->score < b->score) return 1;
    if (a->score > b->score) return -1;
    return a->id - b->id;              // 成绩相同按学号升序
}
