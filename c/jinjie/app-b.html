附录 B 常见编译错误速查表

预计 10 分钟·约 932 字·C 语言进阶

把常见的编译器报错和原因整理成表，遇到报错先来这里查：

报错关键词常见原因解决
'for' loop initial declarations are only allowed in C99 mode编译器按 C89 编译加 -std=c99，或把 int i 提到 for 外
expected ';' before ... token上一行漏了分号；或结构体定义末尾漏了 ;检查报错行的前一行
undefined reference to 'main'没有 main 函数；或拼成了 mian补上 int main(void)
implicit declaration of function 'xxx'没包含对应的头文件加 #include <stdio.h> 或 <string.h>
undefined reference to 'sqrt'数学库没链接Linux 下加 -lm
'xxx' undeclared (first use in this function)变量没定义；或拼写错误；或作用域不对检查声明位置
stray '\357' in program文件里混入了中文全角空格/标点，或 BOM 头删除该行重新输入
expected declaration or statement at end of input花括号不配对，少了一个 }数一数 { 和 }
assignment to expression with array type对数组整体赋值（s.name = "x"）改用 strcpy
incompatible pointer type指针类型不匹配，如 int* 赋给 double*检查类型，必要时强制转换
variable-sized object may not be initialized对变长数组用了 = {0}改用循环赋值
warning: format '%d' expects argument of type 'int'printf 格式符和参数类型不匹配sizeof 先转 (int) 再用 %d
■读报错的方法

① 先看第一条 error（后面的往往是它引发的连锁反应）；② 位置看「行号:列号」；③ 看不懂英文就抓关键词，对照本表；④ 别忘了看 note 行，编译器经常直接告诉你解法。
