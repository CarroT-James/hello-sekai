第 3 章 变长数组（VLA）

预计 10 分钟·约 1,750 字·C 语言进阶

3.1 什么是变长数组#

前面的数组长度都写死在代码里，但实际编程中经常是「用户输入 n，然后开 n 个格子」。C99 引入了变长数组（Variable Length Array，VLA），允许用变量指定长度：

C
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);

    int a[n];              // 运行时才确定大小

    for (int i = 0; i < n; i++) {
        a[i] = i * i;
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    return 0;
}

名字叫「变长」，但其实一旦创建，长度就固定了，不能在运行过程中再变大变小。「变」指的是长度可以在运行时才确定，而不是编译时就写死。

■历史

VLA 是 C99 引入的；到了 C11，它从「必须支持」降级为「可选支持」。所以同一个程序，gcc 能编译，MSVC（Visual Studio）不能，这不是你写错了。

3.2 用法与限制#

VLA 的规矩比普通数组多，踩中任何一条都编译不过或行为未定义：

限制说明示例
必须在声明时确定大小后面的语句不能再改int a[n]; 之后 n 变了也没用
不能初始化编译器不知道要填几个 0int a[n] = {0}; ← 错误
不能是全局或 static全局对象大小必须编译期确定static int a[n]; ← 错误
不能作为结构体成员结构体大小必须固定struct S { int a[n]; }; ← 错误
大小必须大于 0n ≤ 0 是未定义行为先检查 if (n <= 0) return;
分配在栈上太大会栈溢出几百 MB 的数组请用 malloc
C
int n = 10;
int a[n];

// 错误 1：不能初始化
// int b[n] = {0};

// 错误 2：大小在声明后不能改
n = 20;
// 此时 a 仍然是 10 个元素，不会变成 20 个

sizeof 对 VLA 是在运行时求值的：

C
int n = 10;
int a[n];
printf("%d\n", (int)sizeof(a));       // 40（int 为 4 字节时），运行时算出来的

3.3 VLA 与 malloc 的取舍#

同样实现「运行时决定大小」，VLA 和 malloc 各有适用场景：

对比项VLA（int a[n]）malloc（int *a = malloc(...)）
标准C99，C11 起为可选所有 C 标准都支持
内存位置栈堆
大小上限受栈大小限制（通常 1~8 MB）受物理内存限制
释放函数/代码块结束自动回收必须手动 free
生命周期只在当前代码块内有效直到 free 为止
能否返回不能返回给调用者可以返回指针
失败处理无法检测，直接崩返回 NULL，可检查

给初学者的建议：课程作业里优先用 #define N 100 开固定大小的数组，因为它最稳、所有编译器都认、调试也方便。等学到第 10 章动态内存，再根据实际需要选 VLA 或 malloc。

C
#define MAXN 100          // 题目数据范围的上限

int a[MAXN];
int n;
scanf("%d", &n);
if (n > MAXN) {           // 养成检查的习惯
    printf("数据超范围\n");
    return 1;
}

3.4 编译器支持与常见报错#

VLA 相关的报错通常长这样：

报错信息原因解决
variable-sized object may not be initialized对 VLA 用了 = {0}改用循环赋值或 memset
variably modified type at file scope在全局定义了 VLA移进函数内部
error: 'for' loop initial declarations are only allowed in C99 mode编译器按 C89 编译加 -std=c99（见附录 A）
undefined reference 或直接崩溃n 为 0 或负数使用前检查 n > 0

Dev-C++ 5.11 自带的 TDM-GCC 4.9.2 在加了 -std=c99 之后是支持 VLA 的。如果你的代码在别人电脑上能跑、在自己这里报错，先查编译选项，不要怀疑代码。
