第 7 章 指针与数组

预计 10 分钟·约 2,782 字·C 语言进阶

这一章是全书的核心。学完它，你会明白为什么 C 里的「数组」和「指针」总被放在一起讲。

7.1 数组名到底是什么#

结论先给：数组名在大多数场合会被自动转换成「首元素的地址」，类型是 int *（假设元素是 int）。

C
int a[5] = {10, 20, 30, 40, 50};

printf("%p\n", (void *)a);       // 和 &a[0] 输出相同
printf("%p\n", (void *)&a[0]);   // 一样

int *p = a;                      // 合法：a 就是首元素地址

但有两个例外，数组名不会退化，仍然代表整个数组：

  1. 作为 sizeof 的操作数：sizeof(a) 得到 20，是数组总大小。
  1. 作为 & 的操作数：&a 得到「整个数组的地址」，类型是 int (*)[5]，不是 int*。
C
int a[5];

sizeof(a)     // 20     整个数组
sizeof(&a)    // 8      指针大小
sizeof(a + 0) // 8      a 退化成指针后参与运算，就是指针了

// &a 和 a 的数值相同，但类型不同：
// a  的类型是 int *          （指向第一个元素）
// &a 的类型是 int (*)[5]     （指向整个数组）
// &a + 1 会跳过 20 字节，a + 1 只跳 4 字节

数组名不是指针，它是一个地址常量：不能赋值、不能自增。

C
int a[5];
// a = p;        // 错误：数组名不能赋值
// a++;          // 错误：数组名不是变量，不能自增

7.2 下标的本质：a[i] 就是 *(a + i)#

C 标准规定，a[i] 完全等价于 *(a + i)。编译器看到 a[i] 时，内部做的就是这个转换：取首地址、加上偏移、再解引用。

这也解释了两件事：

  • 为什么下标从 0 开始：因为首元素就是「偏移 0」，写成 *(a + 0) 最自然。
  • 为什么 a[i] 是 O(1)：地址是一次加法算出来的，不需要从头遍历。
C
int a[5] = {10, 20, 30, 40, 50};

a[2]        // 30
*(a + 2)    // 30，完全等价
*(2 + a)    // 30，加法可交换
2[a]        // 30，居然也合法！（但别这么写，会被打）

最后那个 2[a] 不是段子，是 C 标准允许的——因为 a[2] 被展开成 *(a + 2)，而加法满足交换律，*(2 + a) 自然等于 2[a]。知道有这回事就行，实际代码里绝对不要这么写。

二维数组的下标展开#

二维数组是「数组的数组」，所以展开两次：

C
int a[3][4];

a[i][j]
= *(a[i] + j)          // 先把 a[i] 当成一行
= *(*(a + i) + j)      // 再把 a[i] 展开成 *(a + i)

逐层理解：

表达式类型含义
aint (*)[4]指向「含 4 个 int 的一行」的指针
a + iint (*)[4]第 i 行的地址（整行）
*(a + i)int *第 i 行首元素的地址（退化成 int*）
*(a + i) + jint *第 i 行第 j 个元素的地址
*(*(a + i) + j)int第 i 行第 j 个元素的值
■关键

a 和 a[0] 的数值相同（都是首地址），但类型不同：a 是 int(*)[4]，a[0] 是 int*。类型不同，加 1 跳过的字节数就不同——a + 1 跳过一整行（16 字节），a[0] + 1 只跳一个元素（4 字节）。

7.3 用指针遍历数组#

既然 a[i] 等价于 *(a + i)，用指针遍历数组就顺理成章：

C
int a[5] = {10, 20, 30, 40, 50};
int n = 5;

// 写法一：指针 + 偏移
int *p = a;
for (int i = 0; i < n; i++) {
    printf("%d ", *(p + i));
}

// 写法二：指针自增（最地道）
for (int *p = a; p < a + n; p++) {
    printf("%d ", *p);
}

写法二里的 a + n 是「最后一个元素的下一个位置」，这个位置可以取地址、可以比较，但不能解引用（越界了）。这是 C 语言的一个特殊约定，叫「尾后指针」，很多算法都靠它做结束条件。

*p++ 这个经典组合#

C
int a[3] = {1, 2, 3};
int *p = a;

printf("%d\n", *p++);    // 输出 1，然后 p 指向 a[1]
printf("%d\n", (*p)++);  // 输出 2，然后 a[1] 变成 3

*p++ 等价于 *(p++)，因为后缀 ++ 优先级高于 *。它的意思是「取出当前值，然后指针后移」，是遍历数组的常用写法。而 (*p)++ 是「把所指的值加 1」，指针不动。这一对要分清楚。

指针遍历和下标遍历在性能上没有区别——现代编译器会把两种写法优化成同样的机器码。选哪种只看可读性，不要为了「显得高级」而用指针。

7.4 指针数组 与 数组指针#

这两个名字只差一个字，含义完全不同，是考试和面试的高频陷阱。

C
int *p[4];      // 指针数组：一个数组，含 4 个 int* 元素
int (*q)[4];    // 数组指针：一个指针，指向「含 4 个 int 的数组」

记忆方法看优先级：[] 的优先级高于 *。

  • int *p[4]：p 先和 [] 结合，所以 p 是数组；数组元素是 int*。读作「指针的数组」。
  • int (*q)[4]：括号强制 q 先和 * 结合，所以 q 是指针；指向 int[4]。读作「数组的指针」。
写法名称sizeof典型用途
int *p[4]指针数组32（4 × 8）存多个字符串、多行不等长数据
int (*q)[4]数组指针8指向二维数组的一行
C
// 指针数组的典型用法：存一组字符串
char *names[3] = {"Alice", "Bob", "Cindy"};
for (int i = 0; i < 3; i++) {
    printf("%s\n", names[i]);
}

// 数组指针的典型用法：遍历二维数组
int a[2][4] = {{1,2,3,4}, {5,6,7,8}};
int (*row)[4] = a;
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 4; j++) {
        printf("%d ", row[i][j]);
    }
}

7.5 总结：数组与指针的关系#

最后用一张表把这章收束：

说法对不对解释
数组就是指针错数组是一块内存，指针是存地址的变量
数组名可以当指针用对多数场合退化为首元素地址
指针可以当数组用基本对p[i] 等价于 *(p+i)，但指针没有长度信息
a 和 &a 一样错数值相同，类型不同，+1 的结果不同
a[i] 等价于 *(a+i)对这是 C 标准的定义
sizeof(a) 总是数组大小错传参后退化成指针，大小变成 8
■一句话记住

数组名是「地址常量」，指针是「存地址的变量」。前者不能改，后者能改；前者带长度信息（在定义它的作用域内），后者不带。
