第 9 章 指针与字符串

预计 10 分钟·约 1,325 字·C 语言进阶

9.1 字符数组 与 字符指针#

在 C 里，字符串就是以 '\0' 结尾的字符序列。有两种方式「持有」一个字符串，它们在内存里完全不同：

C
char s[] = "hello";     // 字符数组：在栈上复制了一份，6 字节
char *p  = "hello";     // 字符指针：指向只读区的字符串常量

// s:
//   [h][e][l][l][o][\0]   ← 栈上，可读可写
//
// p:
//   p ──→ "hello\0"       ← 只读数据段，不可修改
对比项char s[] = "hello"char *p = "hello"
存储内容字符本身（6 字节）一个地址（8 字节）
sizeof68
strlen55
能否修改内容能不能（未定义行为）
能否重新指向不能（数组名是常量）能
▲致命错误

char *p = "hello"; p[0] = 'H'; 在多数系统上会直接段错误。因为字符串常量放在只读内存段，写它会触发保护。要修改就必须用字符数组。

C
char s[] = "hello";
s[0] = 'H';             // 正确：Hello
printf("%s\n", s);

char *p = "hello";
// p[0] = 'H';          // 错误：段错误（Segmentation fault）
p = "world";            // 正确：改变指向，不改变内容

9.2 常用字符串函数#

这些函数都在 <string.h> 里，面试和作业都要求能手写其中几个：

函数作用注意
strlen(s)求长度（不含 '\0'）O(n)，每次调用都重新数
strcpy(d, s)把 s 复制到 dd 必须够大，否则溢出
strncpy(d, s, n)最多复制 n 个字符可能不补 '\0'，要手动补
strcat(d, s)把 s 接到 d 后面d 必须够大
strcmp(a, b)比较，相等返回 0不能用 == 比较字符串
strchr(s, c)找字符，返回指针找不到返回 NULL
strstr(s, sub)找子串，返回指针找不到返回 NULL

手写 strlen 和 strcpy#

理解原理最好的方式是自己实现一遍：

C
size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p != '\0') {
        p++;
    }
    return (size_t)(p - s);     // 指针相减 = 元素个数
}

char *my_strcpy(char *dst, const char *src) {
    char *ret = dst;
    while ((*dst++ = *src++) != '\0') {
        ;                       // 空循环体，所有工作都在条件里完成
    }
    return ret;
}

while ((*dst++ = *src++) != '\0') 这一行是 C 的经典写法：先赋值、再判断、最后各自后移。看懂它，说明你对指针和表达式的理解到位了。

■安全输入

读字符串永远不要用 gets（已从标准中删除，会溢出）。用 fgets(buf, sizeof(buf), stdin) —— 它保证不越界，但会把换行符 '\n' 也读进来，需要手动处理：buf[strcspn(buf, "\n")] = '\0';
