第 6 章 指针基础

预计 15 分钟·约 3,183 字·C 语言进阶

6.1 内存、地址与变量#

把内存想象成一排编了号的小格子，每个格子 1 字节，编号就是地址。当你写 int a = 42; 时，编译器做了三件事：找一块连续 4 字节的空地、把 42 按二进制写进去、把这块地的起始地址和名字 a 绑定起来。

C
内存（简化示意，每格代表 4 字节）：

地址     0x100      0x104      0x108      0x10C
       +----------+----------+----------+----------+
       |    42    |          |          |          |
       +----------+----------+----------+----------+
            ↑
            a 就住在这里，a 的值是 42，a 的地址是 0x100

所以一个变量其实有两层信息：它的值（42）和它的地址（0x100）。平时我们只用值，指针让我们能直接操作地址。

C
#include <stdio.h>

int main(void) {
    int a = 42;

    printf("a 的值   = %d\n", a);          // 42
    printf("a 的地址 = %p\n", (void *)&a); // 0x7ffd... 之类的十六进制

    return 0;
}

& 是取地址运算符，%p 用来输出地址。注意要强制转换成 (void *)，因为 %p 期望的是 void 指针，直接传 int* 在严格编译下会报警告。

■注意

每次运行程序，变量的地址都可能不同（操作系统会做地址随机化）。所以地址的具体数值不重要，重要的是「谁指向谁」这层关系。做题时如果看到地址变化，不要慌。

6.2 指针的定义与使用#

指针就是一个专门用来存地址的变量。定义时在类型后面加一个星号：

C
int  *p;      // p 是「指向 int 的指针」，里面存的是一个 int 的地址
double *q;    // q 是「指向 double 的指针」
char *r;      // r 是「指向 char 的指针」

完整的用法分两步：先让指针指向某个变量，再通过指针读写那个变量：

C
int a = 42;
int *p = &a;        // p 指向 a（把 a 的地址存进 p）

printf("%d\n", *p); // 42    解引用：取出 p 所指地址里的值
*p = 100;           // 通过指针修改
printf("%d\n", a);  // 100   a 跟着变了

内存里的关系是这样的：

C
        a                    p
   +---------+          +-----------+
   |   100   |  ←────── |  0x100    |
   +---------+          +-----------+
     0x100                0x200
   （int，4 字节）      （指针，8 字节）

p 自己也有地址（0x200），它的值是 0x100，也就是 a 的地址。所以 *p 就是「去 0x100 这个地方取值」，取到的自然是 a。

星号 * 在 C 里有两个身份，这是初学最大的混淆点：

出现位置含义例子
类型声明中说明「这是个指针」int *p; → p 的类型是 int*
表达式中解引用，取所指地址的值*p = 5; → 修改 p 指向的内容
C
int *p;          // 这里的 * 是"类型的一部分"
int x = *p;      // 这里的 * 是"运算符"
int y = *p * 2;  // 第一个 * 解引用，第二个 * 是乘法

初学建议：定义时把星号贴着变量名写（int *p），不要写成 int* p。因为 int *p, q; 里只有 p 是指针，q 是普通 int——星号只作用于紧跟的那个变量。

6.3 指针的大小与类型#

一个常见的误解：指针的大小和它指向的类型有关。其实无关。

C
printf("%d\n", (int)sizeof(int *));     // 8（64 位系统）
printf("%d\n", (int)sizeof(char *));    // 8
printf("%d\n", (int)sizeof(double *));  // 8
printf("%d\n", (int)sizeof(int **));    // 8

指针存的是一个地址，地址的长度由 CPU 决定：64 位系统就是 8 字节，32 位系统是 4 字节。不管指向 int 还是 struct，指针本身都是这么大。

那类型有什么用？两个作用，都很关键：

  1. 决定解引用时读几个字节。int* 解引用读 4 字节，char* 读 1 字节，double* 读 8 字节。
  1. 决定指针加 1 时跳过几个字节。这就是指针运算的规则，见 6.5 节。
C
int a = 0x12345678;
int *p = &a;
char *c = (char *)&a;      // 强制转换后，c 指向同一个地址

printf("%d\n", *p);        // 305419896，完整读出 4 字节
printf("%x\n", *c);        // 78，只读了最低 1 字节（小端机器）
▲易错点

不同类型的指针不能随便赋值。int *p; double *q = p; 会报警告（incompatible pointer type），因为它们解引用时读的字节数不同，强行赋值会导致读到错误的数据。需要转换时写显式强制转换。

6.4 空指针与野指针#

指针不初始化时，里面是栈上的垃圾值——它指向一个随机的、可能非法的地址，这叫野指针。对野指针解引用，轻则读到垃圾数据，重则程序当场崩溃。

C
int *p;         // 野指针！里面是垃圾值
*p = 10;        // 未定义行为：往一个随机地址写数据

规范做法：定义时就初始化，暂时不知道指向哪里就赋 NULL。

C
int *p = NULL;          // 空指针：明确表示"不指向任何地方"

if (p != NULL) {        // 使用前检查
    *p = 10;
}

NULL 在标准库里定义为 ((void *)0)，本质上就是地址 0。现代操作系统会把地址 0 所在的内存页标记为不可访问，所以对 NULL 解引用通常会立刻触发段错误——这其实是好事，问题能马上暴露，而不是悄悄改坏别处。

野指针的三种来源说明防范
定义后未初始化int *p; 直接用定义时赋 NULL
free 之后继续用内存已归还，指针还指着free(p); p = NULL;
指向已退出的局部变量函数返回后地址失效不返回局部变量的地址
■好习惯

free(p) ; p = NULL; 这两句永远成对出现。这样即使后面不小心再用到 p，也会因为解引用 NULL 而立即崩溃，而不是悄悄改坏已经分配给别人的内存。让错误尽早暴露，是 C 编程的重要原则。

6.5 指针运算#

指针可以做加减运算，但规则和普通整数不同：加 1 不是地址加 1，而是加一个元素的大小。

C
int a[5] = {10, 20, 30, 40, 50};
int *p = a;            // 指向 a[0]

// 假设 a 的起始地址是 0x100，int 占 4 字节
// p      → 0x100
// p + 1  → 0x104   不是 0x101
// p + 2  → 0x108

通用规则：

C
p + n 的地址 = p 的地址 + n * sizeof(*p)

正因为这个规则，指针才能自然地遍历数组——p++ 自动跳到下一个元素，不用关心元素多大。

其他运算规则：

运算是否合法说明
p + n、p - n合法地址偏移 n 个元素
p++、p--、++p合法指向下一个/上一个元素
p1 - p2合法两个指针相差几个元素（要求指向同一数组）
p1 < p2、p1 == p2合法比较地址先后
p1 + p2非法两个地址相加没有意义
p * 2、p / 2非法指针不能乘除
C
int a[5] = {10, 20, 30, 40, 50};
int *p = &a[1];
int *q = &a[4];

printf("%d\n", q - p);      // 3：中间隔了 3 个元素
printf("%d\n", *(p + 2));   // 40：等价于 a[3]
▲易错点

两个指针相减的前提是它们指向同一个数组。指向不同数组（或不同变量）的两个指针相减，结果是未定义的，编译器不会拦你。
