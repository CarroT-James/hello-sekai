习题一 数组综合练习

预计 10 分钟·约 1,046 字·C 语言进阶

建议先独立完成，卡住超过 20 分钟再看提示。基础题保证全对，进阶题至少写出思路。

基础题#

【1-1】数组求和与平均 基础

输入 10 个整数存入数组，输出总和、平均值（保留两位小数）、最大值和最小值。

提示：平均值记得用 (double) 强转。

【1-2】逆序输出 基础

输入 n（n ≤ 100）个整数，分别用「原数组逆序输出」和「原地逆序后正序输出」两种方式实现。

提示：原地逆序用双指针 i、j 向中间靠拢。

【1-3】统计数字 基础

输入 20 个 0~9 之间的整数，统计每个数字出现的次数并输出。

提示：开一个 cnt[10] 数组，用值当下标。

【1-4】删除指定元素 基础

输入 n 个整数，再输入一个值 x，删除数组中所有等于 x 的元素，输出剩余元素个数和内容。

提示：用双指针：一个读、一个写，相等的跳过。这样一趟就能完成。

【1-5】矩阵转置 基础

输入一个 3×4 的矩阵，输出它的转置（4×3）。

提示：转置后 b[j][i] = a[i][j]。

【1-6】对角线求和 基础

输入一个 n×n 的方阵，分别求主对角线和副对角线的元素之和。

提示：注意 n 为奇数时中心元素被两条对角线共用。

进阶题#

【1-7】冒泡排序与统计 进阶

输入 n 个整数，用冒泡排序升序输出，同时输出排序过程中的交换次数。

提示：在交换的地方计数即可。

【1-8】二分查找插入位置 进阶

给定一个已升序排列的数组和一个目标值，返回它应该被插入的位置（保持有序）。若已存在，返回其下标。

提示：二分查找的变体：循环结束时 lo 就是插入位置。

【1-9】矩阵乘法 进阶

输入两个矩阵 A（m×n）和 B（n×p），输出 A×B。

提示：三重循环，最内层是点积；先给 c[i][j] 清零。

【1-10】杨辉三角 进阶

输入行数 n（≤ 20），用二维数组输出杨辉三角的前 n 行。

提示：a[i][0] = a[i][i] = 1，其余 a[i][j] = a[i-1][j-1] + a[i-1][j]。

【1-11】数组去重 进阶

输入 n 个整数，删除重复元素（保留第一次出现的），按原顺序输出。

提示：可以开一个标记数组，或对每个元素往前扫一遍看是否出现过。

【1-12】统计字符（用数组模拟） 进阶

输入一行字符串（不超过 100 字符），统计其中大写字母、小写字母、数字、空格和其他字符的个数，不允许使用 ctype.h。

提示：用 char 数组存字符串，靠 '\0' 判断结束。
