学习路线

不需要按目录从头磕到尾。先对号入座，选一条适合你的路线。

先确认你在哪个阶段#

你的情况建议起点大概要花多久
没写过任何代码C 入门册 第 0 章8 周
上过 C 课，但指针、数组一知半解C 入门册 第 5 章 + 进阶册6 周
只想快速写个脚本处理数据Python 第 1 课2 周
要参加算法竞赛 / 课程设计数据结构 + C 实战册持续

路线一：完全零基础（推荐 8 周）#

第 1\~2 周：能跑起来。从 第 0 章 开始之前 开始，装好 Dev-C++，跑通第一个程序，然后一路学到 第 2 章 运算。目标只有一个：看到报错不慌，知道去哪找行号。

第 3\~4 周：能写逻辑。第 3 章 流程控制 和 第 4 章 函数。学完你应该能独立写出「判断闰年」「九九乘法表」「求 1 到 100 的和」，而且不用抄。

第 5\~6 周：能存数据。第 5 章 数组 是第一个坎，第 6 章 指针 是第二个坎。卡住很正常——被指针卡住的人比你想的多得多。技巧是：先接受「指针就是存地址的变量」，然后反复画内存图。

第 7\~8 周：能组合起来。第 7 章 结构体 和 第 8 章 算法入门，最后用 第 9 章 综合实战 的两个项目收尾。到这里你已经能写一个几百行、带菜单、能增删改查的程序了。

★每周配合刷题

学到哪一章，就去刷题页做对应难度的题。看懂了不等于写对了，判题会告诉你差在哪。

▲不要做的三件事
  1. 不要同时开三本书。一本走完再开第二本。
  2. 不要只看不写。看懂和写对之间差着十万八千里。
  3. 不要在装环境上折腾一整天。装不上就先问人。

路线二：学过 C，但没学明白#

如果你能看懂 for 循环，但一写指针就懵，问题通常不在语法，而在内存模型没建立起来。

  1. 先把 第 5 章 数组 的「数组在内存里长什么样」重看一遍，动手画下标和地址的对应关系。
  2. 再进 进阶册 第 1 章 一维数组，把 sizeof、越界、传参退化成指针这三件事搞清楚。
  3. 然后从 进阶册 第 6 章 指针基础 一路到 第 9 章 指针与字符串，每节的代码都手敲。
  4. 最后做 习题二 指针专项，做完对答案。

这条路线大概 6 周。时间紧就至少过完第 6、7、8 三章——指针搞懂了，后面全是顺的。

路线三：只想用 Python 干活#

Python 不需要先学 C。直接进 Python 第 1 课。

  • 第 1 周：第 1\~4 课。目标：能读懂别人的小脚本。
  • 第 2 周：第 5\~8 课。目标：能自己写一个处理 CSV 或 JSON 的脚本。
  • 第 3\~4 周：第 9\~12 课（类、继承、模块、正则）。目标：能拆成多文件、能装第三方库。
  • 第 5\~6 周：第 13\~16 课（标准库、数据处理、网络、项目）。目标：能写一个带命令行参数和单元测试的小工具。
▲前提

Python 的「简单」是语法简单，不是能少想。写不出程序，通常不是语法问题，是不知道怎么把问题拆成步骤。

路线四：数据结构与竞赛#

竞赛要的是熟练度和算法，不是语言特性。

  • 语言层面：把 入门册 第 8 章 的排序、查找吃透，会手写冒泡、选择、插入、二分。
  • 数据结构：数据结构板块 12 课按顺序过，每课的代码自己敲一遍。链表、栈、队列、树、哈希表这五个必须能手写。
  • 刷题层面：每天 2 道，坚持一个月比周末突击 20 道有用。
  • 课程设计：直接看 第 9 章 综合实战 和 C 实战册，这两个是真实项目的骨架。

路线五：把计算机基础补上#

计算机基础板块 的 8 课，建议在大一结束前看完。它不影响你写作业，但决定你以后看文档、查错误、用命令行时是不是每次都得求人。

最优先的三课：进制与编码（不然你永远不明白为什么中文乱码）、命令行（不然你只会用鼠标）、Git（不然你的代码只有「最终版\_v3\_真的最终.zip」）。

每周花多少时间#

在校生每周 4\~5 小时足够：

  • 2 小时读课 + 敲代码
  • 2 小时做练习题
  • 0.5 小时订正错题

比时间更重要的是一周里至少碰三次。隔一周不碰，忘得比你想象的快。

常见问题#

Q：一定要装 Dev-C++ 吗？不一定。VS Code + GCC 也行，但新手配置容易卡住。Dev-C++ 最省事，先跑起来最重要。（但是VS Code真的很好用awa）

Q：C 和 C++ 要一起学吗？不要。先把 C 学到能写小项目，再开 C++。同时学会把两套语法搅在一起。

Q：Python 和 C 谁先学？看你目的。要打基础、以后学嵌入式或系统课，先 C；要做数据处理、爬虫、AI，直接 Python。

Q：看不进去怎么办？把一章拆成三节，一次只看一节，看完立刻敲一遍。别指望一口气读完一章。

Q：判题判错了但我不知道错哪？判题页会把「期望输出」和「你的输出」并排给你看，还会指出第几行不一致。善用它。
