01第 1 课 认识 Python，跑通第一个程序从下载安装到跑出第一行输出：配好 Windows 环境，用 print 和 input 写一个能对话的小程序。20 分钟02第 2 课 变量、类型与运算变量不是盒子，而是贴在值上的名字。这一课讲清赋值、五种基本类型、类型转换和除法规则，最后写一个计算器。25 分钟03第 3 课 字符串与文本处理引号、转义、下标、切片、f-string 和常用方法一次讲完，最后用六行代码统计一句话里的单词。25 分钟04第 4 课 列表、元组、字典与集合四种容器一次认全：列表能改、元组不能改、字典按名字找、集合自动去重，最后用它们算一张成绩表。30 分钟05第 5 课 条件、循环与缩进缩进划出代码块，if 做判断，for 遍历一串东西，while 转到达成条件。这一课把程序的三种基本走法讲透。35 分钟06第 6 课 函数与参数把代码装进函数、起个名字反复用。这一课讲参数、返回值、作用域、lambda，还有那个坑过无数人的可变默认参数。35 分钟07第 7 课 文件、编码与异常处理程序一关，变量就没了。这一课把数据存进文件，顺带讲清编码、csv、json 和异常处理。40 分钟08第 8 课 常用标准库与项目实战先认识几个够用的标准库，再动手写一个完整项目：能读数据、能排序、能查询、能退出的班级成绩管理程序。45 分钟09第 9 课 类与对象：把数据和行为装进一个盒子一个学生有姓名、有分数，还该会算平均分。先用生活里的例子把「数据和动作打包」讲透，再动手写第一个 class。30 分钟10第 10 课 继承与魔法方法：子类少写一遍，对象学会比较研究生也是学生。把公共字段提到父类，子类只写多出来的部分；再让对象会比较、能被 len 量、还能像属性一样读。32 分钟11第 11 课 模块、包与虚拟环境：把代码拆成能互相借用的文件一个 .py 文件就是一个模块。讲清 import 做了什么、怎么拆自己的代码，以及为什么每个项目都该有 venv。32 分钟12第 12 课 正则表达式：给文本画一张形状一串符号能顶二十行字符串判断。从「在一堆文本里找形状」讲起，把 re 的五个函数、量词和分组讲透，最后清洗一段脏数据。33 分钟13第 13 课 常用标准库：六个模块顶掉一半手写循环时间、路径、计数、排列组合、随机、JSON。六个标准库模块够日常用，不用背，知道遇到问题该翻谁就行。33 分钟14第 14 课 数据处理入门：从 csv 到一张班级报表读 csv、数数、排序、算平均和中位数，用纯 Python 出一份班级报表，再说清 pandas 到底解决了什么。34 分钟15第 15 课 网络与接口：一次请求里到底装了什么地址栏回车之后发生了什么？拆开 HTTP 请求，用 requests 调接口、读 JSON、认状态码，再说清爬虫的边界。34 分钟16第 16 课 项目：一个能测试的命令行工具用 argparse 收参数，把逻辑拆成能单独测的模块，再用 unittest 给自己上保险。写完就有个能交付的小项目。35 分钟
