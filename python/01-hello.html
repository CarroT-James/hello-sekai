第 1 课 认识 Python，跑通第一个程序

预计 20 分钟·约 4,870 字·Python

如果这是你第一次写程序，先记住一件事：编程不是背语法，而是把你想让电脑做的事，拆成一条条它能照做的指令。Python 是目前最接近「人话」的编程语言之一，这一课从零开始，把环境装好，把第一行输出跑出来。

1.1 Python 是什么#

Python 是一门编程语言，1991 年发布，名字来自喜剧团体 Monty Python，跟蟒蛇没关系。它今天用在数据分析、人工智能、网站后端、自动化脚本这些地方，特点就三个：代码短、读起来接近英语、自带一大堆现成工具。

一段 Python 程序就是一个后缀为 .py 的文本文件，里面按顺序写着指令。你双击它不会像双击 Word 文档那样直接看到结果，因为 Windows 不认识 .py 里的内容，得请一个叫解释器的程序来读。解释器从第一行开始，读一行、执行一行，执行完再读下一行。

比如这两行：

Python
print("Hello, World")
print("我在学 Python")
运行结果
Hello, World
我在学 Python

print 的意思是「打印」，括号里放什么，屏幕上就显示什么。引号是给解释器看的标记，它告诉 Python「引号里是一段文字，原样输出，别当成代码」，引号本身不会显示。

解释执行的好处是改完保存就能再跑，没有「先整体翻译成 exe」这一步。代价是 Python 运行速度不算快，但对入门阶段写的程序来说，这个差别你基本感觉不到。

◆记忆点

.py 文件是写给人看的源码，python 这个程序负责读它。你写代码，解释器干活。

1.2 在 Windows 上安装 Python#

  1. 打开浏览器，访问 python.org。首页会自动识别 Windows，点黄色的 Download Python 3.x.x 按钮。
  2. 下载完双击安装包。第一屏最下面有个勾选框，一定要勾上 Add python.exe to PATH（旧版本写作 Add Python 3.x to PATH），然后点 Install Now。
  3. 等进度条走完，点 Close。安装程序会顺便装好 pip 等工具，不用管。
  4. 按 Win 键，输入 cmd，回车打开「命令提示符」。在黑窗口里敲 python --version，回车。
  5. 看到 Python 3.12.14 这样的一行，说明装好了。版本号比你新或旧一点都没关系，3.10 以上都能跑本课的代码。

PATH 是系统里的一份目录清单。你在命令行敲一个名字，Windows 会去清单里的目录挨个找有没有这个程序。安装时勾了 Add to PATH，安装程序才会把 Python 的目录写进这份清单；不勾，你敲 python 系统就找不到，还可能跳转到微软商店。

▲常见错误

装完 Python 后，之前打开的旧命令行窗口不会自动更新 PATH。一定要关掉旧窗口，重新开一个再敲 python --version。如果还是提示「不是内部或外部命令」，九成是安装时没勾 PATH：重新运行安装包选 Modify 补勾，或者卸载重装。

1.3 写第一个程序，用命令行运行#

命令行看起来复古，但它是和电脑对话最直接的方式。它总有一个「当前目录」，cd 就是切换当前目录的命令。

  1. 打开「此电脑」，在 D 盘新建文件夹 python-learn。路径尽量短，别藏得太深。
  2. 在这个文件夹里新建 hello.py。用记事本也行，保存时文件名带引号写成 "hello.py"，保存类型选「所有文件」，编码选 UTF-8，否则容易变成 hello.py.txt。
  3. 回到命令行，敲 cd /d D:\python-learn 切过去。/d 表示允许跨盘符切换，从别的盘切到 D 盘必须加。
  4. 敲 dir，确认列表里有 hello.py。
  5. 敲 python hello.py。
Python
print("Hello, World")
print("我的第一个 Python 程序")
Shell
cd /d D:\python-learn
python hello.py
运行结果
Hello, World
我的第一个 Python 程序

python hello.py 这行命令分两部分：python 让系统启动解释器，hello.py 是交给解释器的文件。解释器打开文件，从上往下执行，执行完退出，回到命令行。

▲常见错误

三种报错对应三个不同的问题。'python' 不是内部或外部命令：PATH 没配好，回到 1.2 节。can't open file 'hello.py'：当前目录不对，hello.py 不在你站的地方，用 cd 切过去。SyntaxError：代码里有拼写或标点问题，最常见的是用了中文引号，或者在 print 后面漏了括号。

1.4 REPL 与 VS Code#

命令行直接敲 python（后面不跟文件名），会进入交互模式，提示符变成 >>>。这里敲一行算一行：

TEXT
>>> 1 + 2
3
>>> print("hi")
hi
>>> exit()

>>> 是 Python 打印的提示符，不是你该输入的内容。这种环境叫 REPL（Read-Eval-Print Loop，读入、求值、打印、循环），试语法、算个数、看某个东西返回什么，用它最快。退出敲 exit()，或者按 Ctrl+Z 再回车。REPL 里敲的东西关掉窗口就没了，所以真正写程序还是得用文件。

写文件推荐 VS Code：去 code.visualstudio.com 下载 Windows 版，安装时勾上「添加到 PATH」。装完打开，在左侧扩展面板搜索 Python，安装微软官方那个扩展。然后用「文件 → 打开文件夹」打开 D:\python-learn，新建 hello.py，编辑区右上角会出现三角形运行按钮，点一下，结果出现在下面的终端里。

第一次运行时，VS Code 可能让你选解释器：按 Ctrl+Shift+P，输入 Python: Select Interpreter，选中你刚装的那个 Python 3.x。选一次以后它就记住了。

VS Code 的好处是「写、跑、看报错」在同一个窗口，改一行按一次运行，循环越短，学得越快。

1.5 print() 的逗号和两个开关#

print() 是最常用的函数。括号里可以放好几件事，用逗号隔开，它会按顺序输出。数字不用引号，Python 会先算出结果；字符串必须用引号包起来。

Python
print("一年有", 365, "天")
print(1 + 2)
print("1 + 2")
print("2024", "01", "05", sep="-")
print("处理中", end="")
print("...完成")
print("A", "B", sep="", end="!\n")
运行结果
一年有 365 天
3
1 + 2
2024-01-05
处理中...完成
AB!

前三个 print 的差别值得停一下。第一行的逗号会被换成一个空格，所以输出是「一年有 365 天」。第二行没有引号，Python 先算 1 + 2，把结果 3 打出来。第三行有引号，1 + 2 就是三个字符，原样输出。

后四行动的是两个默认值：

  • sep 管多个参数之间用什么隔开，默认是一个空格
  • end 管打印完结尾加什么，默认是换行符 \n

sep="-" 把日期连成 2024-01-05；end="" 让这一行打印完不换行，下一句 print 的输出直接接在后面，于是有了 处理中...完成；最后一行的 sep="" 去掉 A 和 B 之间的空格，end="!\n" 让结尾先输出感叹号再换行。写进度提示、拼一行文字时，这两个参数很常用。

◆记忆点

sep 管中间，end 管结尾。默认值是 sep=" "、end="\n"。

1.6 input()：让程序开口问你#

print 负责输出，input 负责输入。括号里的文字是提示语，会先打印出来，然后程序停下来等你敲字，按回车后把你敲的内容交回来：

Python
name = input("你叫什么名字？")
print("你好，" + name)

age = int(input("你多大了？"))
print("明年你就", age + 1, "岁了")
运行结果
你叫什么名字？小明
你好，小明
你多大了？18
明年你就 19 岁了

name = input(...) 里的 = 是赋值：把等号右边得到的内容存进左边的名字里。下一行用 + 把「你好，」和 name 里的内容拼起来。

这里有个所有新手都会踩的坑：input() 拿回来的永远是字符串。你敲 18，得到的是文字 "18"，不是数字 18。第二段套了一层 int()，把它转成整数，age + 1 才能算。要是去掉 int()，"18" + 1 会报 TypeError，因为文字和数字不能相加。

▲常见错误

引号必须是英文引号 " 或 '。中文输入法下的引号 “” 看起来差不多，Python 不认识，会直接报 SyntaxError: invalid character。写代码时把输入法切到英文。

1.7 缩进：Python 用空格划分代码块#

到这一节，你已经能写一行行按顺序执行的代码了。但程序经常需要「满足条件才做某件事」，这时就要把几行代码划成一组。Python 的划法很特别：用缩进。

下面这段出现了 if，第 5 课才正式讲，现在你只看它的形状：

Python
score = 85

if score >= 60:
    print("及格了")
    print("分数是", score)

print("程序结束")
运行结果
及格了
分数是 85
程序结束

if score >= 60: 末尾的冒号表示「下面是我的地盘」。紧跟着的两行 print 往右缩进了 4 个空格，表示它们属于这个 if，只有分数大于等于 60 才会执行。最后一行退回最左边，表示它又回到了外层，不管分数多少都会执行。

规矩只有两条：

  • 同一组的代码，左边必须对齐，多一个空格少一个空格都会报错
  • 下一层比上一层多缩进 4 个空格

Python 不让你随便缩进：对齐错了，程序连跑都不跑，直接抛 IndentationError。这看起来严格，其实省事——你读别人的代码时，看缩进就知道哪几行是一组的。

▲常见错误

不要用 Tab 键缩进，也不要一会儿 Tab 一会儿空格。Python 3 不允许同一个文件里混用，混了会报 TabError。在 VS Code 右下角把缩进设成「空格: 4」，然后一直用空格。

◆小结
  • Python 程序写在 .py 文件里，由 python 解释器逐行读取执行
  • Windows 安装时勾上 Add python.exe to PATH；装完新开命令行，用 python --version 验证
  • 命令行里 cd 切到文件所在目录，再 python hello.py 运行
  • print() 用逗号分隔多项，sep 管中间，end 管结尾
  • input() 返回的永远是字符串，要算数先用 int() 或 float() 转换
  • 缩进就是语法，同一组代码必须对齐，一层 4 个空格
  • 下一课：第 2 课 变量、类型与运算，讲变量名和值到底是什么关系
✎练习
  1. 装好 Python 后，在命令行运行 python --version 和 python -c "print(1 + 1)"，把两条命令的输出记下来。
  2. 写一个 intro.py，用三行 print 输出你的名字、专业和一句今天的心情。
  3. 用 input() 读入两个整数，输出它们的和与积。先故意不写 int() 跑一次，看看报错长什么样，再改对。
  4. 用一次 print 输出 2024|01|05，再用一次输出 2024-01-05，要求只改一个参数。
