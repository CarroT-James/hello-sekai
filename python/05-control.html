第 5 课 条件、循环与缩进

预计 35 分钟·约 5,361 字·Python

前面几课的代码都是从第一行按顺序执行到最后一行。但程序得会拐弯：分数够了才打印「及格」，一百个数要挨个处理，猜数字要一直问到猜中为止。这一课讲三件事：怎么把代码划成一组、怎么按条件选择、怎么重复执行。

5.1 缩进就是语法#

Python 用缩进表示「这几行属于上面那一块」。上一行以冒号结尾，下面缩进的行就是它的地盘；缩进退回去，这一块就结束了。

看一个完整的例子：

Python
score = 85

if score >= 60:
    print("及格了")
    print("分数是", score)

print("程序结束")
运行结果
及格了
分数是 85
程序结束

if score >= 60: 末尾的冒号表示「下面是我的代码块」。紧跟着的两行 print 往右缩进 4 个空格，表示它们受 if 管，只有分数大于等于 60 才执行。最后一行退回最左边，表示它回到了外层，不管分数多少都会执行。

规矩只有两条：

  • 同一组的代码，左边必须对齐，多一个空格少一个空格都会报错
  • 下一层比上一层多缩进 4 个空格

缩进错了，程序连跑都不跑，直接报 IndentationError。比如把上面两行 print 顶格写，会看到这样的报错：

TEXT
    print("及格了")
    ^^^^^
IndentationError: expected an indented block after 'if' statement on line 2

意思是：第 2 行的 if 后面应该跟一个缩进的代码块，你没给。这类错误叫语法错误，Python 在运行前就检查出来了，一行都不会执行。报错信息会指到具体行号，照着改就行。

▲常见错误

三种写法最容易把缩进搞坏。忘了写冒号，报 SyntaxError: expected ':'；有的行用 Tab、有的行用空格，报 TabError；从网页复制代码，混进了全角空格，报 IndentationError 或 SyntaxError: invalid character。把编辑器设成「Tab 插入 4 个空格」，并且只从可信的地方复制代码。

★为什么缩进能当语法

缩进本来就是你读代码时的视觉线索。Python 把它变成硬性规定：看到哪几行对齐，就知道它们是一组，不用再找别的标记。代价是复制粘贴时容易带错对齐，所以改完代码先扫一眼左边。

5.2 if / elif / else 与真值判断#

Python
score = 78

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

name = ""
if name:
    print(f"你好，{name}")
else:
    print("名字是空的")

nums = []
if not nums:
    print("列表是空的")
运行结果
及格
名字是空的
列表是空的

elif 是 else if 的缩写，想写几个写几个。Python 从上往下检查，命中一个就执行那一个块，后面的全部跳过，所以顺序很重要：先写 >= 90，再写 >= 60。写反了，90 分以上的人也会先命中 >= 60，一屋子全是「及格」。

条件不用括号。写成 if (score >= 90): 也能跑，但 Python 程序员不这么写。另外 = 是赋值，== 才是比较：if score = 90: 会直接报 SyntaxError，少写一个等号在运行前就会被抓住。

真值判断#

Python 里任何对象都能直接当条件，不用写 > 0 或 != ""。规则只有一条：空的东西、零、None、False 是假，其他都是真。

假的东西一共就这些：0、0.0、""、[]、()、{}、set()、None、False。

所以 if len(nums) > 0: 可以写成 if nums:，反过来 if not nums: 就是「列表是空的」。这是 Python 里最常见的写法之一，读别人代码一定会遇到。

副作用是 0 和 "" 也算假，所以判断 None 时要写 if x is None:，别写 if not x:，不然 0 会被你当成「没有值」。

▲常见错误

if x == None: 能跑，但规范写法是 if x is None:。None 全程序只有一个，用 is 判断身份比用 == 判断相等更准，也更快。

5.3 while：条件成立就一直转#

Python
total = 0
i = 1
while i <= 100:
    total += i
    i += 1

print(total)
运行结果
5050

while 的流程是：先判断条件，成立就执行循环体，执行完回到条件再判断一次，直到条件不成立才往下走。上面这段把 1 到 100 加起来，i 从 1 开始，每轮加 1，加到 101 时条件不成立，循环结束。

循环体里一定要有让条件最终变假的动作。漏掉 i += 1，i 永远是 1，条件永远成立，程序卡在那里不动。这叫死循环，在终端里按 Ctrl+C 能强制停下。

死循环不总是错误。while True: 配一个 break 是最常见的写法：条件永远真，靠循环体里的 break 决定什么时候走。5.6 节的猜数字就是这种结构。

▲常见错误

while 的条件里用到的变量，一定要保证它最终会变。少写一句 i += 1，程序不报错，只是永远转下去。这种 bug 比报错难查得多，因为屏幕上什么提示都没有。

5.4 for 是遍历#

for 只有一个意思：把一串东西挨个拿出来。句式是 for 变量 in 容器:，缩进下面是循环体，读作「对于容器里的每一个 x，做下面这些事」。容器可以是列表、字符串、字典，也可以是 range() 造出来的一串数字。

Python
for ch in "Python":
    print(ch)

for n in range(5):
    print(n, end=" ")
print()

for n in range(1, 10, 2):
    print(n, end=" ")
print()

names = ["小明", "小红", "小刚"]
for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")

scores = [88, 95, 62]
for name, score in zip(names, scores):
    print(f"{name}：{score}")

nums = [1, 2, 2, 3]
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)
运行结果
P
y
t
h
o
n
0 1 2 3 4 
1 3 5 7 9 
1. 小明
2. 小红
3. 小刚
小明：88
小红：95
小刚：62
[1, 2, 3]

逐条看：

  • for ch in "Python" 把字符串当字符序列，一次吐一个字符
  • range(5) 生成 0、1、2、3、4，不含 5。想从 1 数到 5 要写 range(1, 6)。
  • range(1, 10, 2) 的第三个参数是步长，得到 1、3、5、7、9。写 range(10, 0, -1) 就是倒着数。
  • enumerate(names, start=1) 一次给你下标和值。别写 for i in range(len(names)): 再取 names[i]，又长又容易越界。
  • zip(names, scores) 像拉链一样把两个列表对上，一次拿一对。两个列表不一样长时以短的为准，多出来的直接丢掉。
▲常见错误

别在遍历列表的时候删它的元素。看上面最后那段：本想把 2 全删掉，结果还剩下一个。for n in nums: 内部是按位置往后走的，你删掉一个，后面的元素全体前移，循环正好跳过它。想删就遍历副本 for n in nums[:]:，或者用列表推导式生成一个新列表，更干净。

5.5 跳出循环与嵌套循环#

Python
for n in [3, 7, 12, 5]:
    if n == 12:
        print("找到 12，跳出")
        break
    print(n)

for n in range(1, 6):
    if n % 2 == 0:
        continue
    print(n, end=" ")
print()

for n in range(1, 6):
    if n == 3:
        print("找到 3")
        break
else:
    print("没找到 3")

for n in range(1, 6):
    if n == 9:
        print("找到 9")
        break
else:
    print("没找到 9")
运行结果
3
7
找到 12，跳出
1 3 5 
找到 3
没找到 9
  • break 立刻跳出最近的一层循环。两层嵌套时，它只跳出里面那层，外面的继续转。
  • continue 跳过本次剩下的代码，直接进下一次。上面的例子用它只打印奇数。
  • for ... else 是 Python 的一个特别设计。else 里的代码在循环「正常跑完」时执行；中途被 break 打断，就不执行。

for ... else 第一次看很反直觉，因为它和 if ... else 没有半点关系。把它读成「没被 break 才执行」就顺了。典型用途是查找：翻完所有元素都没找到，才说「没有」。找 9 的那个循环跑完了，else 执行；找 3 的那个 break 了，else 跳过。

用嵌套循环打印图形#

Python
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
运行结果
*
**
***
****
*****

外层 for i in range(1, 6) 管行，i 就是这一行该有几个星号。内层 for j in range(i) 负责在一行里重复打印。

两个细节：print("*", end="") 的 end="" 表示打印完不换行，默认是 end="\n"；内层结束后单独一句 print() 输出一个空行，也就是换行。

把 range(1, 6) 改成 range(1, 4)，三角形就矮两行。这个图形其实一行就能画：print("*" * i)。但两层循环各管一件事，能画 * 拼不出来的东西，比如九九乘法表那种二维表。

5.6 完整程序：猜数字#

Python
answer = 42
count = 0

print("我想了一个 1 到 100 之间的数，你猜。")
while True:
    text = input("猜一个数（1~100）：").strip()
    if not text.isdigit():
        print("请输入数字。")
        continue

    guess = int(text)
    count += 1

    if guess > answer:
        print("大了")
    elif guess < answer:
        print("小了")
    else:
        print(f"对了，就是 {answer}。你猜了 {count} 次。")
        break
运行结果
我想了一个 1 到 100 之间的数，你猜。
猜一个数（1~100）：50
大了
猜一个数（1~100）：25
小了
猜一个数（1~100）：38
小了
猜一个数（1~100）：42
对了，就是 42。你猜了 4 次。

拆开看：

  • answer = 42 把答案写死，这样输出才固定。想变成真游戏，换成 random.randint(1, 100)，第 8 课讲 random。
  • while True: 一直循环，唯一的出口是猜对时的 break。
  • input() 拿回来的一定是字符串，.strip() 去掉两头空格，防止你手滑多敲一个空格。
  • .isdigit() 判断是不是纯数字。不是就打印提示，然后 continue 重新问，这次不算次数。
  • 三个分支处理大了、小了、对了。对的时候打印次数再 break，一步都不能少。
  • count 在循环外面初始化。放在循环里，每轮都会被清零，永远显示 1 次。

如果删掉那个 break，猜对之后程序还会接着问。它不报错，只是永远停不下来——这又是一个死循环的例子。

◆小结
  • 缩进是语法，冒号加 4 个空格，别混 Tab
  • if / elif / else 从上往下，命中一个就停
  • 空列表、空字符串、0、None 都是假，所以 if nums: 就是「非空」
  • while 的条件里那个变量必须最终会变，while True 配 break 才是常态
  • for 是遍历，range() 造数字，enumerate() 拿下标，zip() 配两个列表
  • for ... else 的 else 在没被 break 打断时才执行
  • 上一课是 第 4 课 列表、元组、字典与集合，下一课 第 6 课 函数与参数 把重复的代码打包起来
