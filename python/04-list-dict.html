第 4 课 列表、元组、字典与集合

预计 30 分钟·约 5,871 字·Python

存一个分数，一个变量就够了；存一个班的分数，就得上容器。Python 有四种常用容器，各有各的脾气：列表像一张可以随时加行删行的清单，元组像一张写死了的卡片，字典像通讯录，集合像一个自动去重的收纳袋。选错了写起来别扭，选对了代码能短一半。这一课挨个过一遍，最后拿它们算一次成绩。

4.1 列表：能装一串东西#

列表用方括号写，元素之间用逗号隔开，顺序就是它记住的顺序：

Python
scores = [90, 85, 78]
scores.append(92)
scores.insert(0, 100)
print(scores)

scores[1] = 88
print(scores)

last = scores.pop()
print(last, scores)

scores.remove(88)
print(scores)

del scores[0]
print(scores)
运行结果
[100, 90, 85, 78, 92]
[100, 88, 85, 78, 92]
92 [100, 88, 85, 78]
[100, 85, 78]
[85, 78]

逐个说：

想做的事写法说明
末尾加一个a.append(x)最常用，速度快
插到指定位置a.insert(i, x)后面元素整体往后挪
删末尾并取出a.pop()给个下标就删指定位置
按值删a.remove(x)只删第一个，找不到报 ValueError
按下标删del a[i]不返回值
改a[i] = x下标越界报 IndexError
查a[i]、a.index(x)、x in ain 返回 True 或 False

insert(0, 100) 插到最前面，后面的 90、85、78 全体右移；pop() 把最后那个 92 摘下来交给你，列表跟着少一个。这些操作不用你操心容量：列表长度不是提前定死的，加一个元素它就长一格。

列表不要求元素同类型：[1, "two", 3.0, True] 完全合法。元素本身也可以是列表，形成嵌套，比如 [[1, 2], [3, 4]] 就是一张两行两列的表。

有个细节要提前说：append()、insert()、remove() 这些方法返回值都是 None，它们改的是列表本身。写 scores = scores.append(92)，scores 会变成 None，后面再取下标就报 TypeError。要加就直接写 scores.append(92)，别接返回值。

但列表是可变对象，第 2 课讲的「标签」模型到这儿开始咬人：

Python
a = [1, 2, 3]
b = a
b.append(4)
print("a =", a)
print("b =", b)

c = a[:]
c.append(5)
print("a =", a)
print("c =", c)
运行结果
a = [1, 2, 3, 4]
b = [1, 2, 3, 4]
a = [1, 2, 3, 4]
c = [1, 2, 3, 4, 5]

b = a 没有复制列表，只是给同一个列表又贴了一张标签，所以改 b 就是改 a，第一行打印 a 也能看到 4。c = a[:] 才是真复制，切片不带起点终点就是整个列表的副本；等价的写法还有 a.copy()。

▲常见错误

看到 b = a 就以为复制了，是初学阶段最贵的错觉。判断标准很简单：赋值号右边是在造新对象，还是指向同一个对象。数字、字符串不可变，怎么指都安全；列表、字典、集合可变，共享迟早出事。要拿一份副本随便改，又不想影响原表，先 a[:] 或 a.copy()。

4.2 sort()、sorted() 和切片#

排序有两种写法，区别就一条：改不改自己。

Python
nums = [3, 1, 4, 1, 5]
print(sorted(nums))
print(nums)

nums.sort()
print(nums)
print(sorted(nums, reverse=True))

print(nums[1:4])
print(nums[:2])
print(nums[-2:])
print(nums[::-1])
运行结果
[1, 1, 3, 4, 5]
[3, 1, 4, 1, 5]
[1, 1, 3, 4, 5]
[5, 4, 3, 1, 1]
[1, 3, 4]
[1, 1]
[4, 5]
[5, 4, 3, 1, 1]
  • sorted(nums) 返回排好的新列表，原表一个不动
  • nums.sort() 原地排自己，返回值是 None
  • reverse=True 从大到小
  • 切片规则和第 3 课字符串一模一样：含头不含尾，负下标从右数，nums[::-1] 是反转后的副本

sort 不返回值这件事，坑过无数人。写成 nums = nums.sort()，nums 立刻变成 None，后面再 nums[0] 就报 TypeError。要新表就用 sorted(nums)，要原地就单独写一行 nums.sort()，别接返回值。

排序还能给 key：sorted(names, key=len) 按字符串长度排。这个参数后面配函数用，第 6 课再说。

4.3 元组：不想被改就用它#

元组就是不可变版的列表，用圆括号写：

Python
point = (3, 5)
print(point[0], point[1])

x, y = point
print(x, y)

a, b = 1, 2
a, b = b, a
print(a, b)

print(type((42)), type((42,)))
运行结果
3 5
3 5
2 1
<class 'int'> <class 'tuple'>

point[0] = 9 会报 TypeError，和字符串一个道理。不能改反而带来两个好处：元组能当字典的键（列表不行），以及别人拿到它也没法改，适合表示「一组成对的数据」，比如坐标、颜色值、数据库的一行记录。

括号其实能省，point = 3, 5 也是元组，逗号才是关键。这也解释了最后一行：(42) 只是给 42 加了层括号，类型还是 int；一个元素的元组必须写成 (42,)，那个逗号不能丢。

解包是元组最舒服的地方。x, y = point 一次取出两个值，a, b = b, a 一行交换两个变量，不用开临时变量。注意等号右边的 b, a 会先组成一个元组，再按顺序拆给左边，所以交换是安全的。

4.4 字典：按名字找值#

列表按下标找，字典按键找。键值对的写法是 {键: 值}：

Python
student = {"name": "小明", "age": 18, "score": 91.5}
print(student["name"])
print(student.get("age"))
print(student.get("phone"))
print(student.get("phone", "未填写"))

student["age"] = 19
student["city"] = "杭州"
print(student)
print(len(student))

scores = {"语文": [90, 85], "数学": [95, 88]}
for subject, marks in scores.items():
    print(subject, "平均", (marks[0] + marks[1]) / 2)
print("语文第一次：", scores["语文"][0])
运行结果
小明
18
None
未填写
{'name': '小明', 'age': 19, 'score': 91.5, 'city': '杭州'}
4
语文 平均 87.5
数学 平均 91.5
语文第一次： 90

[] 和 get() 的区别必须记牢：student["phone"] 取不到会抛 KeyError，程序直接挂；student.get("phone") 取不到返回 None，给第二个参数就返回那个默认值。拿不准键在不在，就用 get()。

赋值是「有则改、无则加」：student["age"] = 19 改了已有的键，student["city"] = "杭州" 新增了一个。删除用 del student["age"] 或 student.pop("age")。字典从 3.7 起保持插入顺序，所以打印出来是 name、age、score、city 排着队。

键必须是不可变类型，字符串、数字、元组都行，列表不行。值什么都能放，包括列表和另一个字典，这就是「嵌套」。成绩表 {"语文": [90, 85], "数学": [95, 88]} 就是字典套列表，取语文的第一次成绩写 scores["语文"][0]，从外往里一层层剥。

中间那个 for subject, marks in scores.items() 是循环，第 5 课正式讲。现在只要看明白：items() 把每对键值拆成 subject 和 marks 两个变量，缩进里那一行对每一对执行一次。keys() 只拿键，values() 只拿值。

4.5 集合与列表推导式#

集合（set）只有一条铁律：不许重复。拿它去重最省事：

Python
nums = [3, 1, 3, 1, 5, 5]
unique = set(nums)
print(len(unique), sorted(unique))

a = {1, 2, 3, 4}
b = {3, 4, 5}
print(sorted(a & b))
print(sorted(a | b))
print(sorted(a - b))

squares = [x * x for x in range(10)]
print(squares)
print([x for x in range(10) if x % 2 == 0])
names = ["amy", "bob", "cindy"]
print([n.upper() for n in names])
运行结果
3 [1, 3, 5]
[3, 4]
[1, 2, 3, 4, 5]
[1, 2]
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
[0, 2, 4, 6, 8]
['AMY', 'BOB', 'CINDY']

集合用花括号写，但 {} 是空字典，空集合必须写 set()。集合无序，打印顺序不保证，所以想看有序结果就 sorted() 一下。& 交集、| 并集、- 差集，in 判断成员几乎瞬间完成，这是它比列表强的地方。

最后几行是列表推导式，写法是 [表达式 for 变量 in 序列]。读法是从左往右：拿 range(10) 里的每个 x，算 x * x，把结果收成一个新列表。range(10) 给出 0 到 9，不含 10，这是新手最容易差一位的地方。

带 if 的版本是先筛再用：只有 x % 2 == 0 的 x 才会被算进去。if 第 5 课讲，这里先照着写。

★值和代价

推导式省的是行数，不是脑子。一层加个 if 挺好读，套两层就开始难懂了，三层基本没人愿意看。规则很土：写完自己也看不懂，就拆回普通循环。

4.6 完整程序：算平均分、找最高分#

一组成绩，要人数、总分、平均分、最高最低、排名、不及格人数。用今天学的凑一凑：

Python
scores = [72, 88, 95, 55, 79, 88]

total = sum(scores)
print("人数：", len(scores))
print("总分：", total)
print("平均分：", round(total / len(scores), 1))
print("最高分：", max(scores))
print("最低分：", min(scores))
print("从高到低：", sorted(scores, reverse=True))
print("前三名：", sorted(scores, reverse=True)[:3])
print("不及格人数：", len([s for s in scores if s < 60]))
print("去重后：", sorted(set(scores)))
运行结果
人数： 6
总分： 477
平均分： 79.5
最高分： 95
最低分： 55
从高到低： [95, 88, 88, 79, 72, 55]
前三名： [95, 88, 88]
不及格人数： 1
去重后： [55, 72, 79, 88, 95]

逐行拆：

  • sum()、max()、min() 是内置函数，直接吃列表，不用自己写循环
  • round(x, 1) 保留一位小数；这里 477 除以 6 本来就不是整数，所以得留一位
  • sorted(scores, reverse=True) 返回新表，所以原表还在，后面几行还能继续用
  • [:3] 在排好的表上切前三个，链式写法很常见
  • len([s for s in scores if s < 60]) 是「先筛出不及格的，再数个数」，比写循环加计数器短
  • 最后一行 sorted(set(scores)) 里，set 去重、sorted 排序，两次转身拿到一张不重复的成绩表

注意 scores 从头到尾没被改过。这个习惯值得养：需要新结果就让它进新变量，别在原数据上反复动刀。

◆小结
  • list 可变：append、insert、pop、remove、del，下标从 0 起，切片和字符串一样
  • b = a 不复制列表，a[:] 或 a.copy() 才复制
  • sorted() 给新表，sort() 改自己且返回 None
  • tuple 不可变，能当字典键，解包和交换变量最好用
  • dict 用 get() 拿不准的键，[] 取不到会 KeyError；items() 拆键值对
  • set 自动去重，&、|、- 玩交并差
  • 推导式 [表达式 for 变量 in 序列]，带 if 就是先筛后算
  • 上一课是 第 3 课 字符串与文本处理；下一课 第 5 课 条件、循环与缩进，for 正式登场，字典和列表的遍历就靠它
✎练习
  1. 用 range(1, 11) 和列表推导式，生成 1 到 10 每个数的平方组成的列表。
  2. 给一个名字列表，去掉重复并排好序；再单独输出长度大于 4 的那些名字。
  3. 用字典存三个人的成绩，输出每个人的名字和分数。然后用 [] 和 get() 分别取一个不存在的键，把两次结果都看一遍。
  4. 有一组成绩，输出平均分、最高分和不及格人数，不许用 for，只能用 sum、max、len 和推导式。
