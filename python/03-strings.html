第 3 课 字符串与文本处理

预计 25 分钟·约 5,530 字·Python

字符串是程序里最常见的类型：你的名字、一句提示、文件里的一行、网页上抓下来的一段，全都是字符串。Python 的字符串比想象中好操作，长度自己知道，能随便切，还自带几十个方法。这一课把日常要用的部分过一遍。

3.1 引号的四种写法#

单引号和双引号在 Python 里完全等价，'abc' 和 "abc" 是同一个字符串。选一种用就行，别在同一个文件里换着来。字符串本身带引号时，用另一种包着最省事："他说'你好'"。非要用同一种，就转义："他说\"你好\""。

三引号（''' 或 """）用来写跨行的字符串，里面的换行原样保留：

Python
poem = """床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。"""
print(poem)

print('单引号')
print("双引号")
print('他说"你好"')
运行结果
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
单引号
双引号
他说"你好"

print 会一次把四行都打出来。三引号还有个用法是当多行注释：Python 没有专门的多行注释符号，把一段说明包进三引号当字符串放着，不赋值也不报错。写在函数第一行的三引号字符串另有身份，叫 docstring，第 6 课讲函数时会碰到。

反斜杠 \ 是转义符，它和后面的字符组合起来表示一个特殊字符。\n 是换行，\t 是制表符，\\ 才是一个真正的反斜杠：

Python
print("第一行\n第二行")
print("他说：\"你好\"")
print("D:\\new\\table")
print(r"D:\new\table")
运行结果
第一行
第二行
他说："你好"
D:\new\table
D:\new\table

最后两行输出一样，写法不同。"D:\\new\\table" 里的 \\ 转义成反斜杠；r"D:\new\table" 前面加了个 r，叫原始字符串，里面的反斜杠不再有特殊含义。写 Windows 路径时，r 前缀能省掉一堆双写。

▲常见错误

"D:\new" 里的 \n 会被当成换行，打印出来变成两行，路径直接坏掉。要么写 "D:\\new"，要么写 r"D:\new"。另外，字符串末尾不能是单个反斜杠，"abc\" 会把结尾的引号转义掉，Python 会以为字符串还没结束。

3.2 下标与切片#

字符串是一串字符排成的队伍，每个字符有自己的位置，叫下标。下标从 0 开始数：

Python
s = "Python"
print(s[0], s[1], s[-1])
print(len(s))
print(s[1:4])
print(s[:3])
print(s[3:])
print(s[-2:])
print(s[::2])
print(s[::-1])
运行结果
P y n
6
yth
Pyt
hon
on
Pto
nohtyP
  • 合法下标是 0 到 len(s) - 1，"Python" 的最后一个字符是 s[5]
  • 负数下标从右边数：s[-1] 是最后一个，s[-2] 是倒数第二个
  • 下标越界会报 IndexError，程序直接停，不会给你一个莫名其妙的结果

真正好用的是切片 s[起点:终点]，规则是含起点、不含终点。s[1:4] 取下标 1、2、3 三个字符，得到 yth，长度正好是 4 - 1 = 3。起点省略就从头开始，s[:3] 是 Pyt；终点省略就一直到结尾，s[3:] 是 hon；两个都省略，s[:] 得到整个字符串的一份副本。

两个冒号是步长。s[::2] 每隔一个取一个，得 Pto；步长给 -1 就倒着走，s[::-1] 是 nohtyP。反转字符串的惯用法就是这个，判断回文一句话：s == s[::-1]。

切片还有个好处：永远不会越界。s[2:100] 只给你 thon，不报错，因为终点超出长度就按长度算。这是它和下标最大的区别，也是 Python 里取子串很少出事的原因。

3.3 字符串不可变#

试着改一个字符会马上翻车：s[0] = "p" 报 TypeError: 'str' object does not support item assignment。

不可变的意思是："Python" 这个对象一旦造出来，内容就定死了。所有看起来像「修改」的操作，其实都是造一个新字符串：

Python
s = "Python"
t = "p" + s[1:]
print(t)
print("ab" * 3)
print(t + "!" * 2)
print(s == "python")
print(s.lower() == "python")
运行结果
python
ababab
python!!
False
True

t = "p" + s[1:] 是拿第一个字符 P 换成了 p，拼出一个新字符串 python，再让 t 指向它。原来的 "Python" 还在，只是没人用了，后面会被回收。注意 s 从头到尾没变，s.lower() 也返回新串，不是把 s 改成小写。

为什么这么设计？因为字符串可能被好几个变量共享。如果其中一个变量能偷偷改内容，另一个变量手里的值就跟着变了，这种 bug 极难查。干脆一刀切：不许改，要用新的就新造一个。附带的好处是字符串可以当字典的键，第 4 课会用到。

+ 拼接、* 重复，都是造新串。注意 "3" + 3 会报 TypeError，Python 不会帮你自动把数字转成字符串，得写 "3" + str(3)。另外别在循环里用 + 一路拼，每次都造新串，数据多了很慢，那种场合用 join。

3.4 f-string：把变量塞进字符串#

拼字符串最舒服的写法，Python 3.6 起可用。在引号前加个 f，串里的 {变量} 会被换成值：

Python
name = "小明"
age = 18
score = 91.5

print(f"我叫{name}，今年{age}岁。")
print(f"明年我就{age + 1}岁了。")
print(f"平均分{score:.2f}")
print(f"及格线{score * 0.6:.1f}分")
print(f"|{name:>8}|")
print(f"{1234567:,}")
print(f"{0.873:.1%}")
运行结果
我叫小明，今年18岁。
明年我就19岁了。
平均分91.50
及格线54.9分
|      小明|
1,234,567
87.3%

{} 里不只能放变量名，放表达式也行，{age + 1}、{score * 0.6} 都是先算再填，不用为了输出专门造个中间变量。

冒号后面是格式控制，常用的这几个：

写法作用效果
{x:.2f}保留两位小数3.14159 变 3.14
{x:.0f}舍入到整数3.7 变 4
{x:>8}右对齐占 8 格输出表格时对齐
{x:<8}左对齐占 8 格名字后面补空格
{n:,}千分位1234567 变 1,234,567
{p:.1%}百分比一位小数0.873 变 87.3%

老代码里你还会见到 "我叫%s" % name 和 "我叫{}".format(name)，读得懂就行，自己写一律用 f-string。只有一个地方要留神：f-string 里的花括号是语法，真想要一对花括号得写 {{}}。

▲常见错误

f-string 前面漏了 f，print("{name}") 就会原样输出 {name}，变量根本没被替换。这个错误不报错，只是输出不对，最容易被忽略。看到输出里带着花括号，先检查引号前面有没有那个 f。

3.5 常用方法#

字符串的方法都是「谁调用、对谁操作」，返回值是新串：

Python
raw = "  Hello, Python World  "
print(raw.strip())
print(raw.strip().lower())
print(raw.strip().upper())
print(raw.strip().replace("Python", "世界"))
print(raw.strip().split(","))
print("-".join(["a", "b", "c"]))
print(raw.find("Python"))
print(raw.strip().startswith("Hello"))
print(len(raw))
print("thon" in raw)
运行结果
Hello, Python World
hello, python world
HELLO, PYTHON WORLD
Hello, 世界 World
['Hello', ' Python World']
a-b-c
9
True
23
True
  • strip() 去掉两端空白（空格、Tab、换行），lstrip()、rstrip() 只去一边
  • lower()、upper() 转大小写。判断用户输入时先 lower() 再比，能少一半 bug
  • replace(旧, 新) 替换所有出现，不是只换第一个
  • split(",") 按分隔符切成列表；不带参数时按任意空白切，连续空格自动合并成一个分隔
  • join 反过来拼，注意谁调用谁当分隔符："-".join(words)，写成 words.join("-") 是错的
  • find() 返回下标，找不到返回 -1；index() 找不到直接报 ValueError
  • startswith()、endswith() 判断开头结尾，比先切片再比较直观
  • len(s) 是函数不是方法，s.len() 会报错
  • in 判断子串，比 find() != -1 更像 Python
★链式调用

raw.strip().lower() 连着写，是因为 strip() 返回一个新字符串，lower() 立刻在这个新串上继续操作。只要每一步都返回字符串，就可以一直点下去。但每一步都是造新串，链子太长时拆开写反而好读。

▲常见错误

所有方法都返回新串，不会改原来的 raw。写 raw.strip() 却不接返回值，这一步等于白做。要改就写 raw = raw.strip()。同理，words.sort() 这类原地操作返回 None，别把返回值又赋回去。

3.6 完整例子：数单词、首字母大写#

需求很日常：读一句话，数出几个词，把每个词的首字母大写，再看看里面有没有 python 这个词。

Python
sentence = input("输入一句话：").strip()
words = sentence.split()

print("单词数：", len(words))
print("首字母大写：", sentence.title())
print("全部小写：", sentence.lower())
print("用 - 连接：", "-".join(words))
print("含 python 吗：", "python" in sentence.lower())
运行结果
输入一句话：i love python and programming
单词数： 5
首字母大写： I Love Python And Programming
全部小写： i love python and programming
用 - 连接： i-love-python-and-programming
含 python 吗： True

逐行看：

  • 第一行是链式调用。input() 返回字符串，立刻在它身上调 .strip()，把用户不小心敲进去的首尾空格削掉
  • split() 不带参数，按空格切，连续空格和 Tab 都算一个分隔，所以多打几个空格也不会数出空词
  • len(words) 数的是列表长度，words 是列表，第 4 课系统讲，现在只要知道它能装一串词
  • .title() 把每个单词的首字母大写、其余字母小写；.capitalize() 只处理整句的第一个字母，其余全小写，两个别搞混
  • "-".join(words) 把列表拼回字符串，顺带展示 join 的用法
  • 最后一行先 lower() 抹平大小写再判断，所以用户打成 Python 或 PYTHON 都能命中
◆小结
  • 单双引号等价，三引号写多行，r"" 写原始字符串（Windows 路径用得上）
  • 下标从 0 起，负数从右数；切片含头不含尾，[::-1] 反转
  • 字符串不可变，所有「修改」都是造新串
  • f-string 里能放表达式，冒号后面接格式控制，.2f 最常用
  • split 切开、join 拼回、strip 削空白，这三个配一起能干掉大多数文本处理
  • in 判断子串，len() 求长度
  • 上一课是 第 2 课 变量、类型与运算，下一课是 第 4 课 列表、元组、字典与集合，split() 切出来的那个东西正式登场
✎练习
  1. 读入一句话，把整句倒着打印出来（提示：[::-1]）。
  2. 判断一个字符串是不是回文，也就是正着念和反着念一样。
  3. 读入 2024-01-05 这样的日期，输出「2024 年 1 月 5 日」。注意输出的是数字 1 和 5，不是带前导零的 01。
  4. 读入姓名和分数，输出 姓名：小明 分数：91.50，要求姓名左对齐占 6 格、分数保留两位小数。
