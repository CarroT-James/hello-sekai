第 2 课 变量、类型与运算

预计 25 分钟·约 5,149 字·Python

先看两行几乎每段程序都会出现的代码：

Python
age = 18
print(age)
运行结果
18

很多人第一反应是「把 18 放进 age 这个盒子里」。这个画面会把你带偏。age 不是一个装东西的容器，它更像一张便利贴：Python 先造出一个整数 18，再把写着 age 的标签贴到它上面。这一课就从这个模型讲起，因为后面所有的坑几乎都从这儿长出来。

2.1 变量是贴在值上的名字#

先看一段能跑的代码：

Python
a = 1
print(a)
a = "hello"
print(a)
a = [1, 2, 3]
print(a)

x = 1000
y = x
print(x == y, id(x) == id(y))
运行结果
1
hello
[1, 2, 3]
True True

第一行 a = 1 分两步：Python 先在内存里造出一个整数对象 1，再把名字 a 贴到它身上。print(a) 做的事是「找到 a 贴着的那个值，打印它」。

第二行 a = "hello" 不是「把字符串塞进 a」，而是造了一个新字符串，把标签 a 从 1 上撕下来，贴到新字符串上。第三行同理，a 又贴到了一个列表上。原来那个 1 现在没人贴了，Python 会在合适的时候把它回收，你不用管。

这叫动态类型：类型长在值身上，不长在名字身上。名字 a 本身没有类型，type(a) 问的其实是「a 现在贴着的那个值是什么类型」。

后面两行在验证另一件事：y = x 没有复制 1000，只是让 y 也贴到同一个对象上。id() 返回对象的编号，两个编号一样，说明贴的是同一个东西。你可以把 id() 理解成对象的身份证号，具体数字是多少不重要，重要的是「一样还是不一样」。

赋值还有一个容易忽略的顺序：先算等号右边，再把名字贴过去。所以 a = a + 1 是合法的，右边先算出新值，再让 a 指向它，旧的整数没人引用就被回收了。它不是数学里的等式，别用「两边相等」去理解。

▲常见错误

别把 a = 1 读成「a 是一个整数」。它只说明 a 现在指向 1。所以 a = "1" 之后再写 a + 1，会报 TypeError: can only concatenate str (not "int") to str。

不是「a 改了类型」这件事有错，而是 a 现在指向字符串 "1"，字符串加整数本来就没定义。遇到 TypeError，先问自己：这个变量现在到底指着什么？

★为什么这个区别值得较真

如果变量真是盒子，b = a 就该复制一份数据，两个盒子各装一份。但在 Python 里，b = a 只是多贴一张标签，a 和 b 指的是同一个值。对数字、字符串这种改不了的值，这事无所谓；对列表这种能改的值，改 b 就是改 a，第 4 课会专门踩这个坑。

另外，变量名只对你有意义，Python 运行时并不关心你叫它 a 还是 age。名字起得好，是给三个月后的自己留条活路。

2.2 五种基本类型#

常用的类型就五种，一张表看完：

类型例子说明
int42整数，没有上限
float3.14小数，双精度
str"你好"字符串，引号包起来
boolTrue只有 True 和 False
NoneTypeNone表示「没有值」，全语言只有这一个

int 最反直觉的地方是没有上限。Python 的整数想长多大长多大，只受内存限制：

Python
print(2 ** 100)
print(10 ** 20 + 1)
print(0.1 + 0.2)
运行结果
1267650600228229401496703205376
100000000000000000001
0.30000000000000004

第三行的结果别慌，这跟 Python 无关。0.1 和 0.2 在二进制里都是无限循环小数，只能存一个近似值，两个近似值相加，误差就露出来了。计算机用二进制存小数，都会遇到这件事。要比较两个小数，别写 ==，用 round(0.1 + 0.2, 2) == 0.3，或者干脆用 decimal 模块做精确计算。

bool 只有两个值，首字母必须大写，小写的 true 是错的。None 得单独说：它表示「什么都没有」，不是 0，不是空字符串，也不是 False。它是 NoneType 类型唯一的那个值，判断的时候用 x is None，别用 ==。

2.3 用 type() 和 isinstance() 查类型#

不确定手里是什么类型，type() 直接告诉你：

Python
print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
print(type(None))

print(isinstance(42, int))
print(isinstance(3.14, int))
print(isinstance(True, int))
print(isinstance("42", (int, float)))
运行结果
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
True
False
True
False

前五行里最容易看错的是 "42"：加了引号就是字符串，跟数字 42 完全是两样东西。一个是能参与加减乘除的数，一个是三个字符排成的文本。

后四行有个意外：isinstance(True, int) 居然是 True。因为 bool 是 int 的子类，True 就是 1、False 就是 0，True + True 能算出 2。所以你写「是不是数字」的检查时，True 也会被算进去。这个细节知道就行，平时很少主动依赖它。

isinstance() 第二个参数可以给一个元组，表示「是其中任意一种就行」。判断类型优先用它，因为 type(x) == int 会把子类排除在外，而 isinstance 认继承。

◆记忆点

type() 返回类型本身，isinstance() 回答「是不是这类」。写检查用 isinstance，排查问题用 type。

2.4 类型转换：三个最常翻的车#

int()、float()、str() 是三个转换函数。用起来简单，坑都在边界上：

Python
print(int(3.9))
print(int(-3.9))
print(float("3.5"))
print(str(42), type(str(42)))
print(int(float("3.5")))
print(bool("False"), bool(""), bool(None), bool(0))
运行结果
3
-3
3.5
42 <class 'str'>
3
True False False False

第一、二行说明 int() 不是四舍五入，是直接砍掉小数部分，而且是朝零砍：3.9 得 3，-3.9 得 -3。想要舍入用 round()，round(3.9) 得 4。

第五行是绕坑的正解。int("3.5") 会直接报错，错误信息是 ValueError: invalid literal for int() with base 10: '3.5'，因为 int() 只认整数字符串。想留整数部分，先 float() 转成数，再 int() 砍。

最后一行是另一个坑：bool("False") 是 True。只要字符串非空，它就是真，哪怕是 "0"、"False"、一个空格。空字符串、0、None 才是假。

还有个细节：int(" 42 ") 能成，首尾空白会被自动忽略；但 int("4 2") 会报错。所以从文件或输入里读来的数字，先 strip() 再转换更保险。

▲常见错误

input() 拿回来的是字符串，忘了转换就开始算，是最常见的翻车方式。a = input() 之后 a + 1 直接报 TypeError。读整数写 int(input())，读小数写 float(input())。转换要趁早，别等算到一半才发现手里是文字。

2.5 除法、整除、取余和幂#

Python 的除法有四种写法，各有各的脾气：

Python
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(7.0 // 2)
print(-7 // 2, -7 % 2)
运行结果
3.5
3
1
1024
3.0
-4 1
  • / 是真除法，结果一定是 float，10 / 2 也给 5.0
  • // 是整除，规则是向下取整，不是截断
  • % 取余，结果符号跟着除数走
  • ** 是幂，2 ** 100 也能算

前四行都符合直觉，最后一行值得盯两秒。-7 // 2 得 -4，不是 -3，因为 -3.5 向下取整是 -4；既然商是 -4，余数就得满足 -4 * 2 + 1 = -7，所以 -7 % 2 是 1。Python 保证 a == (a // b) * b + a % b 永远成立，这个等式比死记符号好使。做题涉及负数时，用这个式子推一遍。

10 / 2 得 5.0 这件事也有代价：想输出「5」会变成「5.0」。要整数就用 //，或者 int(10 / 2)。顺带记一个函数：divmod(7, 2) 一次返回商和余数 (3, 1)，同时要两个值时省事。

+=、-=、*=、//= 这些写法也有，a += 1 就是 a = a + 1 的缩写。写循环里的计数器时会天天用到。

2.6 小计算器和命名规矩#

把这一课的东西拼成一个计算器：

Python
a = float(input("第一个数："))
b = float(input("第二个数："))

print("和：", a + b)
print("差：", a - b)
print("积：", a * b)
print("商：", a / b)
print("整除：", a // b)
print("余数：", a % b)
运行结果
第一个数：7
第二个数：2
和： 9.0
差： 5.0
积： 14.0
商： 3.5
整除： 3.0
余数： 1.0

用 float 读，是因为你没法预判用户敲的是整数还是小数，读成 float 两种情况都收得住。注意 // 对着 float 用力，结果带 .0，不是整数 3。

变量名这块，Python 的社区习惯比较统一：

  • 用小写加下划线，user_name、total_score，这叫 snake_case
  • 名字区分大小写，age 和 Age 是两个变量
  • 不能用关键字，if、for、class、None、True 都不行；也不能数字开头
  • 中文变量名技术上合法，但别用
  • 没有真正的常量，想要常量就全大写，MAX_SIZE = 100，靠大家自觉不去改
▲常见错误

True、False、None 三个词必须首字母大写，小写的 true、none 会直接报 NameError: name 'true' is not defined。另外 = 是赋值，== 是比较：if a = 1 是语法错误，if a == 1 才对。这两个符号看久了会眼花，写条件时多看一眼。

◆小结
  • 变量名是标签，不是盒子；类型属于值，赋值只是让名字换一个值
  • int 没有上限，float 存的是近似值，0.1 + 0.2 != 0.3 不是 Python 的锅
  • type() 看类型，isinstance() 做判断，后者认继承
  • int() 朝零砍，int("3.5") 直接报错，得先 float()
  • / 给小数，// 向下取整，% 符号跟除数，** 是幂
  • 命名用 snake_case，True、False、None 首字母大写
  • 上一课是 第 1 课 认识 Python，跑通第一个程序，下一课是 第 3 课 字符串与文本处理
✎练习
  1. 读入圆的半径，输出面积和周长，结果只保留两位小数（提示：round(x, 2)）。
  2. 读入一个三位整数，输出它的百位、十位、个位，只能用 // 和 %。
  3. 先猜再运行：print(0.1 + 0.2 == 0.3) 输出什么？再试 print(round(0.1 + 0.2, 2) == 0.3)，解释两次结果为什么不同。
  4. 分别打印 10 / 2、10 // 2、10 % 2 的 type()，先写答案再验证。
