第 8 课 常用标准库与项目实战

预计 45 分钟·约 7,271 字·Python

Python 装好之后就自带一大堆模块，叫标准库，不用额外安装，import 一下就能用。这一课先挑几个最常用的过一遍，然后拿它们和一个完整项目收尾。

8.1 math 与 random：算数和随机#

Python
import math
import random

print(math.sqrt(16))
print(math.pi)
print(math.floor(3.7), math.ceil(3.2))
print(math.gcd(12, 18))

random.seed(42)
print(random.randint(1, 100))
print(random.choice(["石头", "剪刀", "布"]))
print(random.sample(range(1, 50), 5))

random.seed(42)
print(random.randint(1, 100))
运行结果
4.0
3.141592653589793
3 4
6
82
石头
[2, 48, 18, 16, 15]
82

math 里常用的就几个：sqrt 开方、pi 圆周率、floor 向下取整、ceil 向上取整、gcd 最大公约数。3.7 向下取整是 3，3.2 向上取整是 4，别和 round() 搞混，round 是舍入。

random 有四个常用函数：

  • randint(a, b) 随机整数，两头都包含
  • choice(序列) 从里面随机挑一个
  • sample(序列, k) 挑 k 个不重复的，返回列表
  • shuffle(列表) 原地打乱，没有返回值

random.seed(42) 是设定随机种子。计算机的随机是「伪随机」：种子一样，后面吐出来的数就一样。上面两次 seed(42) 之后都打印 82，就是这个原因。写测试、做教学演示时固定种子很有用，正式程序里别 reseed。

▲常见错误

random.shuffle 是原地改列表，不返回新列表。写成 cards = random.shuffle(cards)，cards 就变成 None 了，后面一用就 TypeError。正确写法是单独一句 random.shuffle(cards)。

8.2 datetime 与 time：时间#

Python
from datetime import datetime, timedelta

start = datetime(2006, 9, 1)
now = datetime(2026, 11, 25, 21, 30)
delta = now - start

print(delta.days)
print(now.strftime("%Y 年 %m 月 %d 日"))
print((now + timedelta(days=100)).strftime("%Y-%m-%d"))

import time

print("开始")
time.sleep(1)
print("一秒后")
运行结果
7390
2026 年 11 月 25 日
2027-03-05
开始
一秒后

datetime 表示一个时间点，timedelta 表示一段时间差。两个 datetime 相减得到 timedelta，.days 拿出天数。datetime 加 timedelta 得到新的时间点，算「一百天后是哪天」很方便。

strftime 把时间格式化成字符串：%Y 四位年、%m 月、%d 日、%H:%M:%S 时分秒。反过来 strptime("2026-11-25", "%Y-%m-%d") 把字符串解析成 datetime。这两个名字只差一个字母，很容易记反，f 是 format，p 是 parse。

time 模块更底层。time.time() 返回从 1970 年 1 月 1 日到现在的秒数（浮点数），time.sleep(1) 让程序停一秒，time.perf_counter() 用来测代码跑了多久。

什么时候用哪个？要处理「年月日、加减天数」用 datetime，要计时、要休眠用 time。

8.3 os 与 pathlib：路径和目录#

Python
import os
from pathlib import Path

p = Path("demo_dir")
p.mkdir(exist_ok=True)

file = p / "note.txt"
file.write_text("你好，pathlib\n", encoding="utf-8")

print(file.exists())
print(file.read_text(encoding="utf-8").strip())
print(file.name, file.suffix, file.parent)
print(file.stem)

print(os.path.exists(str(file)))
os.remove(file)
print(file.exists())
运行结果
True
你好，pathlib
note.txt .txt demo_dir
note
True
False

pathlib 是新的写法，把路径当对象。最舒服的是用 / 拼路径：p / "note.txt"，Windows 和 Linux 都能跑，不用管分隔符是 \ 还是 /。用字符串拼 "demo_dir" + "\\" + "note.txt"，在 Windows 上还得转义反斜杠，很容易错。

常用的几个：exists() 判断存在，mkdir(parents=True, exist_ok=True) 建目录且已存在不报错，read_text() / write_text() 一次读写整个文本文件，iterdir() 列目录，glob("*.py") 按模式找文件，unlink() 删文件。name、suffix、stem、parent 分别是文件名、后缀、去掉后缀的名字、所在目录。

os 是老牌模块，管的是路径、目录、环境变量这些系统层面的东西。常用 os.getcwd() 当前目录、os.listdir() 列目录、os.remove() 删文件、os.rename() 改名、os.path.join() 拼路径。看到老代码里一堆 os.path.xxx 不奇怪，pathlib 是后来才加的。

★补充说明

新代码优先用 pathlib。os.path 全是字符串操作，拼错了要到运行时才发现；Path 对象拼出来的路径是合法的，而且 .exists() 这种写法读起来更顺。

8.4 import 的几种写法与 pip#

同一个模块，有四种导入方式，差别在「用的时候要不要写前缀」。

Python
import math
print(math.sqrt(16))

import math as m
print(m.sqrt(16))

from math import sqrt, pi
print(sqrt(16))

from math import *
print(sqrt(16))
运行结果
4.0
4.0
4.0
4.0
  • import math 最稳，用的时候写 math.sqrt，名字从哪来一目了然
  • import math as m 起个短名字，适合名字长的模块，比如 import numpy as np
  • from math import sqrt, pi 只拿需要的，用起来短，但读代码时看不出 sqrt 是标准库还是你自己写的
  • from math import * 把所有名字倒进当前文件，容易撞名，不要用

最后一种的危害不是理论上的：你定义了一个 sqrt，然后 from math import *，你自己的就被覆盖了，还不报错。

import 一律写在文件开头，顺序是标准库、第三方库、自己写的模块，中间空一行。PEP 8 这么建议，工具也按这个顺序检查。

第三方库和 pip#

标准库不够用时，去 PyPI 装包。pip 是 Python 自带的包管理器：

Shell
pip install requests
pip install requests==2.32.3
pip list
pip uninstall requests

pip install 包名 从网上下载安装，== 锁定版本（团队协作时必须锁，不然今天能跑的代码明天就崩），pip list 看装了什么，pip uninstall 卸载。装不上可以换国内镜像，加 -i https://pypi.tuna.tsinghua.edu.cn/simple。

这个站是离线的，上面的命令你在这儿跑不了，看看长相就行，回自己电脑上试。真正做项目时还要用虚拟环境 venv，把每个项目的依赖隔开，8.6 节会说。

◆记忆点

import 模块 和 from 模块 import 名字 都对，但前者更清楚。只有一种情况例外：from datetime import datetime，因为模块名和类名一样，不这么写就得写 datetime.datetime.now()。

8.5 项目：班级成绩管理#

需求是这样：

  • 从 scores.json 读学生成绩
  • 菜单里有五个选项：查看全部、按分数排序、统计信息、按名字查询、退出
  • 用 while True 驱动菜单，输入 5 才退出
  • 代码按功能拆成函数，main() 只负责调度

数据长这样，一个列表，每个元素是一个字典。读文件、编码、异常这些细节都在 第 7 课 文件、编码与异常处理 里讲过，这里直接用：

TEXT
[
  {"name": "小明", "score": 88},
  {"name": "小红", "score": 95},
  {"name": "小刚", "score": 62},
  {"name": "小美", "score": 79}
]

为什么不用两个列表分别存名字和分数？因为下标要对齐，删一个人要同时删两个列表，很容易漏。一个字典装一个人的全部信息，加字段（比如班级、学号）也只是多一个键。

把上面那段 scores.json 存到和程序同一个目录，然后运行。完整代码：

Python
import json

DATA_FILE = "scores.json"


def load_scores(path=DATA_FILE):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"找不到 {path}，请先创建。")
        return []
    except json.JSONDecodeError:
        print(f"{path} 不是合法的 json。")
        return []


def print_records(records):
    for i, item in enumerate(records, start=1):
        print(f"{i}. {item['name']}：{item['score']} 分")


def sort_by_score(records):
    return sorted(records, key=lambda r: r["score"], reverse=True)


def show_stats(records):
    scores = [r["score"] for r in records]
    best = max(records, key=lambda r: r["score"])
    worst = min(records, key=lambda r: r["score"])
    average = sum(scores) / len(scores)
    print(f"人数：{len(scores)}")
    print(f"平均分：{average:.1f}")
    print(f"最高分：{best['score']}（{best['name']}）")
    print(f"最低分：{worst['score']}（{worst['name']}）")


def search_by_name(records, keyword):
    hits = [r for r in records if keyword in r["name"]]
    if not hits:
        print(f"没有名字包含「{keyword}」的同学。")
        return
    print_records(hits)


def show_menu():
    print("1 查看全部  2 按分数排序  3 统计信息  4 按名字查询  5 退出")


def main():
    records = load_scores()
    if not records:
        return

    while True:
        show_menu()
        choice = input("请选择：").strip()

        if choice == "1":
            print_records(records)
        elif choice == "2":
            print_records(sort_by_score(records))
        elif choice == "3":
            show_stats(records)
        elif choice == "4":
            keyword = input("输入名字：").strip()
            search_by_name(records, keyword)
        elif choice == "5":
            print("再见。")
            break
        else:
            print("只能输入 1 到 5。")


if __name__ == "__main__":
    main()

结构上的几个决定，值得记下来：

  • load_scores 把读文件和异常处理包在一起，main 拿到的要么是数据，要么是空列表，不用关心文件在不在
  • print_records 只管打印，排序、查询、统计都调它，输出的格式只有一处定义
  • sort_by_score 返回新列表，不改原数据。records 的顺序始终是最初读进来的顺序，反复排序也不会乱
  • 每个分支只写一行调用，main 一眼看完，加新功能就是加一个 elif
  • input().strip() 去掉多余空格，不然输入「 1」会走到 else 分支
  • keyword in r["name"] 是部分匹配，输入「小」能查出所有名字里带「小」的同学

想加功能？在菜单里加一项、写一个函数、elif 里调一下，三处改动就够。这就是把功能拆成函数的好处。

8.6 跑起来，然后呢#

一路写下来，你已经能读文件、处理数据、写回结果，还能用一个菜单把它们串起来。这已经是「脚本」的水平了，日常处理表格、批量改文件名、算点东西，够用。

接下来往哪走：

  • 类与面向对象。现在一个学生是裸字典，取数据靠 r["score"]，写错了要到运行时才知道。类能把数据和操作绑在一起，student.score 拼错立刻报错。项目一大，这个区别很明显。
  • 虚拟环境 venv。python -m venv .venv 建一个独立环境，pip install 装的东西只影响这个项目。不做隔离，A 项目要 requests 2.31、B 项目要 2.32，你只能来回卸载。
  • requests。发 HTTP 请求，爬网页、调 API。学完它，你就能让程序去网上拿数据，而不是等你手动存成 csv。
  • numpy 与 pandas。处理成千上万行数据，pandas 的 read_csv 一行顶你手写几十行循环，分组统计、透视表都是现成的。

还有两个不急但值得知道：类型注解（def f(x: int) -> int:）能让编辑器和检查工具提前发现类型错误；pytest 用来自动跑测试，项目大了没测试不敢改代码。

别急着把上面全学一遍。把这个项目再加两个功能，比看三个新教程有用。

◆小结
  • 标准库不用装：math 算数、random 随机、datetime / time 时间、os / pathlib 路径
  • import math、import math as m、from math import sqrt，别用 from ... import *
  • 第三方库用 pip install，版本用 == 锁住；本站不联网，命令回自己电脑试
  • 项目套路：数据用列表装字典，菜单用 while True，一个功能一个函数，main 只调度
  • 下一步：类、venv、requests、numpy / pandas
  • 上一课是 第 7 课 文件、编码与异常处理，八课到这里就齐了；想继续，可以回 第 1 课 认识 Python，跑通第一个程序 把环境再摸一遍
✎练习
  1. 加一个菜单项「6 添加同学」：输入名字和分数，追加到 records，然后能立刻查到。
  2. 加一个「保存并退出」：把改完的 records 用 json.dump 写回 scores.json，下次启动能看到新增的人。
  3. 加一个按名字排序的选项。中文排序的结果可能不是拼音顺序，想想为什么。
  4. 用 random 和 math 写一个口算练习：随机出 10 道 100 以内的加法题，每答一题判对错，最后打印得分。
