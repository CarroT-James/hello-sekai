第 6 课 函数与参数

预计 35 分钟·约 6,503 字·Python

前面几课的代码都摊在文件里，从上往下一路写到底。程序一长，同一个「算平均分」的逻辑复制三遍，改的时候漏掉一处就出 bug。函数就是给一段代码起个名字，用的时候喊一声，改的时候只改一处。这一课把函数的每个零件拆开看。

6.1 定义一个函数#

Python
def add(a, b):
    return a + b


def divmod2(a, b):
    return a // b, a % b


def say_hi(name):
    print(f"你好，{name}")


print(add(3, 5))
print(divmod2(17, 5))
q, r = divmod2(17, 5)
print(q, r)
x = say_hi("小明")
print(x)
运行结果
8
(3, 2)
3 2
你好，小明
None

def 是 define 的缩写，后面跟函数名、括号、冒号，缩进的部分就是函数体。调用写 add(3, 5)，括号里的 3 和 5 叫实参，函数定义里的 a、b 叫形参，调用时实参按位置交给形参。

return 把值交回给调用者，函数立刻结束，后面的代码不执行。divmod2 那行 return a // b, a % b 看起来像返回两个值，其实是返回一个元组，外面那层括号被省掉了。所以 q, r = divmod2(17, 5) 能一次拆开，这叫解包，等价于先拿元组再按下标取。

say_hi 没有 return，那它返回什么？None。Python 里没有返回值的函数统一返回 None，所以 x = say_hi(...) 语法上永远合法，x 是 None。注意 say_hi("小明") 会先打印「你好，小明」，然后才把 None 交给 x，最后那行 print(x) 打出来的就是 None。

只写函数名不写括号，函数不会执行。say_hi 拿到的是函数本身，say_hi("小明") 才是调用。这个区别调试时很关键：屏幕上什么都不打印，八成是括号忘了。

◆记忆点

return a, b 返回的是元组 (a, b)。要接住就跑 x, y = f()。看到别人的函数这么写，不用怀疑，就是元组。

6.2 参数：位置、关键字、默认值#

Python
def introduce(name, age, city="北京"):
    print(f"{name}，{age} 岁，来自{city}")


introduce("小明", 18)
introduce("小红", 19, "上海")
introduce(age=20, name="小刚")
introduce("小美", city="广州", age=18)
运行结果
小明，18 岁，来自北京
小红，19 岁，来自上海
小刚，20 岁，来自北京
小美，18 岁，来自广州

三种传参方式在这一段里全用上了：

  • 前两次是位置参数，按顺序对号入座，第三个不传就用默认值「北京」
  • 第三次是关键字参数，写 名字=值，顺序随便，Python 自己找位置
  • 第四次混着用，位置参数在前，关键字参数在后

规则只有一条：位置参数必须排在关键字参数前面。写成 introduce(name="小明", 18) 是语法错误，因为 Python 不知道那个 18 该给谁。

默认参数必须放在参数列表末尾。def f(a=1, b) 直接报 SyntaxError: non-default argument follows default argument。

如果调用时少传一个没默认值的参数，会报 TypeError: introduce() missing 1 required positional argument: 'age'。读法：introduce() 少了一个必需的位置参数 age。这种报错一眼就能定位。

默认值不是「每次调用都重新算」，而是在 def 执行的那一刻算好，只算一次。下一节就有个坑等着它。

6.3 默认参数的坑：可变对象#

先看一段能跑、但结果是错的代码：

Python
def add_item_bad(item, cart=[]):
    cart.append(item)
    return cart


print(add_item_bad("苹果"))
print(add_item_bad("香蕉"))


def add_item(item, cart=None):
    if cart is None:
        cart = []
    cart.append(item)
    return cart


print(add_item("苹果"))
print(add_item("香蕉"))
运行结果
['苹果']
['苹果', '香蕉']
['苹果']
['香蕉']

前两行是错误现象：第二次调用凭空多出一个苹果。后两行是正确写法，每次都是干净的列表。

原因还是「默认值只算一次」。cart=[] 里的 [] 只创建了一个列表对象，之后每次调用没传 cart，用的都是这同一个。函数把它记住了，你往里面 append，它就越来越大。这个列表甚至活到程序结束。

记住一句话：默认值只放不可变对象。数字、字符串、元组、None 都安全，列表、字典、集合不行。

需要「默认是空列表」时，用 None 当哨兵：默认值写 None，函数开头判断 if cart is None:，再新建一个。dict 同理，def f(d={}) 也是同样的 bug。

▲常见错误

看到 def f(x, y=[]) 或者 y={}，基本可以直接判定是 bug。这不是风格问题，是逻辑错误：所有调用共享同一个容器，数据会串。默认值写 None 是标准解法，几乎所有 Python 项目都这么写。

6.4 *args 与 **kwargs#

Python
def total(*args):
    print(args)
    return sum(args)


print(total(1, 2, 3))
print(total(10, 20))


def show(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} = {value}")


show(name="小明", age=18, city="北京")


def mix(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)


mix(1)
mix(1, 3, 5, 7, name="小红")
运行结果
(1, 2, 3)
6
(10, 20)
30
name = 小明
age = 18
city = 北京
1 2 () {}
1 3 (5, 7) {'name': '小红'}

*args 把多出来的位置参数收成一个元组。名字不重要，*nums、*items 都行，星号才是关键，args 只是惯例。total(1, 2, 3) 里 args 就是 (1, 2, 3)，所以能直接 sum。

**kwargs 把多出来的关键字参数收成一个字典，所以用 .items() 遍历。name="小明" 进去变成 {"name": "小明"}。

mix 展示了参数顺序：位置参数 → 有默认值的参数 → *args → **kwargs。这个顺序不能乱，Python 靠位置区分它们。mix(1) 里 a=1、b 用默认值 2、args 是空元组、kwargs 是空字典。mix(1, 3, 5, 7, name="小红") 里 5 和 7 被 args 收走，name 被 kwargs 收走。

星号反过来也能用：调用时 total(*[1, 2, 3]) 把列表拆成三个参数，效果和 total(1, 2, 3) 一样。第 6.6 节的完整程序就用了这一招。

6.5 作用域：LEGB 与 global#

Python
x = 10


def inner():
    x = 20
    print("函数里的 x：", x)


inner()
print("函数外的 x：", x)

count = 0


def add_one():
    global count
    count += 1


add_one()
add_one()
print("count =", count)
运行结果
函数里的 x： 20
函数外的 x： 10
count = 2

函数里 x = 20 不会改外面的 x，它创建了一个局部变量，函数一结束就没了。外面的 x 还是 10。函数内部是独立的小房间，房间里的新东西不会自动搬到外面。

找变量时 Python 按 LEGB 的顺序找：Local（函数里）→ Enclosing（外层函数）→ Global（模块全局）→ Builtin（内置）。先找到谁就用谁，找不到才 NameError。所以函数里只读不写全局变量是合法的，一赋值就变成了局部变量。

真要改全局变量，得先用 global count 声明。声明之后 count += 1 才会作用到外面那个。

但 global 要少用。函数偷偷改了全局变量，你在别处调用它时根本看不出副作用，出 bug 只能一行行翻。正确的做法是把值当参数传进去，把结果 return 出来，函数变成「输入什么、输出什么」的干净东西。

▲常见错误

在函数里读一个全局变量、又在同一个函数里给它赋值，会报 UnboundLocalError。原因还是作用域：只要函数体里出现过 count = 1，Python 就把整个函数里的 count 当成局部变量，前面那句 print(count) 执行时它还没赋值。想读全局的，就别在函数里给同名变量赋值。

6.6 函数是对象、lambda 和 __main__#

函数可以当参数传#

Python
def square(x):
    return x * x


f = square
print(f(4))

students = [("小明", 88), ("小红", 95), ("小刚", 62)]
print(sorted(students, key=lambda s: s[1]))
print(sorted(students, key=lambda s: s[1], reverse=True))
运行结果
16
[('小刚', 62), ('小明', 88), ('小红', 95)]
[('小红', 95), ('小明', 88), ('小刚', 62)]

f = square 没有调用函数，只是给同一个函数对象多起了一个名字。f(4) 和 square(4) 完全一样。函数在 Python 里就是普通对象，能赋值、能放进列表、能当参数。

sorted 的 key 参数要的就是一个函数。排序前，sorted 拿每个元素调用它一次，按返回值比较大小。这里 lambda s: s[1] 返回元组的第二项，也就是分数，所以按分数排。

lambda 是匿名函数，lambda s: s[1] 等价于一个只有 return s[1] 的小函数，只是不用起名字。它只能写一个表达式，不能有语句，用完就扔。简单的一行逻辑用 lambda 很顺手，逻辑一复杂就老老实实 def 起个名字，不然没人看得懂。

if __name__ == "__main__": 是什么#

每个 .py 文件都有一个内置变量 __name__。用 python 文件名.py 直接运行时，它是字符串 "__main__"；被别的文件 import 时，它是模块名。

所以 if __name__ == "__main__": 的意思是：这段代码只在直接运行时执行，被 import 时不执行。

为什么要写？因为别人可能想用你文件里的函数。他 import 你的文件，结果你的测试代码也跑了一遍，屏幕上凭空多出一堆输出。加上这个判断，测试代码就留在自己家里。你现在写的文件小，看不出好处；等文件多了，这是每个 Python 文件的标配。

完整程序：成绩小报告#

Python
def stats(*scores):
    """返回最低分、最高分、平均分"""
    return min(scores), max(scores), sum(scores) / len(scores)


def by_score(record):
    return record[1]


def report(records, title="成绩报告", reverse=True):
    scores = [score for _, score in records]
    low, high, avg = stats(*scores)

    print(f"== {title} ==")
    ordered = sorted(records, key=by_score, reverse=reverse)
    for i, (name, score) in enumerate(ordered, start=1):
        print(f"{i}. {name}：{score} 分")
    print(f"最低 {low}，最高 {high}，平均 {avg:.1f} 分")


if __name__ == "__main__":
    data = [("小明", 88), ("小红", 95), ("小刚", 62), ("小美", 79)]
    report(data)
    print()
    report(data, title="从低到高", reverse=False)
运行结果
== 成绩报告 ==
1. 小红：95 分
2. 小明：88 分
3. 小美：79 分
4. 小刚：62 分
最低 62，最高 95，平均 81.0 分

== 从低到高 ==
1. 小刚：62 分
2. 小美：79 分
3. 小明：88 分
4. 小红：95 分
最低 62，最高 95，平均 81.0 分
  • stats(*scores) 里的 * 把列表拆成一个个参数，正好接上第 6.4 节的 *args。列表里有 4 个分数，就拆成 4 个参数传进去。
  • by_score 单独起名字而不是写 lambda，是因为排序依据以后可能改（比如按总分），改一处就行，也更好读。
  • report 的 title 和 reverse 都有默认值，平时只传 records 就够，想换标题和顺序再传。
  • avg:.1f 是 f-string 的格式控制，保留一位小数。
  • if __name__ == "__main__": 里的 data 只是演示数据。别人 import 这个文件，不会看到任何打印。

把最后一行改成 report(data, title="从低到高")，顺序又变回从高到低，因为这次没传 reverse，它用了默认值 True。默认参数的作用就是让常用的调用最短。

◆小结
  • def 定义、名字(参数) 调用；没有 return 的函数返回 None
  • return a, b 返回元组，x, y = f() 解包
  • 位置参数在前，关键字参数在后，默认参数放末尾
  • 默认值只放不可变对象，容器默认写 None，进函数再新建
  • *args 收成元组，**kwargs 收成字典；调用时 * 还能把列表拆开
  • 作用域按 LEGB 找；global 能不用就不用，用参数和返回值代替
  • 函数是对象，能当参数传；sorted(key=...) 配 lambda 是最常见的组合
  • if __name__ == "__main__": 只在直接运行时执行，import 时不执行
  • 上一课是 第 5 课 条件、循环与缩进，下一课 第 7 课 文件、编码与异常处理 让数据活过程序结束
