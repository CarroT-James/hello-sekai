大一容易被跳过但迟早要补的一课：程序怎么跑起来、Linux 怎么用、Git 怎么不把自己坑了。

01第 1 课 进制与编码电脑只认 0 和 1，那负数、中文、小数是怎么塞进去的？这一课从「十根一捆」讲到补码、UTF-8 和乱码的来历。30 分钟02第 2 课 一个程序是怎么跑起来的你按下编译运行，黑窗口一闪就出了结果。中间那几步——预处理、编译、汇编、链接、加载——这一课全部拆开给你看。30 分钟03第 3 课 操作系统与进程任务管理器里那几十个进程到底是什么？这一课讲清进程和线程的区别、虚拟内存的「假地图」，以及操作系统在背后替你干了什么。32 分钟04第 4 课 命令行与 Linux 基础鼠标点十下的事，一行命令就干完了，还能批量干。这一课从 cd、ls 讲到管道、权限和 ssh，每一步都能照着敲。35 分钟05第 5 课 Git 与版本管理论文改到第七版，你已经分不清哪份是好的了。Git 就是给代码装一个随时能读档的存档系统，这一课的每一步都能照着敲。35 分钟06第 6 课 开发环境与调试同一行代码，有人三分钟修好，有人熬到凌晨。差别不在聪明，在于会不会读报错、会不会用断点。这一课把调试拆成可练的步骤。33 分钟07第 7 课 计算机网络入门你在地址栏敲下回车，一秒内发生了什么？这一课讲清 IP、端口、DNS、HTTP 和 HTTPS，最后在自己电脑上起一个服务器看看。34 分钟08第 8 课 用 Markdown 与 LaTeX 写作业实验报告排版花两小时，内容只写半小时——这种亏吃一次就够了。这一课把 Markdown 和公式语法讲完，附一份能直接用的作业模板。30 分钟
