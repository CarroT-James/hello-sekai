第 3 课 链表

预计 35 分钟·约 7,689 字·数据结构

链表是很多人学数据结构遇到的第一个坎。我当年把 p->next = q 和 q->next = p 抄了十遍，考试还是写反。后来发现，问题不在指针语法，而在我脑子里没有那张图。

所以这一课先不急着敲代码，先画图。你只要记住一句话：链表里每个结点只知道「下一个是谁」，别的什么都不知道。

拿食堂排队类比。队伍不是按学号站的，每个人只认识前面那个人。你想插队，只要让前面那位改认你，你再认原来那位——两个人换了个关系，后面的人根本不用动。数组就不行，数组像按学号排好的座位，中间加一个人，后面所有人都得往后挪。

写之前先把 C 语言 指针 里那点 * 和 -> 捡回来，不用全懂，会读写结构体指针就够这一课用了。

3.1 一个结点长什么样#

链表由一个个「结点」串起来。每个结点存两样东西：你的数据，和下一个结点的地址。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;   // 指向下一个结点，最后一个为 NULL
} Node;

int main(void) {
    Node *first = malloc(sizeof(Node));
    Node *second = malloc(sizeof(Node));
    Node *third = malloc(sizeof(Node));

    if (first == NULL || second == NULL || third == NULL) {
        free(first);
        free(second);
        free(third);
        return 1;
    }

    first->value = 10;
    first->next = second;

    second->value = 20;
    second->next = third;

    third->value = 30;
    third->next = NULL;

    for (Node *p = first; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");

    free(first);
    free(second);
    free(third);
    return 0;
}
运行结果
10 20 30

几个细节值得停一下：

  • 结构体里面必须写 struct Node *next，不能写 Node *next。因为这时 typedef 还没生效，编译器还不认识 Node 这个名字。
  • 最后一个结点的 next 是 NULL。遍历、插入、删除全靠它判断「到头了」。
  • for (Node *p = first; p != NULL; p = p->next) 是链表遍历的标准写法，背下来不亏。p 每轮变成下一个结点，走到 NULL 就停。

整条链表只靠一个入口指针进门。示例里它叫 first，后面统一叫 head。它是唯一的入口，丢了，后面的结点就全找不回来了。所以头插、删除头结点这些要动 head 的操作，都得格外小心。

▲常见错误

新建结点后忘了给 next 赋值，它就是一个野指针。遍历时程序会顺着一个随机地址往下跑，轻则乱码，重则段错误。malloc 只负责给内存，不负责清零，每个字段都得自己写。

3.2 头插和尾插：为什么顺序会反#

往链表里加结点，有两种加法：插到头前面，或者接到尾巴上。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *push_front(Node *head, int v) {
    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = v;
    node->next = head;   // 新结点指向原来的头
    return node;         // 新结点成为新头
}

Node *push_back(Node *head, int v) {
    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = v;
    node->next = NULL;

    if (head == NULL) return node;   // 空链表，它就是头

    Node *p = head;
    while (p->next != NULL) p = p->next;   // 走到最后一个
    p->next = node;
    return head;
}

void print_list(Node *head) {
    for (Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");
}

void free_list(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;
        free(p);
        p = next;
    }
}

int main(void) {
    Node *a = NULL;
    for (int i = 1; i <= 5; i++) a = push_front(a, i);
    printf("头插：");
    print_list(a);
    free_list(a);

    Node *b = NULL;
    for (int i = 1; i <= 5; i++) b = push_back(b, i);
    printf("尾插：");
    print_list(b);
    free_list(b);

    return 0;
}
运行结果
头插：5 4 3 2 1
尾插：1 2 3 4 5

同一组数字，一个倒着出来，一个正着出来。原因很直观：头插每次都把新结点放在最前面，后放的盖住先放的；尾插每次都走到最后接上，顺序自然是插入顺序。

代价也不一样。头插只改两根指针，O(1)；尾插要从头走到尾，O(n)。想让它也变成 O(1)，可以额外维护一个 tail 指针，但删除尾结点时又得找到它的前一个，麻烦事在后头。

▲常见错误

head = push_front(head, v) 这个赋值不能省。函数的参数 head 只是一个副本，你在函数里改它，改了外面也不知道。不接返回值，新结点就丢了——内存泄漏，而且链表里根本找不到它。

3.3 遍历与查找：只能从头走#

数组能一步跳到 a[999]，链表不行。你手里只有头结点，想知道第 999 个是谁，只能走 998 次 next。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *push_back(Node *head, int v) {
    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = v;
    node->next = NULL;
    if (head == NULL) return node;
    Node *p = head;
    while (p->next != NULL) p = p->next;
    p->next = node;
    return head;
}

int length(Node *head) {
    int n = 0;
    for (Node *p = head; p != NULL; p = p->next) n++;
    return n;
}

int find(Node *head, int value) {
    int index = 0;
    for (Node *p = head; p != NULL; p = p->next, index++) {
        if (p->value == value) return index;
    }
    return -1;
}

void free_list(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;
        free(p);
        p = next;
    }
}

int main(void) {
    Node *head = NULL;
    for (int i = 1; i <= 5; i++) head = push_back(head, i * 10);

    printf("长度：%d\n", length(head));
    printf("30 在下标 %d\n", find(head, 30));
    printf("99 在下标 %d\n", find(head, 99));

    free_list(head);   // 释放整条链表
    return 0;
}
运行结果
长度：5
30 在下标 2
99 在下标 -1

遍历和查找都是 O(n)，这是链表的硬伤。也正因为如此，说「链表插入是 O(1)」时必须补一句：前提是你已经站在要插入的位置上。手里只有头结点的话，先找到那个位置就已经 O(n) 了。

这就像寻宝纸条：每张只写下一个线索藏在哪。你想看第 10 张，只能一张一张顺着找，不能直接翻到第 10 张；但要在某张后面再塞一张新的，只要改两个线索，很快。

注意 find 返回的那个下标，是一步一步数出来的，不是算出来的。它和数组的 a[i] 有本质区别：数组是「跳过去」，链表是「走过去」。刷题时看到「返回第 k 个结点」，别下意识写 p = p + k，链表上没有这种加法。

3.4 按位置插入：先接新结点，再断旧线#

插入的代码只有两行，但顺序错了就出事。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *push_back(Node *head, int v) {
    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = v;
    node->next = NULL;
    if (head == NULL) return node;
    Node *p = head;
    while (p->next != NULL) p = p->next;
    p->next = node;
    return head;
}

Node *insert_at(Node *head, int pos, int value) {
    if (pos < 0) return head;
    if (pos == 0) {
        Node *node = malloc(sizeof(Node));
        if (node == NULL) return head;
        node->value = value;
        node->next = head;
        return node;
    }

    Node *prev = head;
    for (int i = 0; i < pos - 1 && prev != NULL; i++) {
        prev = prev->next;
    }
    if (prev == NULL) return head;   // pos 超出长度

    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = value;
    node->next = prev->next;   // 第一步：新结点接上后半段
    prev->next = node;         // 第二步：前一个结点改认新结点
    return head;
}

void print_list(Node *head) {
    for (Node *p = head; p != NULL; p = p->next) printf("%d ", p->value);
    printf("\n");
}

void free_list(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;
        free(p);
        p = next;
    }
}

int main(void) {
    Node *head = NULL;
    for (int i = 1; i <= 4; i++) head = push_back(head, i * 10);

    head = insert_at(head, 2, 25);
    print_list(head);

    head = insert_at(head, 0, 5);
    print_list(head);

    head = insert_at(head, 99, 999);   // 位置越界，什么都不做
    print_list(head);

    free_list(head);
    return 0;
}
运行结果
10 20 25 30 40
5 10 20 25 30 40
5 10 20 25 30 40

核心就两行：

  • node->next = prev->next：先让新结点握住后半段的头
  • prev->next = node：再让前一个结点改认新结点

顺序不能反。如果先写 prev->next = node，原来 prev->next 指向的那个结点就再也没人指向它了，后半段整条丢失——而且它还在内存里，你连 free 都找不到它。

★补充说明

插入或删除头结点都可能改 head 本身，所以这里的函数都返回新的头。另一种写法是传 Node **head，函数里用 *head 直接改调用者的变量，不用返回值。两种都对，返回值写法更好懂，先把一种写熟。

3.5 删除：先接上，再拆线，最后 free#

删除比插入多一步：除了改指针，还得把结点还给系统。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *push_back(Node *head, int v) {
    Node *node = malloc(sizeof(Node));
    if (node == NULL) return head;
    node->value = v;
    node->next = NULL;
    if (head == NULL) return node;
    Node *p = head;
    while (p->next != NULL) p = p->next;
    p->next = node;
    return head;
}

Node *delete_value(Node *head, int value) {
    Node *prev = NULL;
    Node *cur = head;

    while (cur != NULL && cur->value != value) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return head;   // 没找到

    if (prev == NULL) {
        head = cur->next;           // 删的是头结点
    } else {
        prev->next = cur->next;     // 前一个跨过 cur
    }
    free(cur);
    return head;
}

void print_list(Node *head) {
    for (Node *p = head; p != NULL; p = p->next) printf("%d ", p->value);
    printf("\n");
}

void free_list(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;
        free(p);
        p = next;
    }
}

int main(void) {
    Node *head = NULL;
    for (int i = 1; i <= 4; i++) head = push_back(head, i * 10);

    head = delete_value(head, 20);
    print_list(head);

    head = delete_value(head, 10);
    print_list(head);

    head = delete_value(head, 99);
    print_list(head);

    free_list(head);
    return 0;
}
运行结果
10 30 40
30 40
30 40

删除的逻辑是「让前一个结点跳过当前结点」：prev->next = cur->next。删头结点时没有前一个，只能改 head。

顺序很重要：先把指针接好，再 free(cur)。如果你先 free(cur)，然后还想读 cur->next，那是在读已经还给系统的内存——这叫 use-after-free，可能当场崩，也可能安安静静地跑出错误结果，过半小时再崩给你看。

这个版本只删第一个匹配的结点。想删掉所有相同值，就在外面套一层循环，但每次删完要从头重新找，别接着用已经 free 掉的 cur。

3.6 链表 vs 动态数组：把代价摆在一张表里#

操作动态数组链表
按下标访问 a[i]O(1)O(n)
头部插入O(n)O(1)
尾部插入均摊 O(1)O(n)，有尾指针则 O(1)
已知位置的插入删除O(n)O(1)
按值查找O(n)O(n)
额外内存预留的容量每个结点一个指针
CPU 缓存友好度好差

这张表有个很容易被误读的结论：链表好像全面占优。实际不是。

链表每个结点都是单独 malloc 出来的，地址东一块西一块，CPU 缓存基本帮不上忙；而且每次 malloc/free 都有开销。数组虽然「插入 O(n)」，但那是连续内存上的一次 memmove，跑起来极快。数据量不大的时候，数组常常反过来赢链表。

所以别因为背了「链表插入 O(1)」就到处用链表。真实项目里，数组（以及第 2 课那种动态数组）用得比链表多得多；链表真正的主场是「频繁在已知位置插入删除」和「不想预留大块连续内存」——比如操作系统的空闲内存块管理、图里的邻接表。

还有个实际问题：链表结点的地址东一个西一个，调试器里看是一跳一跳的，初学时不画图根本对不上号。我的习惯是每写一个链表函数，先在纸上画三个方框、两根箭头，照着图敲代码。图对了，代码基本就对了。

想亲眼看看缓存的影响，可以做个小实验：生成 100 万个整数，分别放进数组和链表，各遍历 100 遍，用 clock() 计时。链表大概率慢好几倍，尽管两边的复杂度都写着 O(n)。

✎练习
  1. 写 void print_reverse(Node *head)，递归地从尾到头打印链表，但不要真的反转。再想一下：链表有 10 万个结点时，这个递归会出什么事？
  2. 写 Node *reverse_list(Node *head) 原地反转单链表，只许改 next，不许新建结点。先画出三个指针 prev、cur、next 每一步的位置，再写代码。
  3. 合并两个升序链表，返回合并后的头结点，要求复用原来的结点、不额外 malloc。例如 1 3 5 和 2 4 6 合并成 1 2 3 4 5 6。
  4. 不用 malloc，用三个数组 value[100]、next[100]、head 模拟一条链表，实现头插、遍历和按值删除。体会一下「静态链表」是怎么在没有指针的环境里工作的。
◆小结
  • 链表结点 = 一份数据 + 一个 next 指针，最后一个指向 NULL
  • 头插 O(1)，尾插 O(n)，按下标访问 O(n)
  • 插入两步：新结点先接后半段，前一个结点再改指向；说它 O(1) 的前提是你已经拿到了那个位置
  • 删除先改指针再接 free，free 之后不能再碰那个结点
