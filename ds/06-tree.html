第 6 课 树与二叉树

预计 40 分钟·约 7,945 字·数据结构

前面几课的结构都是「一条线」：数组是一条线，链表是一条线，栈和队列也不过是线的两种用法。现实里的关系很少这么老实——家里的族谱、电脑里的文件夹、一个公司的组织架构，都是一层一层往下分的。

树就是用来存这种关系的。

我得先承认：树的递归遍历是这门课第一个真正绕人的地方。我当年看前序、中序、后序，觉得这三个名字毫无道理，三段代码长得也差不多。后来自己画了一棵树，把三种输出写在一张纸上，才突然明白——所谓「序」，只是根在什么时候被访问。

6.1 树：一个根，往下分叉#

树有一个根结点，从根往下分出若干个子结点，每个子结点再往下分。规则只有两条：

  • 除了根，每个结点只有一个父结点
  • 顺着指针往下走，永远不会绕回自己，也就是没有环

第二条把「环」排除在外。链表其实也能看成树的一个特例：每个结点最多一个孩子，而且只有一边。所以你可以把树理解成「链表放开了孩子数量的限制」。

看一棵具体的二叉树。它长这样：

TEXT
        1
       / \
      2   3
     / \   \
    4   5   6

结点 1 是根。它有两个孩子：左边 2，右边 3。2 又有两个孩子 4 和 5，3 只有一个右孩子 6。4、5、6 都没有孩子，叫叶子。

6.2 术语：根、叶、深度、高度#

数据结构的术语第一次看很吓人，其实就那么几个，对着图看一遍就懂了。

术语意思在这棵树里
根唯一没有父结点的结点1
叶子没有孩子的结点4、5、6
度一个结点有几个孩子1 的度是 2，3 的度是 1
深度从根往下数，根为第 0 层4 的深度是 2
高度从叶子往上数，叶子为 1整棵树的高度是 3

深度和高度最容易混。深度是「从上往下数」，高度是「从下往上数」。同一棵树，根的深度是 0，高度是 3；叶子 4 的深度是 2，高度是 1。做题时看清题目说的是哪个。

◆记忆点

二叉树不是「每个结点必须有两个孩子」，而是「每个结点最多两个孩子」。可以没有，可以只有一个。4、5、6 这种没有孩子的，也是合法的二叉树结点。

6.3 二叉树与它的 C 写法#

二叉树的每个结点，除了存数据，还要存两个指针：左孩子和右孩子。这种「结构体里放指向自己的指针」的写法，和 C 语言 结构体 里的链表结点是同一套，只是从一个指针变成了两个。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int value;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *new_node(int v) {
    TreeNode *p = malloc(sizeof(TreeNode));
    if (p == NULL) return NULL;
    p->value = v;
    p->left = NULL;
    p->right = NULL;
    return p;
}

TreeNode *build_tree(void) {
    TreeNode *n1 = new_node(1);
    TreeNode *n2 = new_node(2);
    TreeNode *n3 = new_node(3);
    TreeNode *n4 = new_node(4);
    TreeNode *n5 = new_node(5);
    TreeNode *n6 = new_node(6);

    if (n1 == NULL || n2 == NULL || n3 == NULL ||
        n4 == NULL || n5 == NULL || n6 == NULL) {
        return NULL;
    }

    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;
    n3->right = n6;

    return n1;
}

void free_tree(TreeNode *root) {
    if (root == NULL) return;
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

int main(void) {
    TreeNode *root = build_tree();
    if (root == NULL) return 1;

    printf("根是 %d\n", root->value);
    printf("根的左孩子是 %d，右孩子是 %d\n",
           root->left->value, root->right->value);
    printf("左孩子的左孩子是 %d\n", root->left->left->value);

    free_tree(root);
    return 0;
}
运行结果
根是 1
根的左孩子是 2，右孩子是 3
左孩子的左孩子是 4

left 和 right 为 NULL，表示这个方向没有孩子。叶子的两个指针都是 NULL。

free_tree 是个值得多看两眼的函数：它先释放左子树，再释放右子树，最后释放自己。如果先 free(root) 再去访问 root->left，就是在读已经回收的内存。这个顺序不是随便定的，下一节讲完后你会发现，它就是后序遍历。

6.4 三种遍历：前序、中序、后序#

遍历就是把每个结点访问一遍。树不是一条线，所以「按什么顺序访问」有好几种答案。最常用的三种，区别只在于根什么时候被访问：

  • 前序：根 → 左 → 右
  • 中序：左 → 根 → 右
  • 后序：左 → 右 → 根

看代码比看名字快。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int value;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *new_node(int v) {
    TreeNode *p = malloc(sizeof(TreeNode));
    if (p == NULL) return NULL;
    p->value = v;
    p->left = NULL;
    p->right = NULL;
    return p;
}

TreeNode *build_tree(void) {
    TreeNode *n1 = new_node(1);
    TreeNode *n2 = new_node(2);
    TreeNode *n3 = new_node(3);
    TreeNode *n4 = new_node(4);
    TreeNode *n5 = new_node(5);
    TreeNode *n6 = new_node(6);

    if (n1 == NULL || n2 == NULL || n3 == NULL ||
        n4 == NULL || n5 == NULL || n6 == NULL) {
        return NULL;
    }

    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;
    n3->right = n6;
    return n1;
}

void preorder(TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->value);
    preorder(root->left);
    preorder(root->right);
}

void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->value);
    inorder(root->right);
}

void postorder(TreeNode *root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->value);
}

void free_tree(TreeNode *root) {
    if (root == NULL) return;
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

int main(void) {
    TreeNode *root = build_tree();
    if (root == NULL) return 1;

    printf("前序：");
    preorder(root);
    printf("\n");

    printf("中序：");
    inorder(root);
    printf("\n");

    printf("后序：");
    postorder(root);
    printf("\n");

    free_tree(root);
    return 0;
}
运行结果
前序：1 2 4 5 3 6
中序：4 2 5 1 3 6
后序：4 5 2 6 3 1

三个函数只差一行 printf 的位置。前序把根放在最前面，中序放在中间，后序放在最后。你把 printf 在脑子里挪一下位置，输出就跟着变了。

换个结构试试：把 6 从 3 的右边挪到左边，中序立刻从 4 2 5 1 3 6 变成 4 2 5 1 6 3。树的结构变了，遍历序列一定跟着变。反过来，给定一棵没有重复值的二叉树，中序序列和任意一种其他序列，能唯一还原出这棵树——很多题就是拿这个做文章。

6.5 递归遍历怎么读：相信子树#

我知道递归难。刚学的时候，我会在脑子里把整棵树一层层展开，展开到第三层就乱了：preorder 调用 preorder，里面又调用 preorder，到底执行到哪一行？

后来我换了个想法：不要展开，相信它。

写 preorder 的时候，你只做三件事：

  1. 打印根
  2. 让左子树自己前序遍历
  3. 让右子树自己前序遍历

左子树怎么前序遍历？它也用 preorder，也会做这三件事。你不用管它内部怎么转，只要相信它能把自己的子树按前序打完。这就是递归的信任跳跃：先假设函数对子树已经正确了，再考虑当前这一层。

每个递归函数都要有终止条件。这里的终止条件是「空树直接返回」，否则会无限往下调用，最后栈溢出。

这个套路不只用于打印。数结点、数叶子、求高度，骨架一模一样，只是把「打印」换成了「返回一个数」。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int value;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *new_node(int v) {
    TreeNode *p = malloc(sizeof(TreeNode));
    if (p == NULL) return NULL;
    p->value = v;
    p->left = NULL;
    p->right = NULL;
    return p;
}

TreeNode *build_tree(void) {
    TreeNode *n1 = new_node(1);
    TreeNode *n2 = new_node(2);
    TreeNode *n3 = new_node(3);
    TreeNode *n4 = new_node(4);
    TreeNode *n5 = new_node(5);
    TreeNode *n6 = new_node(6);

    if (n1 == NULL || n2 == NULL || n3 == NULL ||
        n4 == NULL || n5 == NULL || n6 == NULL) {
        return NULL;
    }

    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;
    n3->right = n6;
    return n1;
}

int count_nodes(TreeNode *root) {
    if (root == NULL) return 0;
    return 1 + count_nodes(root->left) + count_nodes(root->right);
}

int count_leaves(TreeNode *root) {
    if (root == NULL) return 0;
    if (root->left == NULL && root->right == NULL) return 1;
    return count_leaves(root->left) + count_leaves(root->right);
}

int height(TreeNode *root) {
    if (root == NULL) return 0;
    int l = height(root->left);
    int r = height(root->right);
    return (l > r ? l : r) + 1;
}

void free_tree(TreeNode *root) {
    if (root == NULL) return;
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

int main(void) {
    TreeNode *root = build_tree();
    if (root == NULL) return 1;

    printf("结点数：%d\n", count_nodes(root));
    printf("叶子数：%d\n", count_leaves(root));
    printf("高度：%d\n", height(root));

    free_tree(root);
    return 0;
}
运行结果
结点数：6
叶子数：3
高度：3

height 里 (l > r ? l : r) + 1 的意思是：左右两边谁高听谁的，再加 1 层自己。空树返回 0，叶子左右都是空，返回 max(0, 0) + 1 = 1，正好。

▲常见错误

空树的返回值要统一。height 空树返回 0，叶子高度就是 1；如果改成返回 -1，叶子高度会变成 0，整棵树高度变成 2。两种约定都有人用，但一棵树的计算里只能用一种。混着用，结果差一位，还不报错。

6.6 层序遍历：树加队列#

前三种遍历都是一头扎到底，先走完一整条枝再回头。层序遍历不一样：一层一层来，先访问第 0 层，再第 1 层、第 2 层。

递归在这儿不好使了，因为递归天生是「往下钻」。这时候得请回第 5 课 队列。

C
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int value;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *new_node(int v) {
    TreeNode *p = malloc(sizeof(TreeNode));
    if (p == NULL) return NULL;
    p->value = v;
    p->left = NULL;
    p->right = NULL;
    return p;
}

TreeNode *build_tree(void) {
    TreeNode *n1 = new_node(1);
    TreeNode *n2 = new_node(2);
    TreeNode *n3 = new_node(3);
    TreeNode *n4 = new_node(4);
    TreeNode *n5 = new_node(5);
    TreeNode *n6 = new_node(6);

    if (n1 == NULL || n2 == NULL || n3 == NULL ||
        n4 == NULL || n5 == NULL || n6 == NULL) {
        return NULL;
    }

    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;
    n3->right = n6;
    return n1;
}

void level_order(TreeNode *root) {
    TreeNode *queue[32];
    int head = 0, tail = 0;

    if (root != NULL) queue[tail++] = root;

    while (head < tail) {
        TreeNode *p = queue[head++];
        printf("%d ", p->value);

        if (p->left != NULL) queue[tail++] = p->left;
        if (p->right != NULL) queue[tail++] = p->right;
    }
    printf("\n");
}

void free_tree(TreeNode *root) {
    if (root == NULL) return;
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

int main(void) {
    TreeNode *root = build_tree();
    if (root == NULL) return 1;

    printf("层序：");
    level_order(root);

    free_tree(root);
    return 0;
}
运行结果
层序：1 2 3 4 5 6

思路就三步：根入队；每次弹出一个结点，打印它；把它的左孩子、右孩子依次入队。队列先进先出，所以第 0 层的 1 出去以后，第 1 层的 2、3 排在队里；等 2、3 都处理完，第 2 层的 4、5、6 才轮到。一层一层，自动就分好了。

这个套路很值钱：第 8 课的堆，就是按层序把完全二叉树塞进数组；第 10 课的图，BFS 也是同一个骨架，只是把「两个孩子」换成了「所有邻居」。

6.7 两个常见误解#

第一个误解：二叉树就是二叉搜索树。不是。6.1 那棵树只是长成了二叉树的样子，没有任何排序性质。它左子树的值不一定比根小，右子树也不一定比根大。二叉搜索树是在二叉树的基础上再加一条规矩，第 7 课讲。

第二个误解：树只能用指针存。完全二叉树就可以用数组存，而且更省事。把结点按层序编号，从 0 开始，下标 i 的结点，左孩子是 2i+1，右孩子是 2i+2，父亲是 (i-1)/2（i > 0 时）。

C
#include <stdio.h>

int main(void) {
    int tree[6] = {1, 2, 3, 4, 5, 6};
    int n = 6;

    for (int i = 0; i < n; i++) {
        printf("tree[%d] = %d", i, tree[i]);
        if (2 * i + 1 < n) printf("，左孩子 %d", tree[2 * i + 1]);
        if (2 * i + 2 < n) printf("，右孩子 %d", tree[2 * i + 2]);
        printf("\n");
    }
    return 0;
}
运行结果
tree[0] = 1，左孩子 2，右孩子 3
tree[1] = 2，左孩子 4，右孩子 5
tree[2] = 3，左孩子 6
tree[3] = 4
tree[4] = 5
tree[5] = 6

为什么非得是「完全」二叉树？因为数组中间不能空。要是树长歪了，缺的那个位置也得占着，一棵 1000 个结点的斜树可能要开 2^1000 个格子，根本不可能。完全二叉树一层填满再填下一层，中间没有洞，数组才不浪费。

✎练习
  1. 写 count_degree_one(TreeNode *root)，统计只有一个孩子的结点个数；再写 find_max(TreeNode *root)，返回指向值最大结点的指针。
  2. 不用递归，用一个数组当栈实现前序遍历。提示：先把右孩子压栈，再压左孩子，这样左孩子会先出来。
  3. 写 same_tree(TreeNode *a, TreeNode *b)，判断两棵树的结构和每个结点的值是否完全一样。
  4. 用数组存一棵完全二叉树，写前序、中序、后序三个递归函数；再写 is_max_heap，判断它是不是大根堆，也就是每个父结点都大于等于它的孩子。
◆小结
  • 树有一个根，每个结点最多一个父结点；二叉树每个结点最多两个孩子，用 left 和 right 表示
  • 前序、中序、后序的区别只有一个：根在什么时候被访问
  • 写递归遍历别在脑子里展开整棵树，相信子树已经正确
  • 层序遍历用队列，一层一层出，这个骨架后面还会反复出现
