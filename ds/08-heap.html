第 8 课 堆与优先队列

预计 35 分钟·约 7,241 字·数据结构

上一课 第 7 课 二叉搜索树 里的 BST 对顺序很讲究：左小右大，一点都不能乱。这一课要讲的堆正相反，它对顺序极其马虎，兄弟之间谁大谁小完全不关心，只守一条：每个结点都不小于它的两个孩子。

听起来像偷懒，但这条偷懒的规矩换来了一样 BST 给不了的东西：随时能拿到最大值，而且拿走的代价只有 O(log n)。

医院急诊分诊就是堆的逻辑。病人来了不排队，按病情插进去；医生永远先看最重的那一个。你不关心第二个和第三个谁更重，你只关心「现在最该看谁」。

8.1 堆只保证一件事：根是最大的#

大根堆的规矩有两条：

  • 每个结点的值都不小于它的两个孩子
  • 整棵树是完全二叉树，除了最后一层，别的层都填满，最后一层靠左挨着排

第一条保证根是全场最大。第二条看着像排版要求，其实是为了存储：完全二叉树没有空洞，可以直接压进一个数组，一个字节都不浪费。

注意堆不保证「左孩子比右孩子大」，也不保证「第二层比第三层都大」。它是一条条从根到叶的链上递减，不是一层层递减。这一点新手最容易想错。

你想要该用什么
随时取最大/最小，还要能插入堆，O(log n)
全部排好序，能按顺序遍历BST 或排序，O(log n) 或 O(n log n)
按 key 查值哈希表，O(1)

8.2 用数组装一棵完全二叉树#

完全二叉树没有空洞，所以从 0 开始给结点编号，父子关系能直接用下标算出来：

  • i 的父结点是 (i - 1) / 2
  • i 的左孩子是 2 * i + 1，右孩子是 2 * i + 2

这组公式是整课的钥匙，最好背下来。它意味着你不需要任何指针，一个 int 数组就是一棵树。数组下标和地址的关系在 C 语言 数组 里讲过，不熟的话回去扫一眼。

C
#include <stdio.h>

int main(void) {
    int a[] = {90, 70, 80, 40, 60, 50, 30};
    int n = 7;

    for (int i = 0; i < n; i++) {
        printf("a[%d] = %2d", i, a[i]);
        if (i > 0) {
            printf("，父 %d", a[(i - 1) / 2]);
        }
        if (2 * i + 1 < n) {
            printf("，左 %d", a[2 * i + 1]);
        }
        if (2 * i + 2 < n) {
            printf("，右 %d", a[2 * i + 2]);
        }
        printf("\n");
    }
    return 0;
}
运行结果
a[0] = 90，左 70，右 80
a[1] = 70，父 90，左 40，右 60
a[2] = 80，父 90，左 50，右 30
a[3] = 40，父 70
a[4] = 60，父 70
a[5] = 50，父 80
a[6] = 30，父 80

第 0 个元素没有父结点，代码里用 i > 0 挡掉了，否则 (0 - 1) / 2 在整数除法下是 0，程序会拿根结点当它自己的爸爸，不崩但很荒唐。

下标 3 到 6 都没有孩子，因为 2 * 3 + 1 = 7 已经越界。下标大于等于 n / 2 的结点全是叶子，这句话在 8.5 建堆时会再用一次。

再检查一下这棵树是不是大根堆：90 的两个孩子 70、80 都比它小；70 的孩子 40、60 也比它小；80 的孩子 50、30 更小。三条链 90-70-60、90-70-40、90-80-50，都是递减的，符合规矩。

8.3 插入：先放到最后，再往上顶#

往堆里加一个元素，分两步：

  1. 放到数组末尾，也就是完全二叉树的最后一个空位
  2. 和父结点比，比父结点大就交换，一直换到不用换为止

这叫上浮。它只沿着一条从叶到根的路径走，最多 log2(n) 步。

C
#include <stdio.h>

#define MAXN 100

int heap[MAXN];
int n = 0;

void push(int v) {
    int i = n;
    n++;
    heap[i] = v;

    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[parent] >= heap[i]) {
            break;
        }
        int t = heap[parent];
        heap[parent] = heap[i];
        heap[i] = t;
        i = parent;
    }
}

void show(void) {
    printf("[");
    for (int i = 0; i < n; i++) {
        printf("%d%s", heap[i], i + 1 < n ? " " : "");
    }
    printf("]\n");
}

int main(void) {
    int values[] = {50, 30, 80, 20, 90, 70};
    for (int i = 0; i < 6; i++) {
        push(values[i]);
        printf("push %d 后：", values[i]);
        show();
    }
    return 0;
}
运行结果
push 50 后：[50]
push 30 后：[50 30]
push 80 后：[80 30 50]
push 20 后：[80 30 50 20]
push 90 后：[90 80 50 20 30]
push 70 后：[90 80 70 20 30 50]

盯着最后一步看：70 放进下标 6，父结点是下标 2 的 50，70 更大，交换，数组变成 [90 80 70 20 30 50]。再看父结点下标 0 的 90，90 更大，停。整个上浮只走了两层。

if (heap[parent] >= heap[i]) break; 这一句不能漏。少了它，循环会一路换到根，把本来对的顺序又换坏。

8.4 弹出堆顶：这就是优先队列的出队#

取最大值很简单，heap[0]。难的是取完之后怎么补位。

能直接让左孩子顶上来吗？不行，右孩子可能更大。标准做法有点反直觉：把最后一个元素搬到根上，然后让它往下沉。

下沉的规则：和两个孩子里较大的那个比，自己小了就交换，一直换到不用换或者到底为止。

C
#include <stdio.h>

#define MAXN 100

int heap[MAXN];
int n = 0;

void push(int v) {
    int i = n;
    n++;
    heap[i] = v;
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[parent] >= heap[i]) {
            break;
        }
        int t = heap[parent];
        heap[parent] = heap[i];
        heap[i] = t;
        i = parent;
    }
}

int pop(void) {
    int top = heap[0];
    n--;
    heap[0] = heap[n];

    int i = 0;
    while (1) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int big = i;
        if (left < n && heap[left] > heap[big]) {
            big = left;
        }
        if (right < n && heap[right] > heap[big]) {
            big = right;
        }
        if (big == i) {
            break;
        }
        int t = heap[i];
        heap[i] = heap[big];
        heap[big] = t;
        i = big;
    }
    return top;
}

int main(void) {
    int values[] = {50, 30, 80, 20, 90, 70};
    for (int i = 0; i < 6; i++) {
        push(values[i]);
    }

    while (n > 0) {
        printf("%d ", pop());
    }
    printf("\n");
    return 0;
}
运行结果
90 80 70 50 30 20

输出是降序，这很符合直觉：每次拿走的都是当前最大的。

heap[0] = heap[n]; 这一行把最后一个元素搬到了根，所以 n-- 必须在它前面，否则搬的是已经被扔掉的自己。这种「先减长度再取元素」的小顺序，写反了不报错，只是偶尔少一个数。

big 的写法值得学：先假设自己最大，再依次和左、右孩子比，全程只维护一个下标。比写一堆 if-else 分支清楚得多。

◆记忆点

上浮是和父亲比，下沉是和两个孩子里大的那个比。上浮用于插入，下沉用于删除。两者的循环次数都不超过树高。

这里就是优先队列。所谓优先队列，不是一种新结构，而是「每次取出的都是当前优先级最高的元素」这个接口。堆是实现它最常用的方式，入队 = push，出队 = pop，取队头 = heap[0]，三个操作全是 O(log n) 或 O(1)。急诊分诊、任务调度、Dijkstra 最短路，用的都是它。

C 标准库没有堆，<stdlib.h> 里只有 qsort，所以你得自己写这几行。C++ 的 std::priority_queue 和 Python 的 heapq 就是现成的，接口一模一样。

8.5 建堆：为什么它只要 O(n)#

如果手上已经有一整个数组，要把它变成堆，笨办法是挨个 push，那是 O(n log n)。

聪明办法是从最后一个非叶结点开始，倒着对每个结点做一次下沉：

C
#include <stdio.h>

long swaps = 0;

void sift_down(int *a, int n, int i) {
    while (1) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int big = i;
        if (left < n && a[left] > a[big]) {
            big = left;
        }
        if (right < n && a[right] > a[big]) {
            big = right;
        }
        if (big == i) {
            return;
        }
        int t = a[i];
        a[i] = a[big];
        a[big] = t;
        swaps++;
        i = big;
    }
}

void push(int *a, int *n, int v) {
    int i = *n;
    (*n)++;
    a[i] = v;
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (a[parent] >= a[i]) {
            break;
        }
        int t = a[parent];
        a[parent] = a[i];
        a[i] = t;
        swaps++;
        i = parent;
    }
}

void heapify(int *a, int n) {
    for (int i = n / 2 - 1; i >= 0; i--) {
        sift_down(a, n, i);
    }
}

int main(void) {
    int a[15];
    int b[15];
    int na = 0;
    int nb = 15;

    for (int i = 0; i < 15; i++) {
        a[i] = i + 1;
        b[i] = i + 1;
    }

    swaps = 0;
    for (int i = 0; i < 15; i++) {
        push(a, &na, b[i]);
    }
    long push_swaps = swaps;

    swaps = 0;
    heapify(b, nb);
    long heapify_swaps = swaps;

    printf("逐个 push 建堆：%ld 次交换\n", push_swaps);
    printf("heapify 建堆：%ld 次交换\n", heapify_swaps);
    printf("堆顶：%d\n", b[0]);
    return 0;
}
运行结果
逐个 push 建堆：34 次交换
heapify 建堆：11 次交换
堆顶：15

同样 15 个数据，push 花了 34 次交换，heapify 只花 11 次。数据越多，差距越明显。

为什么 heapify 是 O(n)？因为大部分结点都在树的底部，它们下沉的距离很短。准确地说，高度为 h 的结点大约有 n/2^(h+1) 个，总代价是 Σ(n/2^(h+1) · h)，这个级数收敛到 n，不是 n log n。绝大多数结点根本不需要动，这就是省下来的部分。

循环从 n / 2 - 1 开始，因为下标大于等于 n / 2 的全是叶子，叶子没有孩子，下沉一次就立刻返回，纯属浪费。

push 里我改成了传 int *n，因为要修改长度。如果这里写成 int n，函数里的 (*n)++ 就改不到外面，主函数里的 na 永远是 0。

8.6 堆排序#

有了 heapify 和 sift_down，排序几乎不用写新代码：

  1. 先把数组 heapify 成一个大根堆，此时 a[0] 最大
  2. 把 a[0] 和 a[n-1] 交换，最大值就落到了最终位置
  3. 把堆的有效长度减一，对新的根做一次下沉
  4. 重复 2、3，直到只剩一个元素
C
#include <stdio.h>

void sift_down(int *a, int n, int i) {
    while (1) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int big = i;
        if (left < n && a[left] > a[big]) {
            big = left;
        }
        if (right < n && a[right] > a[big]) {
            big = right;
        }
        if (big == i) {
            return;
        }
        int t = a[i];
        a[i] = a[big];
        a[big] = t;
        i = big;
    }
}

void heapsort(int *a, int n) {
    for (int i = n / 2 - 1; i >= 0; i--) {
        sift_down(a, n, i);
    }
    for (int end = n - 1; end > 0; end--) {
        int t = a[0];
        a[0] = a[end];
        a[end] = t;
        sift_down(a, end, 0);
    }
}

int main(void) {
    int a[] = {5, 2, 9, 1, 7, 6, 3};
    int n = 7;

    heapsort(a, n);
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
运行结果
1 2 3 5 6 7 9

注意第二次循环里传的是 end 而不是 n。end 就是当前堆的有效长度，已经把排好的那部分排除掉了。这个「有效长度」的概念是堆排序的关键，写错成 n 的话，最大的元素又被换回堆里，结果会乱。

堆排序的时间是 O(n log n)，空间 O(1)，原地完成，看起来完美。但它有一个缺点：不稳定。两个相等的元素，排序后谁在前谁在后没有保证，因为交换是跨越大段距离的。这一点下一课讲排序时会展开。

8.7 top-k：只留 k 个，别的都扔掉#

面试里最爱问的一道题：从 100 万个数里找最大的 10 个。

把 100 万个数全排序是 O(n log n)，还要额外内存。用堆只要 O(n log k)：维护一个大小为 k 的堆，新元素进来跟堆顶比一下，比堆顶「更有资格」就替换掉堆顶。

有意思的是方向：找前 k 小，要用大根堆。堆顶是这 k 个里最大的那个，也就是最没资格留下的那个。新来的只要比它小，就该把它挤掉。

C
#include <stdio.h>

void sift_down(int *a, int n, int i) {
    while (1) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int big = i;
        if (left < n && a[left] > a[big]) {
            big = left;
        }
        if (right < n && a[right] > a[big]) {
            big = right;
        }
        if (big == i) {
            return;
        }
        int t = a[i];
        a[i] = a[big];
        a[big] = t;
        i = big;
    }
}

void heapify(int *a, int n) {
    for (int i = n / 2 - 1; i >= 0; i--) {
        sift_down(a, n, i);
    }
}

void heapsort(int *a, int n) {
    for (int i = n / 2 - 1; i >= 0; i--) {
        sift_down(a, n, i);
    }
    for (int end = n - 1; end > 0; end--) {
        int t = a[0];
        a[0] = a[end];
        a[end] = t;
        sift_down(a, end, 0);
    }
}

int main(void) {
    int data[] = {7, 1, 9, 3, 8, 2, 6, 4, 5};
    int total = 9;
    int k = 4;
    int top[4];

    for (int i = 0; i < k; i++) {
        top[i] = data[i];
    }
    heapify(top, k);

    for (int i = k; i < total; i++) {
        if (data[i] < top[0]) {
            top[0] = data[i];
            sift_down(top, k, 0);
        }
    }

    heapsort(top, k);
    printf("前 %d 小：", k);
    for (int i = 0; i < k; i++) {
        printf("%d ", top[i]);
    }
    printf("\n");
    return 0;
}
运行结果
前 4 小：1 2 3 4

top 只有 4 个格子，输入有 9 个数，内存占用和总数无关。这就是 top-k 的妙处：n 可以大到装不进内存，k 小到随便放。

把 data[i] < top[0] 改成 data[i] > top[0]，再把 sift_down 换成「小根堆」的版本，就是「前 k 大」。方向一反过来，整个逻辑都要跟着翻，这里最容易写混，建议两种都手写一遍。

▲常见错误

用大根堆找前 k 大，然后再从堆里取 k 次——那要先把 100 万个数全建成堆，O(n) 内存全占了，等于没用 top-k 的思路。找前 k 大必须用小根堆，堆里始终只放 k 个。

✎练习
  1. 把本课的堆改成小根堆（最小堆），用同一组数据测试 push、pop，输出应该是升序。
  2. 给堆加一个 change(int i, int v)，把下标 i 的元素改成 v，仍然保持堆性质。提示：变大就上浮，变小就下沉。
  3. 用堆合并 k 个有序数组：把每个数组的第一个元素放进小根堆，每次弹出最小的，再把那个数组的下一个元素压进去。写出完整程序。
  4. 有一组任务，每个任务有截止时间和收益，写一个程序用堆在 O(n log n) 内选出能按时完成的收益最大的任务集合。
◆小结
  • 堆只看上下、不看左右，是完全二叉树，用数组存，父子下标靠 2i+1 和 (i-1)/2 算
  • 插入是放末尾再上浮，删堆顶是搬末尾再下沉，都是 O(log n)；优先队列就是这套接口
  • 批量建堆从 n/2-1 倒着下沉，只要 O(n)，比逐个插入快一倍以上
  • 堆排序 O(n log n)、原地、不稳定；top-k 用大小为 k 的堆，方向别搞反
  • 下一课 第 9 课 哈希表：不比较大小，直接算位置，查找 O(1) 的代价是丢掉顺序
