关于本站

这个站是什么#

她最初是我自己的课程讲义：学 C 的时候踩过的坑、老师讲得不够细的地方、各种各样奇奇怪怪的报错。。。

现在，她是「Hello Sekai」，一个纯静态的编程学习站，把大一要用的编程内容整理成能在浏览器里直接读的教程，再配上一套可以在浏览器里跑的练习题。

为什么叫 Hello Sekai#

每个程序员（和刚学编程的人）写下的第一行代码几乎都是 printf("Hello, World")。而 sekai 是日语里「世界」的罗马字。

Hello, World 是你对电脑说的第一句话，Hello, Sekai 是你用代码开始接触这个世界。名字起得真的有点中二2333，但意思是真的。

现在站上有什么#

  • C 语言：43 篇，分三册。入门册从「什么是程序」讲到两个完整项目；进阶册专攻数组、指针、结构体；实战册补上文件读写、位运算、多文件工程和调试这些课本不教但课程设计天天用的东西。
  • C++：16 课，从装环境、第一个程序讲起（不需要先学 C），一路到类、STL、模板、异常和智能指针。
  • Python：16 课，从装 Python、第一次 print 讲起（不需要先学别的语言），到类、正则、标准库和两个完整小项目。
  • 数据结构：12 课，全部用 C 实现，从复杂度到动态规划入门。
  • 计算机基础：8 课，进制与编码、程序怎么跑起来、操作系统、命令行、Git、调试、网络、Markdown。
  • 在线刷题：C、C++、Python 共 90 道题，写完当场判。

每篇末尾都有练习题。

在线判题是怎么做到的#

这个站没有后端，也不打算有。所以判题不是在服务器上跑的，而是在你自己的浏览器里跑的：

  • 网站内置了两个用 JavaScript 写的迷你解释器，一个跑 C / C++，一个跑 Python；
  • 你点「运行判题」，代码在本机解释执行，标准输入用题目的测试数据，然后把输出和期望结果逐字比对；
  • 代码不会上传到任何服务器，我这边看不到任何人写了什么。

代价是它只支持语言的一个子集。目前不支持：struct、class、vector、string 类、malloc、文件操作、多文件工程。碰到这些会直接给出中文提示，而不是假装判错。

▲判题会误报吗

会。这套解释器是手写的，边界情况一定还有 bug。如果你确信自己的代码是对的却被判错，把代码发给我，我改解释器。

首页左上角的「Hello Sekai」，点一下会播放 DECO\*27 的《ハローセカイ》，再点一下暂停。这首歌也是这个网站的站名来源（火锅P，永远滴神！）

只有首页能点哦。如果你用的是 Safari 并且没声音，那是浏览器不支持 OGG 格式，换 Chrome 或 Edge 就好。

关于隐私#

这个网站不会收集任何个人信息，没有统计埋点，没有第三方资源。

你的学习进度和做题记录只存在你自己浏览器的 localStorage 里。换设备、清缓存就没了——这是设计如此，也就意味着我完全不知道谁在学、学了多少（）。
