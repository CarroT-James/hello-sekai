第 6 课 vector 与 string

预计 30 分钟·约 6,437 字·C++

到目前为止，你的每个变量都只装一个值。int a = 80; 就是 80，想存第二个分数就得再声明一个 b。五十个分数呢？总不能写五十行。

这类「一串同类型的数据」，需要专门的容器。C++ 标准库给了两个天天要用的：std::vector 存一串元素，std::string 存一串字符。它们的共同点是：自己记着有多长，自己管着内存，你只管往里放、往外取。

6.1 先说清楚「一串数据」难在哪#

朴素的做法是事先估一个最大数量：声明一块能装 100 个数的空间，够用为止。这个做法有三个绕不过去的麻烦。

第一，长度是猜的。猜 100，来 120 个人就装不下；猜 10000，大部分时候浪费。而且真实情况经常是「读进来才知道多少个」。

第二，长度和内容要人工同步。空间能装 100 个，实际装了 37 个，你得另外拿一个变量 n 记住 37。这两个数字一旦对不上，程序就开始读写垃圾数据。

第三，越界的代价是隐形的。往第 100 个位置写数据（下标从 0 开始，合法下标只到 99），编译器不管你，运行时可能悄悄改掉旁边另一个变量的值。程序不会崩，只会给出莫名其妙的结果。

std::vector 把这三件事一起解决了：它会自己扩容，自己记住元素个数，还提供了一堆现成操作。代价只是多写一个 #include。

6.2 vector 的基本用法#

用之前加 #include <vector>。定义一个 vector 有好几种写法，区别值得看清楚：

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> a;              // 空表，一个元素都没有
    std::vector<int> b(5);           // 5 个元素，都是 0
    std::vector<int> c(5, 3);        // 5 个元素，都是 3
    std::vector<int> d = {1, 2, 3};  // 三个元素：1、2、3

    std::cout << "a 的大小：" << a.size() << "\n";
    std::cout << "b 的大小：" << b.size() << "，b[0] = " << b[0] << "\n";
    std::cout << "c 的大小：" << c.size() << "，c[2] = " << c[2] << "\n";
    std::cout << "d 的大小：" << d.size() << "，d[2] = " << d[2] << "\n";
    return 0;
}
运行结果
a 的大小：0
b 的大小：5，b[0] = 0
c 的大小：5，c[2] = 3
d 的大小：3，d[2] = 3

std::vector<int> 读作「装 int 的 vector」。尖括号里换成 double、std::string、甚至你自己写的类，都行——它是通用的，不只为 int 服务。

圆括号讲个数，花括号讲元素，这是最容易混的一处。std::vector<int> b(5) 是「5 个 0」，std::vector<int> b{5} 是「一个 5」。写错了不报错，只是内容完全不一样，查起来要命。我建议：要用个数就用圆括号，要列元素就用等号加花括号，别混着写。

最常用的是先建空表，再一个个加：

C++
#include <cstddef>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores;

    scores.push_back(90);
    scores.push_back(75);
    scores.push_back(88);

    std::cout << "人数：" << scores.size() << "\n";
    std::cout << "第一个：" << scores[0] << "，最后一个：" << scores[2] << "\n";

    for (std::size_t i = 0; i < scores.size(); ++i) {
        std::cout << scores[i] << " ";
    }
    std::cout << "\n";

    for (int x : scores) {
        std::cout << x << "\n";
    }
    return 0;
}
运行结果
人数：3
第一个：90，最后一个：88
90 75 88
90
75
88

push_back 把一个元素加到末尾。size() 返回元素个数，类型是 std::size_t，一个专门表示「大小」的无符号整数。它的定义在 <cstddef> 里，不过 <vector> 一般已经替你带上了。

[] 按下标取元素，从 0 开始。第一个元素是 scores[0]，最后一个不是 scores.size()，而是 scores.size() - 1。这个差一错误（off-by-one）是新手最常见的 bug，没有之一。

下面那个 for (int x : scores) 叫范围 for，意思是「把 scores 里的每个元素依次取出来，叫 x」。不用写下标，不用算长度，也不容易写错边界。第 8 课会专门讲它的细节，尤其是 x 该不该加 &。

▲常见错误

空 vector 不能直接下标赋值。std::vector<int> v; v[0] = 1; 是错的：v 里一个元素都没有，v[0] 访问的是不存在的位置，属于未定义行为，可能崩，也可能悄悄改坏别的内存。要加元素就 v.push_back(1)；要一开始就有 3 个位置，就写 std::vector<int> v(3);，这时 v[0] 到 v[2] 都是合法的。分工记牢：push_back 负责变长，[] 只负责访问已经存在的元素。

6.3 自动扩容：size 和 capacity#

size() 是「现在装了几个」，capacity() 是「当前申请的空间最多能装几个」。装满以后继续 push_back，vector 会申请一块更大的内存，把旧元素搬过去，再释放旧的。这就是自动扩容。

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;

    for (int i = 0; i < 5; ++i) {
        v.push_back(i);
        std::cout << "size=" << v.size()
                  << " capacity=" << v.capacity() << "\n";
    }
    return 0;
}
运行结果
size=1 capacity=1
size=2 capacity=2
size=3 capacity=4
size=4 capacity=4
size=5 capacity=8

具体倍数由标准库实现决定，你这台机器上可能是 1、2、4、8，别的环境可能不一样，不保证。规律是：容量按倍数涨，所以连续 push_back 的平均代价并不高——虽然某一次会搬 4 个元素，但平摊到每次插入上很便宜。

这里有个必须知道的副作用：扩容会让之前拿到的元素引用失效。第 2 课说过引用就是别名，它绑的是那块内存；扩容时元素整体搬家，原来的位置已经作废，你还拿着旧引用去改，改的是一片没人管的内存。

如果你事先知道大概要装多少个，可以先用 reserve(n) 一次性留够空间：

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    v.reserve(1000);     // 先留出 1000 个位置，size 仍然是 0

    std::cout << "size=" << v.size()
              << " capacity=" << v.capacity() << "\n";
    return 0;
}
运行结果
size=0 capacity=1000

reserve 只改 capacity，不改 size。留完空间你还是得 push_back，只是它不会再半路搬家和扩容了。

6.4 string：字符串也是一种容器#

std::string 是「一串字符」，用法和 vector 很像：有 size()、有 []、能遍历。但它多了很多专门为文本准备的操作：

C++
#include <iostream>
#include <string>

int main() {
    std::string line;
    std::cout << "请输入一句英文：";
    std::getline(std::cin, line);

    std::cout << "原文：" << line << "\n";
    std::cout << "长度：" << line.length() << "\n";
    std::cout << "前 5 个字符：" << line.substr(0, 5) << "\n";

    std::string language = "C";
    language += "++";                 // 拼接
    std::cout << "拼接：" << language << "\n";

    std::size_t pos = line.find("C++");
    if (pos != std::string::npos) {
        std::cout << "C++ 的位置：" << pos << "\n";
    } else {
        std::cout << "没有找到 C++\n";
    }
    return 0;
}
运行结果
请输入一句英文：I like C++
原文：I like C++
长度：10
前 5 个字符：I lik
拼接：C++
C++ 的位置：7

getline(std::cin, line) 读一整行，空格也留下来。std::cin >> line 遇到空格就停，只能读一个单词——这是两种读法最直观的区别，也是「输入里有空格就读不全」这类 bug 的根源。

length() 和 size() 完全一样，都是「有多少个字符」。注意它数的是字节，不是「几个汉字」：一个汉字在 UTF-8 里通常占 3 个字节，所以 substr(0, 3) 切中文很可能只切到半个字，打印出来是乱码。中文处理以后用专门的库，现在先按「英文字符 = 1 个」理解。

find 找不到时返回 std::string::npos，这是个特殊值，通常等于无符号整数的最大值。所以判断要找没找到，必须写 pos != std::string::npos，不要写 pos == -1——有时代码也能碰巧跑对，但类型对不上，属于「能跑但不对」的写法。

拼接用 += 或 +，比较内容用 ==。if (a == b) 比的是两个字符串的内容是否相同，这正是你直觉上期待的行为。

6.5 完整例子：读 n 个分数求平均#

把上面学的拼起来。题目：先读人数 n，再读 n 个分数，输出平均分。

C++
#include <iomanip>
#include <iostream>
#include <vector>

int main() {
    int n = 0;
    std::cout << "人数：";
    if (!(std::cin >> n) || n <= 0) {
        std::cout << "人数不对\n";
        return 1;
    }

    std::vector<int> scores;
    scores.reserve(n);

    double sum = 0.0;
    for (int i = 0; i < n; ++i) {
        int x = 0;
        std::cin >> x;
        scores.push_back(x);
        sum += x;
    }

    std::cout << "平均分：" << std::fixed << std::setprecision(2)
              << sum / scores.size() << "\n";
    return 0;
}
运行结果
人数：3
90 80 70
平均分：80.00

几个点：

  • !(std::cin >> n) 的意思是「读失败」，比如你输入了字母。cin >> 失败时会把变量置成 0，所以后面还要判 n <= 0。
  • reserve(n) 只是提前留空间，循环里仍然要 push_back。不去 reserve 也能跑，只是中途会多搬几次家。
  • sum 必须是 double。要是写成 int sum，sum / scores.size() 就是整数除法：90、80、70 这组正好等于 80，看不出问题；换成总和 259，你会得到 86 而不是 86.33。
  • std::fixed << std::setprecision(2) 表示「固定小数点后两位」，需要 #include <iomanip>。这个设置会一直有效，直到你改回来。
  • sum / scores.size() 里，double 除以 size_t 会自动转成浮点运算，不会掉小数。

vector 对象离开作用域时，里面的元素会跟着销毁，内存自动归还。这也是第 5 课说的 RAII——你什么都不用写。

6.6 二维表：vector 套 vector#

std::vector<std::vector<int>> 就是「每个元素又是一个 vector」。外层表示行，内层表示列，正好对应一张表格。

C++
#include <cstddef>
#include <iostream>
#include <vector>

int main() {
    std::vector<std::vector<int>> scores = {
        {80, 90, 70},
        {60, 75, 88},
        {95, 95, 92}
    };

    for (std::size_t i = 0; i < scores.size(); ++i) {
        int sum = 0;
        for (int x : scores[i]) {
            sum += x;
        }
        std::cout << "第 " << i + 1 << " 行平均分："
                  << static_cast<double>(sum) / scores[i].size() << "\n";
    }
    return 0;
}
运行结果
第 1 行平均分：80
第 2 行平均分：74.3333
第 3 行平均分：94

访问第 2 行第 3 列，写 scores[1][2]。外层 size() 是行数，scores[i].size() 是第 i 行的列数。

static_cast<double>(sum) 是把 int 显式转成 double，等价于写 (double)sum，只是 C++ 更推荐这种写法——它一眼能认出来，也容易被搜索到。

每行长度可以不一样，这叫锯齿状的表：第一行 3 个、第二行 5 个都合法。真实数据里做除法前，先确认内层 vector 不是空的，size() 为 0 时除法会得到无穷大或直接崩。

vector<vector<int>> 里两个连续的 > 不用加空格，这是 C++11 之后的规定。你在很老的代码里看到 vector<vector<int> >，那是旧写法，现在不用管。

◆小结
  • vector 是能自动变长的容器，push_back 加元素，size() 求个数。
  • 圆括号讲个数，花括号讲元素；空 vector 不能直接下标赋值。
  • 扩容会搬家，之前拿到的元素引用会失效；预知大小可以先 reserve。
  • string 能拼接、查找、取子串，读整行用 getline，找不到用 npos 判断。
  • vector<vector<int>> 可以直接表示二维表，两个 > 不用空格。
  • 下一课是第 7 课 map、set 与 pair，从「按下标找」升级成「按键找」。
